## 1. 来源与标注契约

基准符号、公差框和孔表必须具有独立稳定ID、所属图纸/视图，以及明确的来源身份。复用现有精确实例路径、Body/Feature、资产/几何修订、原始拓扑索引与指纹；先以锁定NuGet消费者证明需要的原生能力，已有能力不重制上游包。任意面/边的附着不能被“只支持解析基准”的现有接口名称掩盖：若需要新原始拓扑检查能力，追加独立接口并取得真实来源样本，不用解析近似替代。

局部图以父投影定义坐标系；标注可以放在局部图，但来源必须属于该投影。创建、编辑及显式重选都在提交前从原始BRep核验，来源改变时保留旧标注并标失效。已有唯一原生历史链可以提供延续证据；多路径、分裂/合并或证明不足必须停下，不能用距离、几何相似或遍历顺序选替代对象。过期标注阻止有效PDF导出。取消、关闭、文档切换和晚到原生结果不能发布部分状态。

## 2. 一批内联合实施的功能

| 子项 | 实施内容 | 必须验证 |
|---|---|---|
| 关联基准符号 | A/B/C等标识、附着面/边、引出线、移动/改名/删除/明确重选；被公差框消费时保持ID依赖 | 错源/错视图、名称冲突、原生核验、来源变更、删除依赖、撤销及存储 |
| GD&T控制框 | 常见形状/方向/位置/跳动特征、容差数值与单位、直径容差域、材料条件及有序基准引用；按特征约束组合合法性 | 法定组合拒绝、矢量符号、基准ID引用和改名、解析与自由面样本、失效保留 |
| 关联孔表 | 明确选取的孔来源、基准原点/轴、行ID与孔序号、X/Y及孔规格/深度等；标准孔/重复孔和进口真实孔分别核验 | 消费后的孔历史、删除/改变孔、实例位姿、标准与自定义尺寸；不能把外圆柱误认成孔 |
| 装配序号 | 明确实例路径、气泡/引出线、序号表及数量 | 递归装配、共享定义、路径变更、删除及撤销，不按名称合并不同身份 |
| 模板复用 | 具名模板保存/选择/应用，自定义栏位、图框分区和制造备注 | 复制模板不带模型来源；应用不移视图，字段完整存储与迁移；纸张和三语言打印标签 |

孔表的制造尺寸必须来自已证明的原始孔或作者配方及有效延续，不只抄写存储中某个历史HoleRecipe的数值。后继可能填平、切掉或改变孔时，缺少存续证据的行要标失效。设计配方表与当前实体的有效孔表需在界面及契约上明确区分，不混写为已经制造验证。

1. 核对原始拓扑/孔/历史能力，保存聚焦消费者及真实fixtures；需要新能力时使用新不可变版本，不覆盖curve-inspection.6或冻结source4。

3. 追加drawings独立迁移和必需能力；旧文档没有新字段时保持布局，旧版本夹带新字段必须拒绝。损坏/缺失/重复ID与跨文档引用在发布文档前失败。
4. 把矢量符号、引出线与表格加入共同DrawingPageLayout；WPF与PDF共用同一内容。避免用字体缺失的特殊字形充当唯一符号。
