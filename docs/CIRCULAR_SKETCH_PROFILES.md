# M4-S3a–f：精确圆形草图区域

这一轮在已有圆的草图编辑能力上，交付 **单个完整圆区域的关联拉伸**。在草图编辑窗口绘制非构造圆并确认后，选择该草图、启动“草图拉伸”，可在来源列表选取带 `○` 与半径的圆。预览/确认使用 OCCT 的真实圆边、闭合线框和解析平面，结果不是折线近似。再次编辑草图半径时，关联拉伸和后继依赖在隔离候选中重算；确认后可撤销/重做。

## 六个有界阶段

1. **S3a — 圆区域身份**：`SketchProfileBuilder.Circle` 根据稳定圆 ID 从当前草图提取中心/半径；构造圆不能作为边界。多条直线闭环仍按既有 `SketchLoops` 识别，不把同坐标、相交或嵌套的其它元素隐式合并。
2. **S3b — 精确原生拉伸**：`SketchProfile` 显式区分多边形与圆。OcctSharp 已有 `ShapeFactory.CreateCircleEdge`、`CreateWire`、`CreatePlanarFace`，无需上游迁移；内核从圆面拉伸并沿草图平面放置。圆区域旋转暂不提供，验证明确拒绝。
3. **S3c — 关联更新**：`SketchProfileReference` 在原有有序线 ID 外添加互斥的圆 ID；解析核对草图、修订、零件及非构造状态，缓存比较中心和半径。上游草图半径或圆心改变后，重建根特征及其后继；失败不发布部分结果。
4. **S3d — 编辑入口**：建模面板“草图拉伸”的来源列表列出非构造圆，旋转来源仍只列出直线区域。草图编辑器的半径输入同步改动该圆的驱动半径约束；选中的线/圆/点可切换构造状态，并沿用本窗口草稿撤销/重做。
5. **S3e — 文件协议**：写出器 `0.4.17`，`features` v11。`extrude-circle` 白名单配方保存距离、中心与半径，引用 DTO 在既有键后增加 `Circle`；v10→v11 显式拒绝旧版本伪装的新圆字段/配方，旧文件其余字段和身份按原样迁移。
6. **S3f — 交付链路**：验证实际 OCCT 体积与放置、关联尺寸修改、精确撤销/重做、MessagePack 保存重开、STEP/IGES/STL 导出，以及生产 30 秒检查点后强制终止/重启恢复圆引用与实体。

S3a–f 当时完整圆只作为**一个独立的拉伸区域**；后续 S3g–l 已增加明确选择的完整圆孔，见 [圆孔拉伸](CIRCULAR_SKETCH_HOLES.md)。多环自动识别、圆弧混合闭环、切线/角度约束及圆区域旋转仍未实现。可编辑的圆与引用必须保持同一草图/零件；构造圆不能暗中变成建模区域。圆的几何地址是草图实体 ID 与修订，不是通过位置重新猜测的轮廓。完整验收证据与仍未运行的环境门禁以 [ROADMAP](ROADMAP.md) 为准。

联合验证已通过：Release 零警告/错误、406/406 测试、独立发布及桌面/窗口/强制终止恢复冒烟；时间戳 `20260924-192956`。锁定包独立消费探针 21/21、62/62 原生 DLL 匹配。草图物理鼠标专项和混合 DPI/RDP 仍另行验收。
