# B7：圆弧尺寸、倒角、多角编辑与关联轮廓更新

更新：2026-10-01。承接 [B7 规划](B7_SKETCH_FINISHING_PLAN.md)，属于 [A–F 总实施请求](AF_IMPLEMENTATION_TRACKER.md)的 B 批子任务；不代表第 1–6 大批全部完成。第 7 批实机、安装与正式交付按用户要求暂缓。

## 已实现的五项

| 项目 | 行为与范围 |
|---|---|
| 圆弧尺寸 | `RadiusConstraint` 支持圆/三点圆弧；`EqualRadiusConstraint` 支持圆—圆、圆—弧和弧—弧。圆弧使用解析外接圆半径及 Jacobian，不引入代替精确圆弧的线圈 |
| 两线倒角 | 两条共用唯一端点 ID 的有限直线，支持相同/不同退距；A 对应第一条所选线，B 对应第二条线，裁剪后生成直连接线 |
| 多角编辑 | 同一简单直线闭环 1–32 个明确角点，一次圆角或倒角。所有候选基于同一原草图计算，两端合计裁剪预算提前检查；任一角失败整次拒绝 |
| 关联轮廓更新 | 勾选本草图受影响的关联拉伸/旋转，利用明确编辑对应表插入新连接实体。首批限无孔/岛的单一多边形或混合外环；不扫描并猜测新的闭环 |
| 操作与诊断 | 英/中/日工具、半径/双退距、持续半径选项、特征勾选、选中/编辑角数及约束清理反馈；几何错误携带语言资源键，消费层显示本地化错误和相关 ID |

## 操作

- 单角：选择“草图圆角”或“草图倒角”，按顺序点击两条直线、输入尺寸并应用。“约束半径”默认勾选，创建持久驱动尺寸；取消勾选仍可生成独立几何。
- 多角：选择“多角圆角”或“多角倒角”，点击原闭环角点后应用；再次点击可取消该角选择。批量倒角 A/B 按所选闭环的固定遍历次序分配，可在预览中检查两侧退距。当前不自动选择所有角，也不在已经含弧的环上使用多角工具；该环剩余直线角可继续单角操作。
- 关联更新：展开“更新关联角点轮廓”，明确勾选全部受影响的特征，再求解预览。未勾选的失效引用不会自动被替换；所选轮廓含孔/岛、非唯一相邻关系或对应已改变时拒绝。
- 圆弧尺寸：选择一个圆/圆弧添加“圆 / 圆弧半径”；选择两个不同圆/圆弧添加“圆 / 圆弧等半径”。后续用已有尺寸列表修改、禁用、启用和删除，走同一预览/确认事务。

持续半径并不自动锁住其他自由度。若希望改半径时保持原框形状，应保留/补齐位置、方向和尺寸约束；求解器只执行已有约束，不猜用户希望固定的点。倒角退距是创建尺寸，本批不新增可长期重放的参数化倒角特征。

## 解析、历史和引用契约

圆弧半径按三角形外接圆公式 `|AB|*|BC|*|CA|/(2*abs(cross(AB,AC)))` 计算。Jacobian 由弦长和有向面积的解析对数导数组合；圆半径仍是独立变量。只有纯圆半径关系是仿射方程；含圆弧的尺寸关系进入非线性求解。求解器版本为 `cadoryx.sketch.lm-svd.5`。尺寸驱动圆弧与端点相切圆弧均保持原有有向面积分支，候选点退化或分支翻转拒绝；长弧/短弧用例分别验证。

单角几何边界继承 B6：有限正尺寸、裁剪余量 `1e-7 mm`、夹角距 0/pi 大于 `1e-6 rad`、同构造状态、唯一共享端点、无分叉，投影驱动线须先解除。多角计算先把每条原线两端退距相加，防止剩余线反向后误以为“仍有长度”；最终按已知原环插入连接实体并验证闭合/自交。倒角结果保持多边形引用，有圆弧的结果保持混合引用。

受影响线/被删除角点的旧约束清理；远端未改变的既有端点相切约束保留，允许同一原线两端先后编辑而不破坏前一端 G1。新增圆弧的两条相切及可选半径约束使用独立稳定 ID。

`SketchDraft` 的单条历史同时恢复几何和临时 `CornerReplacements`，草稿撤销后不留下已被撤销的对应表。对应表包含原角点/两条原线和新切点/连接实体 ID，**不写入文件**。

`UpsertSketchCommand` 在求解前验证对应与原快照修订/所有权、原线端点及新身份；明确勾选的特征须引用该草图，并且旧边界已合法、两边唯一相邻。不能把旧 ID 伪装成新连接实体，也不能对改变后的裁线继续使用旧对应。更新后的引用、求解结果、原生后继、关联图纸与资产全部在同一候选中完成；失败/取消保留原快照，确认只产生一条文档历史。
