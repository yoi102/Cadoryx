# F3f：原始面、边与制造附着历史

更新：2026-10-03。A–F整体进行中，G实机、安装及交付暂缓。接续[F3e](F3E_TYPED_DATUM_SYSTEMS.md)。本页明确定义的本地契约已实施并验证；整个A–F仍进行中。

## 引用契约

任意精确原始面、边可作为历史入口，包括导入实体和特征结果上的生成面。来源必须绑定文档、生产Feature、资产、修订、完整拓扑图指纹、类型和原始定位；不能把新修订里的同序号当作旧身份。旧Box语义查询保留既有入口。普通孔已有真实原生历史，现加入可验证链路；组合孔的中间历史、抽壳及缺历史算法仍不能伪装成原始到最终的历史。

历史只消费一条完整、有限的来源到目标链。逐步核对所有操作数的顺序、资产、修订、指纹、拓扑数量、类型及覆盖，结果也重新核对。新精确入口重放原生操作，比较结果指纹及完整对应关系；正确指纹和面类型不能授权被篡改的同类型目标映射。分裂、共享合并、生成、删除、缺证据、多路径和预算超限返回失败，不能提供可用的部分目标。

制造附着还逐字段核对原始面/边分类、边界、参数及引出点。原始Body被后继消费时从保留的Feature.Result读取原始BRep，不要求旧Body仍可见。目标来自当前明确图纸来源；多个可达目标即使共享相同结果资产也不选择其中一个。更换图纸来源后可沿唯一链延续，尚未重选来源的过期视图继续保旧。

## 作者来源与当前绑定

`DrawingTopologyReference.HistoryOrigin`保存作者最初选择，当前引用保存已证明的后继身份。禁止嵌套来源、跨实例/定义、同特征修订伪历史及类型变化。再次延续始终从原作者来源出发，不能以当前遍历槽覆盖作者选择。

基准、公差框、装配序号和孔表在同一编辑事务内刷新。完整尺寸轴及孔行重新运行原始邻接/尺寸核验，不能搬用旧尺寸证明。共同/有序基准框仅在每个基准的作者来源与类型保持时刷新当前绑定；明确重选基准仍使依赖框失效并要求确认。失败保留旧引用、尺寸和作者绑定，失效阻止有效PDF。撤销/重做恢复同一快照。

延续及失效状态保留当前引用和原始来源的资产租约；保存重开仍可保留旧证明，而不能依赖撤销历史替它持有资产。圆柱零件端面的原始内外圆环也已区分：与外壁相邻的外环不能误认作沉孔肩部，合法圆柱零件通孔/盲孔可以取得独立孔证明。
