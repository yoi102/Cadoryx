# B8：精确曲线、孔和嵌套岛旋转

更新：2026-10-02。属于 A–F 的 B/G06，第七批暂缓。本批明确范围的代码、核心、原生和三语言生产窗口检查已完成；本子批次不代表整个 A–F 完成。

## 几何与作者契约

- 二次 Bézier、已有夹持均匀三次 B 样条和含它们的混合闭环使用精确曲线构建 BRep，不从显示折线重建。
- 圆、多边形、混合曲线和样条孔保持作者选择；每级先用精确面交集与边界距离确认严格包含及分离，再旋转并执行精确差集。递归岛独立构造并输出显式多 Solid compound；单独一个材料区域必须得到一个有效 Solid。
- 默认局部 Z 轴保持正半径；明确作者轴可使用任一径向半平面。轴须位于作者 XZ 子午面，旋转方向由所选轴方向决定。圆不能切轴，曲线内部切轴/穿轴拒绝，合法端点和直线边界可落在轴上。
- 轴向投影的极值来自圆弧解析角度、二次多项式导数、每个三次样条结点区间的符号 de Boor 多项式及二次导数根。控制点越轴不自动意味着曲线越轴；起点/中点/终点与显示采样不作为轴穿越证据。
- 任意控制多边形、非均匀结点和精确草图交点仍属 G05 后续工作。本次只扩展已有曲线作者契约，不删除 B/E 的待办。

## 应用与原子操作

生产旋转入口提供 Bézier/样条轮廓和完整孔岛选择；作者可逐项选择孔、岛或明确执行已有嵌套区域按钮。取消释放候选，确认一次原子提交；旧状态、非法区域、原生失败保留原文档。完整配方编辑保留冻结曲线及多边形孔岛，避免仅加载外环而丢失内部区域。

草图来源缓存现在核验旋转的全部曲线、孔与递归岛。C1 角度、C2 关联基准轴、草图控制点更新、Boolean 后继和关联工程图通过同一重算闭环；关联来源按明确 ID 更新，不按几何相似搜索替代引用。
