## 实施契约

- 复制来源必须是同一零件内当前精确特征输出；消费来源可见实体，保留生产特征、属性和依赖。一条命令生成稳定输出特征/实体；取消、失败、撤销与重做保留精确快照。
- 平面镜像使用原生 `gp_Trsf.SetMirror(gp_Ax2)` 与精确 BRep 变换，允许仅镜像或包含原件。镜像平面以零件局部坐标系 Z 为法向，原点属于镜像平面。
- 线性阵列沿局部 X，数量含原件，2–256，带符号非零间距不超过 ±1,000,000 mm。圆周阵列绕局部 Z 轴及指定原点；角间距生成一圈内不重复副本，或整圈均匀分布 `2π/count`。
- 输出明确为组合副本或融合并集。组合保留独立相交体积，体积是各副本之和；融合执行精确 Boolean 并集，分离几何仍可能得到多个实体。
- 每个副本持久 GUID，数量变化保留存续前缀，重新增长生成新身份。这些 GUID 是副本来源身份，**不是边/面拓扑延续的证据**；当前不发布虚构历史对应关系。
- C1 支持 Count 有界整数标量、Spacing 长度、Angle 角度；同时驱动字段先全部写入后验证配方，避免暂态数量/角度组合使合法最终候选被拒绝。
- C2 基准与配方进入联合依赖图。绑定帧必须来自同一零件，基准变更更新副本及后继；来源修订与基准修订严格校验。解除基准保留最后应用帧；绑定期间手动改变帧拒绝。
- 三语言窗口支持新建/编辑、参数、基准或手动帧、精确候选预览、确认/取消；特征树编辑路由到同一窗口，关闭释放候选资产。
