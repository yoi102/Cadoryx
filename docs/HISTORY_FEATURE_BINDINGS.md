# H2-C2：跨特征边绑定与显式重选

当前可将 Box 源语义边沿唯一、已验证的历史路径绑定到另一特征的 BRep，创建真实的非 Box 单边圆角。`FeatureTopologyBinding` 保存源语义引用、目标 `FeatureId`、目标结果的精确修订与资产、完整拓扑边索引及适配器版本；`HistoryFilletRecipe` 保存被消费的精确 BRep、索引和半径。查询结果本身不写入文件，只有用户确认后的绑定才成为建模输入。

操作入口在主窗口“历史诊断” MetroWindow：先保存边查询，再分析当前文档。只有状态为 `Resolved`、目标是边，且查询和文档状态均未改变，才能创建圆角。上游变化会清除窗口中的确认；命令提交时再次追踪并比较完整的 `HistoryTarget`。对于过期的圆角，先选对应特征、重新分析当前边，点击“重选边并重算圆角”。旧目标不能替代新目标；`Ambiguous`、`Generated`、`Deleted`、多路径或没有完整证据时停止，不猜测索引。

上游重算改变目标资产或修订时，绑定圆角和后继特征冻结旧结果、标记 `IsStale`、清除其拓扑历史；保存保留旧 BRep 和绑定以便诊断、撤销与显式重选。导出拒绝包含过期特征的文档，避免将旧结果当作当前几何。重选后圆角及其后继按依赖顺序重新计算，精确撤销／重做保留各自状态。`DocumentSnapshot.Validate` 核对绑定、配方、依赖、目标和当前资产的一致性；资产租约覆盖冻结结果。

`.cadoryx` 写出版本 0.4.7，十节 MessagePack：`document` v7、`features` v6（过期位）、新增必需的 `feature-bindings` v1。旧 0.4.6 的九节文件迁移时添入空绑定节并升级字段版本；损坏或重复绑定拒绝加载。恢复快照仍使用生产的 30 秒定时器及正常存储路径，恢复后会重新核对 BRep 历史。

本阶段调用固定 OcctSharp `8.0.1-preview.28.cadoryx.h2b2.2` 包已有的历史追踪和圆角建模接口。独立能力消费测试已验证该包及 62 个原生 DLL；H2-C2 没有证明新的封装缺口，因此没有修改 OcctSharp 或原生 ABI。当前范围是具有 Box 语义源边且能唯一追踪的单边圆角；通用拓扑命名、生成边／面继续建模、多边和变半径、自动重绑定仍按 ROADMAP 后续任务实施。

定向测试覆盖窗口的“先分析再创建”、上游变更清除确认、显式重选、后继过期传播、撤销／重做、十节保存重开、旧九节文件迁移和重复绑定节拒绝。完整脚本 `scripts/verify.ps1 -PublishSmoke -WindowSmoke -RecoverySmoke` 的最终日志及证据位置见 [路线图验证记录](ROADMAP.md)。窗口冒烟实际打开带 Owner 的 MetroWindow，完成创建、过期、重选；恢复冒烟通过生产定时器、强制终止和重启核对绑定字段与原生历史。混合 DPI/RDP、长期运行和真实大模型仍未验收。
