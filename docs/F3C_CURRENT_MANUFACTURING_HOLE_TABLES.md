# F3c：当前有效制造孔表

更新：2026-10-03。用户授权完成A–F，第七批G实机、安装及交付暂缓。F3c接续[F3a关联标注](F3A_ASSOCIATED_ANNOTATIONS.md)与[F3b模板复用](F3B_TEMPLATE_LIBRARY.md)，不代表整个A–F完成。

## 当前实现

孔表、孔行与孔序号具有独立稳定ID。工程图新增“孔表”页，可创建、改名、移动、编辑明确的原点/坐标轴，添加、删除、核验和显式重选孔行。重选保持行ID；删除视图同步删除其孔表。操作进入同一文档事务，支持撤销与重做。

原点和坐标轴以当前视图首个来源实例的局部坐标定义，并保存该实例的完整路径与定义身份。坐标通过各孔来源的当前世界位姿换算；同一孔实体的不同装配实例是不同的明确来源。表的Z轴必须与孔轴平行。纸面孔表、孔号定位及O/X/Y坐标轴与PDF使用共同矢量布局。物理单位统一换算；通孔显示THRU/通孔/貫通，盲孔深度包括沉孔或沉头部分。

每张图最多16表，每表32行。孔号1–9999，在表内唯一；行ID在图纸内唯一，同一原始孔壁不能在同表重复。表须在图框内，避开标题栏/投影符号、其他表和自定义栏位/制造备注。应用模板仍保留孔表来源与ID；尺寸变小后无法容纳内容时，整笔编辑拒绝。

## 当前原始实体证明

锁定包保持`8.0.1-preview.31.cadoryx.curve-inspection.6`，无需重制上游包。原始形状的edge→face及vertex→edge邻接提供明确身份，`RepairSnapshot.FindTopologyIndex`核对原始索引。深拷贝的`CopySubshape`只用于明确选取几何类型，不能用于证明原图邻接。

识别要求一个有效、正向实体，完整内向解析圆柱壁及两端有限圆环。圆弧分段必须共享原始顶点、无分叉，并在同一解析圆平面上无重叠、无缺口地覆盖2π。周期缝只能连接自身面；侧切产生的开放线不能冒充缝。平面邻接的圆心由有界域分类证明为开口或封闭孔底。

沉孔沿原始肩面两圈的邻接连接较大孔壁；沉头沿原始共有圆环连接完整内向圆锥壁。共同边/肩面、共轴、方向、大小端与开口都必须成立。总深度取已证明的入口到孔底/另一开口，不能把主孔壁长度抄作总盲孔深度。原始指纹在检查前后必须相同。

外圆柱、完全封闭内腔、被后继切开或填平的孔均不接受。任意曲面开口、多个连续孔径台阶、双端孔头及证明不足的过渡暂不属于这一识别契约；明确拒绝，不报为已验证孔。检查预算为100000个原始拓扑项、4096面、8192边；取消及晚到结果受原始文档捕获和窗口生命周期守卫约束。

## 规格来源、失效与保存

尺寸首先来自当前原始实体。仅当当前直接生产特征为HoleRecipe，且入口、方向、通盲模式、所有孔/孔头尺寸与独立原生证据一致，才标为“当前作者孔”并携带已核对的普通公制间隙孔规格。STEP进口孔及当前阵列实体中的孔标为“当前几何”；不从历史配方猜测标准规格或旧孔的存续。

几何、生产特征或原始来源改变后，保留旧行/旧尺寸/旧来源并标失效，阻止有效PDF。修改孔直径、重建阵列、来源删除和错误重选均被检查。单独重选一行时可保留其他失效行；它们仍不能混入有效PDF。跨修订没有使用距离、相似几何或遍历顺序自动重绑。

`drawings`独立升级v8，必需能力`cadoryx.current-hole-tables.1`；document39、features35、sketches16及锁定SDK不变。v7→v8要求旧字段缺失，旧版夹带新空数组也拒绝。旧v6→v7仍按原步迁移，不跳过孔表迁移。

保存及加载有效孔行必须提供IDrawingHoleResolver，并逐行重新核验原始实体及全部缓存尺寸；伪造直径、深度或拓扑证据拒绝，失败保存保留旧文件。WPF与CLI已有原生核验器注入；无核验器的读取/保存明确拒绝有效孔表。失效行可以保存以待明确重选。只读设置元数据仍不初始化原生核验。

历史插入守卫按内容核对孔表及各行作者数据，只允许关联坐标和失效缓存刷新；加载后数组容器不同不等于作者修改。文件重开后的原始孔证据、ID与合法历史插入均有专门回归。
