# F3e：完整圆柱尺寸与有类型的制造基准系统

更新：2026-10-03。A–F整体进行中，G实机、安装及交付按用户要求暂缓。接续[F3d关联孔坐标](F3D_ASSOCIATED_HOLE_COORDINATES.md)；本页记录已验证的本地契约。

## 已实施

完整圆柱尺寸证明来自原始BRep的面、边和顶点邻接：有限共轴同径圆柱壁及两端完整2π圆环。内壁与外轴分别核对。封闭内腔可以是尺寸特征，但不能据此成为有效开口孔；侧切、分叉及缺口不能仅凭圆柱分类获得材料条件。

制造基准可明确选择表面或完整圆柱尺寸轴。公差框使用有序稳定ID表达主、次、第三优先级；共同基准保留在同一框格，每个引用独立表达M/L材料边界。输入`A,B,C`表示三个优先级，`A(M)-B(L),C`表示共同主基准及次基准。领域规则核对同零件实例、重复和自引用、特征类型、材料条件、形状公差、跳动轴及共同基准的轴线相容性。未支持组合拒绝整笔事务。

公差框保存其实际消费的基准特征绑定。基准重选面或改变类型后，框保留旧绑定并标失效，必须明确确认；改名只改变标签。刷新、删除依赖、历史插入、撤销及存储完整消费有序/共同引用。尺寸来源变化保留旧证明并标失效，过期内容不能输出有效PDF。

WPF与PDF共用矢量框格和条件符号。生产编辑入口、表面/尺寸轴选择、共同基准语法及三语言指导已接入；ISO/GB独立原则与ASME Rule #1分别说明。轴引出线消费原始证明的轴中点。公差使用最短往返数值表示，避免小数显示长尾。
