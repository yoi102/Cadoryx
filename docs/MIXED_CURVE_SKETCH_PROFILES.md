# M4-S3ae–aj：直线与圆弧混合闭环

这一组六项将一段三点圆弧和至少两段直线组成的闭环，作为可选草图拉伸区域。圆弧和直线共享稳定端点 ID；用户可在草图编辑器中绘制、移动端点或弧上中点，并通过拉伸轮廓选择它。已有单圆、圆弧加隐式弦和直线多边形轮廓继续保留。

| 阶段 | 交付能力 |
| --- | --- |
| M4-S3ae | 按共享端点识别无分支闭环，拒绝开链、交叉、相切及退化区域 |
| M4-S3af | 鼠标绘制圆弧后接直线成环，预览、拾取与点编辑；成环后不再显示圆弧的虚线隐式弦 |
| M4-S3ag | 混合闭环进入关联拉伸的轮廓列表，保存有序线／弧 ID 与草图修订 |
| M4-S3ah | 用 OcctSharp 的圆弧、线段、闭合曲线链和面生成精确拉伸实体 |
| M4-S3ai | 修改草图后沿原有原子命令重算；失败保留原状态，支持原有 STEP/IGES/STL 导出 |
| M4-S3aj | 写出器 0.4.22、features v15、v14→v15 显式迁移及真实进程恢复 |

边界有意限定为**恰好一段非构造圆弧、至少两段非构造直线、无孔**。发现逻辑只接受每个端点度数为二的孤立连通分量，不在分叉处猜测下一条边。冻结配方保存真实线段和圆弧的点坐标，关联来源保存有序实体 ID；缓存不匹配时拒绝恢复。圆弧与直线交点按解析几何检查，OCCT 再检查实际曲线链和面。

任意多圆弧闭环、样条、混合曲线孔及嵌套岛屿仍在路线图后续项。OcctSharp 当前锁定包已有所需曲线链、建面和拉伸 API；最终以独立 NuGet 探针核实，不因 Cadoryx 应用层缺口推断上游缺绑定。
