# F1：精确剖面区域与剖面线

更新：2026-10-03。F 制造工程图的一项实现；整个 A–F 请求继续，G 实机、安装及交付暂缓。

剖视图现在由原始 BRep 与指定平面的精确交线构成轮廓。剖面线另外来自实体与有限平面面的 Boolean Common 区域，再将直线族与这个区域做精确 Common。孔洞、空腔和区域外部不产生剖面线；不会把采样投影中的闭合多边形当作材料。实体、含实体的 compound 和带开放片体的混合 compound 都按实际 solid 子形状确定材料，开放片体和线框仅保留交线。所有中间形状拥有独立生命周期，原模型 BRep 资产不改变。

基础剖视图和它的局部放大各按自己的比例换算纸面线距，再从原始材料区域重裁线族。默认纸面 2.5 mm，来源方向交替为 45°/135°；生产控件现在可编辑 0–小于180°角度、0.1–100 mm纸面间距、交替方向和是否填充。按明确 MaterialId 保存材料覆盖规则，支持添加、编辑和移除；规则不按材料名称或几何相似度匹配。局部图继承父剖面的材料规则，线距保持自己的纸面尺寸。关闭填充仍保留精确剖面轮廓。

来源几何、修订、位姿、材料赋值、规则或比例改变时，在发起编辑的同一事务中重算投影、剖面线和局部图；撤销/重做恢复完整缓存。失败保留原缓存并明确标记待处理，取消不提交，过期投影不能导出 PDF。纯开放片体不填充。材料规则引用缺失材料会被拒绝。配置是显式直线族，不把它称为已覆盖全部制造材料符号约定；F 的 GD&T/关联孔表仍继续。

`DrawingLineKind.SectionHatch` 是新增缓存类型，绘图预览与矢量 PDF 共用 `DrawingPageLayout`，线宽为 0.13 mm。drawings v3保存精确材料缓存，v4增加默认/材料规则和必需能力 `cadoryx.section-hatch-rules.1`，随后[F2](F2_MANUFACTURING_TEMPLATES.md)模板为v5；`cadoryx.section-hatching.1`保留。各步迁移独立，旧v2剖视图及其局部图保留交线并待刷新；旧v3精确缓存不隐式重投影；旧格式夹带新剖面线类型或配置被拒绝。工作预算为每来源最多 4096 条候选线及全图投影 100000 条 stroke；超限明确失败，不暗中改间距。
