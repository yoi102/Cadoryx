当前范围是在一个完整源实体的明确原始支撑面上，对有限平面、球面或圆柱面做定向加料/去料。作者必须保存精确起始支撑面、有限终止面、源资产/修订/指纹、方向和显式 Near/Far。终止面及支撑面从原始源成员读取，不靠几何接近自动选面。

完整轮廓、孔和递归岛的起始材料必须全部位于支撑面内；单位棱柱完整起始面积与体积核对，避免只提取部分材料。原生 Until 的结果必须通过完整材料改变、作者定向棱柱和原始有限终止面之间的精确 Common 覆盖证明；每个终止盖面都要满足明确解析分支。球/柱的解析参数仅从已确认的原生类型恢复，切触、内部/穿越起点和无法证明的分支拒绝。

原生返回成功不等于有限面域满足要求。独立 SDK 负例中过小平面仍返回 done/valid，却得到约 1268.0000128 mm³，而完整平面的期望为 612 mm³，盖面 16 mm² 的覆盖为 0；应用现在整次拒绝该负例，保留快照、历史及资产。没有用替代 Boolean 结果绕过原生失败。

原子创建/重算、来源变化冻结及明确重选、撤销/重做、精确结果重放存储复证和严格结构化 `cad_model` 作者已接入。复证不仅比较体积，还检查结果与重放实体的精确 Common 体积及拓扑数量，拒绝同体积但位于其他位置的载荷。独立零件身份复制已接入映射；有限曲面阵列模板重放明确拒绝，变换后的支撑面尚无证明。

存储为 document50 / features42 / sketches19 / drawings14 / history4，能力 `cadoryx.finite-surface-extrusion.1`。document49→50、features41→42 独立迁移，旧版本夹带有限曲面字段拒绝。生产编辑器增加加载有限面、支撑面、终止面和分支字段；加载不自动选面，改变分支使候选失效。中/英/日各 1310 个非空资源键一致；这些字段已通过候选4三语言真实窗口控件验收；“加载当前面”文案已覆盖有限球/柱面。
