## 生产契约

`SketchCurveExpressionGeometry`保存单一拥有值基曲线与64节点内的明确操作链。区间始终使用作者基曲线原生参数单位；方向单独保存。反向仅改变行进方向，Offset的距离相对于其Basis的有向右法线。重复偏移不把原作者定义替换成拟合曲线。曲线位于草图局部XY，实体/草图平面接入尚未完成；原生边接口显式接收真实RigidTransform3d平面。

`SketchExpressionTaylor`在原齐次控制数据上构造解析Taylor系数，偏移通过解析单位法线级数求导；每层偏移需要更高阶基曲线系数。无显示采样、差分或拟合。有限点求值不证明整段安全；关系调用方须先检查所需阶数的原始结点/周期接缝连续性，嵌套偏移保守累加所需阶数。

`IExactSketchExpressionGeometry`在拥有值边界外提供原生求值、投影、交点/重合检查、正则性和真正BRep。`PrepareExpression`只接受65536区间/48层预算内已经证明正切向倍率的结果；最终距离抵消不能掩盖中间折叠。周期段的原生转换可复制精确非周期段，但证明仍使用完整原始周期及原作者节点索引。原生结果只提供自己的实际几何；`GeometryResult.TopologyHistory`保持空，作者链索引不能用于自动绑定原生边/面。

`SketchCurveExpressionStorage`是独立几何schema1，不是主文档已经完成的新分区。平坦节点表仅允许一个完整叶和前置basis，支持完整64节点。JSON拒绝未知成员，MessagePack在解码前检查全部记录/控制表字段数、节点预算及尾随数据；数值定义再由作者验证器验证。当时主文档writer0.7.0及16分区版本保持；status66主文件为writer0.7.1/17分区，最新格式为writer0.7.2/document54/features43，见轮廓说明。
