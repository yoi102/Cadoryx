# M4-S3s–x：多边形草图通孔

本组六阶段将闭合直线环作为可明确选择的非圆形通孔，沿用草图修订、原子预览／确认与 BRep 资产生命周期。外轮廓可以是多边形或完整圆；孔可由圆和多边形混合组成。圆弧、样条及任意嵌套岛屿仍属后续范围。

1. **轮廓数据与校验**：`SketchProfile.PolygonHoles` 保存逐孔顶点。外环、孔环均要求非退化、无自交；孔必须与外边界严格分离，孔之间不得相交、相切或互相包含。总孔数上限 64，旋转特征拒绝带孔区域。
2. **精确内核拉伸**：对每个多边形孔建立 OCCT 平面面片，沿拉伸方向生成跨越上下表面的刀具体，并从外形依次布尔切除；预览、确认与 STEP/IGES/STL 导出使用同一几何配方。
3. **草图稳定引用**：`SketchProfileReference.PolygonHoleLines` 保存各闭合环的有序直线 ID。解析时验证草图、零件、修订、直线身份及非构造状态，并重建轮廓；修改草图会沿现有依赖链重算，非法孔保持原文档不变。
4. **建模面板交互**：选中拉伸外轮廓后可逐环勾选多边形孔，并与圆孔勾选合用。编辑已有拉伸时按线 ID 集合恢复勾选，换源与后继重算仍为一次原子提交。
5. **文件协议**：写出器 `0.4.20`、`features` v13；MessagePack 配方 Key(7) 保存孔顶点，草图引用 Key(5) 保存孔环直线 ID。v12→v13 明确迁移，仅接受没有新字段的旧数据；把 v13 字段伪装成 v12 会拒绝。`sketches` 仍为 v3。
6. **联合验收**：定向测试检查非交叠、原生体积、勾选创建／编辑、草图重算与失败回退、撤销／重做、旧版迁移、恢复及三种交换格式。联合构建、测试、独立 NuGet 消费探针和桌面冒烟的最终结果记录在 [ROADMAP](ROADMAP.md)。

此阶段仅覆盖共享点身份组成的完整直线闭环；圆弧与样条几何、带孔旋转及嵌套岛屿没有开放。混合 DPI/RDP、长期资源与大模型性能仍需独立验收。
