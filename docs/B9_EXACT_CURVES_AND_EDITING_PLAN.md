# B9：任意合法样条、精确交点与曲线编辑

承接 B8，属于 A–F 的 B/G03、G04 与 E/G05。B8 使已有曲线能旋转，但没有解除单调控制多边形和均匀结点限制；本批继续完成这些真实缺口。G 第七批仍暂缓。

## 按依赖实施

1. **独立锁定消费者**：用当前包验证非单调的合法三次样条、非均匀结点、精确求交/投影和原曲线参数区间裁剪。构建有效区域及解析/独立几何断言；重合、切触、多交点和端点明确分类，先复现 API 缺口才扩上游。
2. **明确作者曲线数据**：控制点稳定 ID、结点及重数、有效参数区间；已有均匀样条的默认值保持相同曲线。曲线合法性与闭合区域合法性分开，不再以控制多边形沿弦单调或全部同侧定义所有合法样条。任意合法控制多边形必须能编辑/保存；自交曲线可在草图中诊断，但不能冒充合法实体区域。
3. **精确几何服务边界**：领域及 Editor 不引入原生指针。Kernel Abstractions 提供复制值的参数/交点/投影/合法性契约，Occt 实现使用原曲线；交点重合区间或多个等价投影拒绝猜测。端点 G1、显示采样、轮廓校验、B8 轴极值和所有曲线构造统一消费作者的结点与区间。
4. **修剪及延伸**：点选明确有限曲线区间，保留精确 Bézier/样条而非折线。修剪后一个存活片段可按明确身份规则保留 ID；分成多个片段时分裂引用失效，清理对应约束，作者明确重选。延伸采用声明的端部多项式/曲线延续，禁止将终点连直线伪装为原样条延伸。退化、重合、歧义及不可证明的交点原子拒绝。
5. **结点与控制点编辑 UI**：生产草图入口和数字编辑、候选/错误定位、取消及撤销重做；非均匀结点、新区间和所有来源能保存并重开。原生失败/过期会话不改变旧草图、特征和资产。
6. **联合闭环**：拉伸、旋转、扫掠/放样和端点关系；控制点/结点/裁剪改变经过参数、基准、Boolean 及图纸关联更新。存储声明新语义并独立迁移，拒绝旧版本夹带字段；核心、精确原生、三语言生产控件及导出证据分别记录。

多环/孔岛偏移、实体拓扑边与椭圆投影及非共享点/G2 关系仍须随后收敛，不能因本批曲线基础扩展而删掉。A 固定性能、C 螺纹、D 曲面终止、E 多边/历史/装配、F 制造/交换/命令继续保留于总跟踪。
