# D1：高级拉伸方向、目标及平面终止

更新：2026-10-01。属于用户已授权的 A–F；第七批实机、安装及交付仍暂缓。本文记录明确的应用范围，不代表整个 D 或 A–F 完成。

## 已实现的契约

新增 `ExtrusionOptions`，旧 `ExtrudeRecipe.Options=null` 的正方向固定距离含义保持。正向区间 [0,D]、反向 [-D,0]、对称 [-D/2,D/2]（D 是总厚度），双向 [-Backward,D]。D/Backward 支持 C1 长度参数；非法方向/终止/参数组合在候选文档中拒绝。

操作包括新实体、加料及去料。加料/去料只能消费所选零件的当前精确单实体输出；保留图层、外观、材质、可见性及来源生产特征。无材料变化、完全消失或分裂成多实体均拒绝，断开的加料不能作为成功。新实体允许合法孔岛组成的多实体输出。

贯穿只用于去料，可正向、反向或对称。正反贯穿从作者选定的轮廓平面开始；不会把轮廓背后的材料一起切掉。原生 bounds 仅用于包围有限刀具体积，不能推断终止面或拓扑身份。

到平面支持正/反方向、任意合法旋转帧及斜平面。完整轮廓必须位于终止平面之前；平行、在后方、穿过起始轮廓及过远条件拒绝。采用实际 BRep 与平面半空间的有限包围盒裁剪；体积由实际原生结果取得，不把轮廓中心到平面的距离当作统一深度。

到平面面采用用户明确选择的 **无界支撑平面**，不是有限修剪面域，也不支持到任意曲面。枚举只提供候选，加载后不自动选中面。选择保存文档、零件所属特征、资产、修订、指纹、全拓扑映射索引、种类和适配版本；原生再次验证。来源发生变化后冻结结果并要求明确重选，不按索引、位置或顺序延续。

到关联基准保存 C2 平面身份/修订和缓存；联合依赖图包含基准/草图来源及面所属特征。原生重算前刷新基准，C1 修改来源尺寸或终止基准时重算后继。终止参考实体保持可见；只有布尔目标是被消费的 `Feature.Inputs`。

## 创建、编辑与原子性

Ribbon 高级拉伸入口使用当前建模面板轮廓，或明确选择关联草图。保留解析曲线、Bézier、现有样条、孔与岛，关联草图变化时重建原始轮廓。高级拉伸及旧冻结曲线/孔岛拉伸从特征树进入独立编辑窗口；旧基础控件和拖动把手不能悄悄抹去高级配置。

en-US、zh-CN、ja-JP 窗口提供方向、距离、操作、终止、起始帧、关联基准和明确面选择，预览/确认/取消。不适用的终止字段不显示，失效预览不能确认；确认使用捕获的完整候选快照和会话 generation。关闭先取消/等待异步工作，再释放来源与临时资产。取消、失败和过期会话不修改原文档；提交可单步撤销/重做。

本批不组合拉伸和布尔的拓扑历史，明确返回 `HISTORY.UNSUPPORTED`。这允许在最终输出上精确重选，不声称已有原件到最终结果的完整边面对应。
