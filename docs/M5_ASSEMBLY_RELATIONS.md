# M5：装配关系五个大阶段

本轮连续实现五个大阶段，并在最后统一验收。这里的“约束”是具有稳定身份、可诊断状态和受限的刚体位姿操作；不宣称已实现完整机械配合求解器。

| 大阶段 | 交付与边界 |
| --- | --- |
| 文档内持久模型 | `AssemblyConstraintId`、精确实例路径、捕获时的定义 ID、局部点、目标距离、固定世界位姿、可选精确修订拓扑来源及启用状态写入文档。`document` MessagePack 节升到 v13，旧 v12 迁移成明确的空约束表；保存、撤销、恢复沿用现有事务。 |
| 固定实例 | 从所选实例捕获世界位姿。有效且启用的固定关系由文档验证守住；即使拓扑来源陈旧或锚点求解暂不支持，位姿变化仍会被拒绝。可显式禁用、移动、重新捕获，再启用。 |
| 点对重合与距离 | 选择参照实例和移动实例，支持各自定义坐标下的锚点。显式“调整”只平移第二个实例，保留旋转，并将世界坐标转换回其父装配局部坐标；无方向的正距离、共享父定义、移动实例包含参照实例，以及破坏其它已满足关系的操作均拒绝。未运行全局多约束求解。 |
| 失效诊断与明确重新指定 | 关系状态区分禁用、已满足、未满足、实例路径缺失、定义被替换、拓扑来源失效与拓扑锚点求解不支持。删除或替换实例后不自动猜测新路径；显式重新指定会重新捕获固定世界位姿。拓扑来源绑定只保留精确修订和诊断，不用未实现的面/轴配合算法伪造结果。 |
| 属性面板与恢复闭环 | 属性面板提供固定、原点重合、原点距离、目标值修改、单关系调整、启停、重新指定和删除。列表保留失效关系，便于用户处理；发布版桌面冒烟和强制终止恢复样本覆盖关系。 |

本阶段不包含同轴、角度、面贴合、完整多约束求解或外部零件链接。关系是文档内数据，不需要新的 OcctSharp 绑定；后续真正的面/轴配合须先验证消费端缺口，再决定是否扩充 OcctSharp。
