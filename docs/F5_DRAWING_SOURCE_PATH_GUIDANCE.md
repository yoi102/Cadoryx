## 行为

`cad_drawing inspect_sources` 先验证活动文档、文档身份及状态，再检查调用方提供的路径。路径必须包含文档根与完整实例槽链，并在当前文档中存在。缺失、空值、超长输入仍走原参数拒绝；旧身份、取消或已关闭文档仍先拒绝。

对路径格式或存在性失败，保留原错误文本，另外返回两个未执行的只读请求：`cad_inspect area=occurrences` 和 `cad_inspect area=bodies`。模型需读取 `occurrences.items[].path`，在同一定义中取得实际 body ID 和修订，再读取最新 `cad_status` 并自行提交完整请求。服务器不补路径、不选择实体或拓扑、不重绑，也不自动重试。合法完整路径仍进入原检查器；实体和修订错误以及检查器自身的失败不会被改成路径引导。

工具 schema 的 path 说明明确指向完整 `occurrences.items[].path`。原12工具的选择算法、8192上下文、1024输出、640/1280安全区、6000/2400工具结果及16工具轮保持。
