# Cadoryx 当前进度与剩余工作

更新：2026-09-30。本页是阅读当前进度的入口；[ROADMAP](ROADMAP.md)保留每阶段的范围与历史记录。下表的“完成”指该阶段**明确定义的功能和本机验收**，不表示整个三维 CAD 产品已经开发或发布完毕。

自动测试的覆盖率、统计边界和补测计划单列在[自动测试与覆盖率](TEST_COVERAGE.md)；该数字只针对 xUnit 进程加载的托管程序集，不代表 WPF 界面或原生内核覆盖率。

当前[快捷圆盘菜单](RADIAL_MENU.md)改为按住 Esc 下方的反引号键显示、松开关闭并执行所指动作；打开时光标移到圆心，受限桌面拒绝移动光标时圆盘移到现有光标位置。滚轮循环四页，圆盘下方显示 1–4 页码。中键拖动恢复平移，右键拖动恢复旋转，右键短点击菜单仍保留。Release 构建零警告、621/621 自动测试通过；发布版窗口冒烟通过键盘、滚轮、相机动作及捕获回归，截图 `artifacts/radial-debug-window4/radial-page-4.png` 已检查。最终桌面冒烟 `artifacts/radial-final-smoke` 也通过，两份绑定日志均为空。实体键鼠、混合 DPI 和 RDP 人工验收仍未执行。

随后修复光标位于圆盘内滚轮无效：Popup 是独立 HWND，旧路径只监听 OCCT 视口。现在圆盘 Popup、WPF 主窗口及视口收到的滚轮都路由到同一翻页处理。发布版窗口冒烟直接向三个 HWND 发送滚轮并通过四页循环检查，`artifacts/radial-wheel-window5` 为完整窗口通过记录；发布版桌面冒烟 `artifacts/radial-wheel-smoke` 也通过，两份绑定日志为空。真实物理滚轮仍待人工验收。

针对高分辨率滚轮翻页延迟和鼠标移动后重复翻页，本轮改为首次小增量立即响应，后续按同一手势的累计量计页；普通鼠标移动只更新扇区，不再重算页码。窗口冒烟代码补充小增量、反向滚动和移动后保持页面的回归场景；Release 全解决方案编译通过，零警告/错误，差异检查通过。依用户要求，本轮未运行测试或冒烟，真实鼠标与触控板仍待人工确认。

用户再次反馈真实滚轮仍有延迟或鼠标移动后跳页。检查发现旧方案仅覆盖三个已知 HWND，且页码变化缺少圆盘自身的显式重绘；250 毫秒间隔也可能拆开一个高分辨率滚动手势。现加入线程级物理滚轮消息入口、页码重绘请求，并将同向手势停顿阈值放宽至 500 毫秒；Debug 全解决方案编译零警告/错误。按用户要求未运行测试，真实设备交互仍需确认。

用户提供的 18.2 秒录屏证实上述修复仍未解决实际操作：约 13.83 秒页面到第 4 页，此后滚轮提示仍显示但页面保持第 4 页，约 16.0 秒才回到第 1 页。录屏无法显示原始 `WM_MOUSEWHEEL` 增量或内部页码，因此不能只凭画面判定是累计量还是绘制问题。用户明确要求保留上一版滚轮累计规则，问题聚焦在鼠标移动不应切页。最新修改恢复同向增量累计和 500 毫秒手势间隔，保留独立的修饰键变更事件；指针移动现在只更新扇区，不能触发页码变更。物理滚轮修复尚未人工复验。

针对“滚动后画面不变，移动鼠标才显示新页面”，本轮保留累计规则，合并页码与图标更新，并在 Render 优先级完成布局、显式刷新圆盘分层窗口；关闭时取消待执行刷新。新增 `--radial-smoke` 专项从三个 HWND 排队发送滚轮消息，在鼠标移动事件为零时直接采样屏幕页码像素，覆盖四页循环、小增量累计、反向及后续移动保持页码。Release 专项通过，`artifacts/radial-stationary-screen-smoke/radial-stationary-wheel.json` 记录每次观察到目标页约 41–54 毫秒（含采样开销），绑定日志为空。此次验证没有复现修复前的硬件现场，实体滚轮和触控板仍需人工复验。

针对切换输入法后 Esc 下方按键不再显示圆盘，触发条件已从美式布局的 `VK_OEM_3` 改为实体键扫描码 `0x29`，同时接入常规、系统及 IME 键消息；IME 吞掉松键消息导致取消后无法重新打开的状态也已处理。设置说明改为按实体键描述。最终 Release 构建零警告/错误；Debug 输出被正在运行的 Cadoryx 和 Visual Studio 锁定，复制资源时失败，未关闭用户窗口。按用户要求，本轮未运行测试；跨输入法实体键操作仍需在桌面实际确认。

Box/Cylinder 鼠标创建的高度阶段曾将上下拖动都取绝对值，导致向下也只沿正法向拉伸；现按拖动符号决定法向方向，负向时移动实体基点并保持正尺寸，适用于 XY/XZ/YZ 工作平面及网格吸附。已添加对应回归用例；按用户此前要求，本轮不运行测试，见[视口鼠标建模](VIEWPORT_CONSTRUCTION.md)。

早期中键圆盘菜单曾提供八扇区、Shift/Ctrl/Alt 实时切页及应用设置中的圆盘预览与逐槽图标拖放。该版本的 Release 构建零警告、603/603 自动测试和窗口冒烟通过；设置页截图为 `artifacts/radial-centering-desktop-smoke-final/metro-radial-settings.png`。触发方式现已由上文的反引号键方案替代。

命令面板本轮补齐[操作输出](COMMAND_AND_AGENT.md)：输入命令保留输入与结果/错误，界面和 AI 实际提交的文档命令记录名称，撤销/重做标明目标命令；保存、导出与主要视图操作也显示操作行。Release 构建零警告、604/604 自动测试与发布版桌面冒烟通过，WPF 绑定日志为空。

AI 工具随后补充文档、零件、实体、特征、图层、材质和当前选择的结构化分页查询；Box/Cylinder 增加精确目标零件及文档状态校验的结构化创建，返回新实体/特征/零件 ID。完整自动测试 615/615 通过，具体输入与剩余边界见[命令行与 AI Agent](COMMAND_AND_AGENT.md)；本轮未重跑真实提供方聊天与桌面交互。

针对装配重名实例，AI 又新增 `cad_select`：按完整实例路径、实体 ID 和几何修订选择，拒绝跨文档或过期状态；可用于后续聚焦、隐藏与隔离。此选择仅改变当前视图，不写入文档历史。最新完整自动测试 617/617 通过，验证见[命令行与 AI Agent](COMMAND_AND_AGENT.md)。

AI 图纸查询进一步补上单张图纸视图和尺寸的精确查询与分页；每张图纸视图上限为 128，摘要只内嵌前 50 个尺寸，完整尺寸列表可按 `sheetId` 分页读取。真实文档会话测试覆盖第 51 个尺寸、身份与错误图纸拒绝；最新 Release 完整覆盖率测试 618/618 通过，生产程序集行覆盖 67.0%、分支覆盖 66.2%。详见[命令行与 AI Agent](COMMAND_AND_AGENT.md)与[自动测试与覆盖率](TEST_COVERAGE.md)。

早期曾调整视口导航为右键拖动平移、Ctrl＋右键拖动旋转；右键短点击菜单仍在松开后显示。该版本的 Release 完整测试 619/619 和发布版窗口冒烟通过；当前输入映射已恢复为中键平移、右键旋转，见[视图导航](VIEW_NAVIGATION.md)。该轮仅验证直接提交路径，当时尚未复现用户点击未提交预览的异常；后续按下段处理。

后续截图定位了圆柱错误的具体触发方式：最后一次点击留下了未提交的预览，再点击青绿色预览会把预览 BodyId 送入正式选择，属性面板从当前文档字典取体时抛出 `KeyNotFoundException`；Esc 随后清除预览，所以圆柱消失。现已让鼠标绘制的 Box/Cylinder 在第三次点击后自动执行预览计算并提交，并阻止未提交预览进入正式选择。发布版窗口回归覆盖预览点击、三次点击提交、实体选择与 Esc 后实体保留；具体结果见[视口鼠标建模](VIEWPORT_CONSTRUCTION.md)。

选中实例的旧球手柄已升级为三模式原生操纵器：右键切换移动、旋转、缩放，当前模式单独显示；操纵器在实体前显示，镜头缩放时保持屏幕尺寸，并随拖动预览移动。移动和旋转提交装配局部放置，缩放仅对唯一使用的 Box/Cylinder 特征按几何中心等比修改。最新 Release 621/621 自动测试、发布版桌面和窗口冒烟通过，旋转／缩放保存重开与撤销已覆盖；独立 OcctSharp NuGet 探针 34/34 场景、62/62 原生 DLL 通过。见[M12 交互与性能](M12_INTERACTION_AND_PERFORMANCE.md)。

## 还没取得的验证证据

- **环境**：两台不同 DPI 显示器之间的实际拖动/浮动、RDP 断开重连、多 GPU/新 Windows 环境、数小时资源和交互趋势。单屏 96 DPI 的短时循环不覆盖这些场景。
- **文件系统**：真实磁盘满、断电及网络文件系统。已通过的确定性故障注入和进程强制终止恢复不等同于介质故障。
- **互操作**：更多外部 CAD 厂商的 STEP/IGES 样本，以及来源文件中高级装配元数据、完整面样式/PMI 的对照检查。IGES 曲面导出的实体语义损失已有诊断，尚未消除。
- **发布**：全新机器上的安装器与依赖核对、签名、公开包/软件发布及外部 CI。M13 新增本机 MSI 安装目录运行与卸载证据；它不替代外部机器结果。
