# D5 有限曲面终止

2026-10-04。继续已授权 A–F 的 G07；G 实机/安装/交付暂缓。D1 的到平面面仍明确使用无界支撑平面。本批增加明确原始有限曲面作为终止参考，不能将一个成功的原生 Until 调用直接当作满足有限面域和方向语义。

先使用当前锁定 SDK 的 `LimitedFeaturePlan` 做独立前提试验：完整平面、过小的平面面域、下半球面、下半圆柱面。原生质量积分必须符合独立解析体积；从输出完整终止盖面与原始选面做精确 Common 面积覆盖核对。原生算法对平面可能使用无界支撑面，完整盖面超出作者有限修剪面时应用必须拒绝，不能偷偷放大边界。

应用需保存文档/零件、目标及明确起始支撑面、完整终止面选择、资产/修订/指纹/适配版本和显式方向。先接入加料/去料的原生支撑面路径；新实体和任意自由起始平面保持独立待办。正反方向、起始面一致性、完整轮廓及孔岛、多次相交/切触/周期缝/起始面穿过终止面都需要明确守卫和原生证明，不能用少量采样声称完整有限域成功。

原始输出盖面、完整拓扑和材料变化必须检查；原生失败不换成一个看似近似的 Boolean 结果。来源变化冻结并显式重选；历史只能使用原生完整源路径，分裂/合并/多路径拒绝猜测。后续接入原子重算、参数及后继图纸、存储独立迁移、三语言完整生产控件、终端和 Agent，使用同冻结载荷验收。

本页是实施契约。SDK 前提、应用实现、窗口、完整回归和真实输入分别记录，不是 D 或 A–F 完成声明。B14 全量继续独立收取；B 混合圆形/椭圆/自由曲线关系、非端点 G2、偏移连接，以及 A 性能/输入、E 曲面移动/替换/缺失历史、F 制造规则/外部元数据/供应商失败仍保留。
