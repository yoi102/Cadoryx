# 视图导航与 Ribbon 布局

## 操作入口

`MainRibbonView` 分为首页、建模、草图、视图四页；每页采用两行纯图标按钮与下方分组标题，窄窗口可横向滚动。按钮使用 Material Design PackIcon，六个正交方向使用突出对应面的 Path 图标；名称移至多语言 Tooltip，并提供无障碍名称。双视口开关也采用图标，边框和底色表示开启状态；禁用按钮仍可查看提示。首页保留文件、撤销/重做、文档资源和文档设置；建模页集中基础形体、轮廓特征、局部建模及历史查询；草图页集中草图编辑与关联特征。

视图页集中“聚焦选择”“适应窗口”、七个标准方向（前/后/左/右/顶/底/轴测）、显示模式和双视口开关。Ribbon 不提供模型、属性、消息工具面板的控制。移除文档视口及单个视口上方重复工具条。视图命令作用于当前文档最后交互的视口；关闭双视口时回到主视口。

隔离选择、临时隐藏、恢复显示位于每个原生视口的右键菜单。对当前选择操作，不因右键单击而替换选择。无选择时禁用隔离和隐藏，无临时过滤时禁用恢复显示；这些状态不写入文件或撤销历史。

## 动画与鼠标契约

- 聚焦、适应窗口和标准方向共用 320ms 平滑相机动画；插值包含目标中心、方向、距离与缩放。纯缩放变化也播放动画。
- 适应窗口直接从当前可见实例的世界包围盒计算目标相机，不先执行一次原生 FitAll，避免首帧跳变；网格和坐标轴不扩大模型范围。空视图不改变相机。
- 连续请求从当前帧重新开始，鼠标导航/滚轮、视口关闭和重建取消在途动画。初次加载的即时适应保留。
- 右键按下只启动候选手势；容许系统拖动阈值以内的轻微抖动，在松开并释放原生捕获后打开 WPF 菜单。超出阈值即转为导航，即使回到按下坐标也不弹菜单。
- 中键拖动平移视图，右键拖动旋转视图；右键短点击仍在松开时显示菜单。左键选择，视口滚轮缩放。按住 Esc 下方的实体键显示快捷圆盘（美式键盘为反引号键）；菜单打开时滚轮改为切换四页，松键关闭圆盘并执行当前指向的动作。识别实体键扫描码，不依赖输入法虚拟键值。
- Esc、捕获丢失、失焦、组合按键、多键操作和滚轮取消菜单候选；迟到的右键释放不弹菜单。原生 WM_CONTEXTMENU 被抑制，避免系统再次弹出。
- 菜单定位由屏幕像素转换为所属视口的 WPF 坐标，视口销毁时关闭菜单。双视口右键交互会激活对应视口。
