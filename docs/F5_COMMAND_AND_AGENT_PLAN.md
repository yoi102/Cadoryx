## 状态与取消

所有 AI 修改与选择均绑定实际 `DocumentId`、`StateId`；输入还需原始对象 ID、必要的几何或草图 revision 和完整实例路径。读取返回分页、实际身份和明确单位。排队期间换文档、关闭、回滚、旧状态或资产失效都拒绝执行；执行期间已有的代际与生命周期守卫继续生效。不能通过名称、坐标相似或自编的索引猜测拓扑。

终端执行接收取消令牌并传递到生产命令。取消必须发生在提交前才回退；提交成功后的取消不能被报告为“没有修改”。撤销、重做及视图选择等同步操作也应在执行前检查取消，并返回实际结果。AI 的终端入口需具备相同状态守卫，不能用旧会话中的命令绕过结构化编辑检查。

## 查询与常用建模

1. 参数、表达式、驱动目标、求值结果、关联基准及特征时间线查询；分页顺序稳定，枚举和配方语义与生产类型一致。
2. 参数新增、修改、删除及重算；必要的原子依赖检查与单位校验。关联基准按精确作者输入创建和编辑，失败保持旧状态。
3. 常用建模动作覆盖草图加去料拉伸、旋转、Boolean、孔、镜像和阵列，再接扫掠、放样、抽壳及拔模。工具须提供完整且可复现的输入，复用已有配方、合法几何检查、资产租约、历史及工程图更新。
4. 特征抑制、恢复、编辑、合法重排、回滚和返回末端；不能把回滚预览误作作者状态。原始后继及历史身份守卫保持。
5. 文档和工程图操作复用现有生产命令，交换/报告工具返回实际文件结果及观测边界；不因报告生成成功就宣布兼容性或制造标准符合性。

终端每条指令和 AI 每个动作均有明确语法、有限输入预算及实际返回身份。若一个动作产生多个对象，应列出所有创建 ID；没有实际变更时不能虚报创建成功。用户可通过同一文档历史撤销和重做。
