# 工作网格与视口鼠标建模

文档视口默认使用竖直天空渐变：顶部深蓝 `#578EC5`、底部浅蓝 `#DCECF8`。在 Ribbon「视图」或底部状态栏打开「文档设置」；窗口按 Direct2dCad 的布局，在左侧选择“视口／网格与吸附／原点与坐标轴／单位与精度”，右侧编辑设置，底部统一提供重置、确定、应用和取消。渐变上下两色可分别选取。更改只属于当前文档，可撤销／重做，保存到 `.cadoryx` 的 document v12 节；网格、原点、工作平面与背景不会改变既有几何或交换文件。

模型世界原点固定为 `(0,0,0)`，默认显示 20 mm 彩色 XYZ 坐标轴，X 红、Y 绿、Z 蓝，正方向带箭头；还可选柔和单色轴线或仅原点三向交叉标记，并可隐藏、设置尺寸 1–1000 mm。左下角方向指示器仍用于辨认相机方向。原点显示与网格分开管理，只在当前视口绘制，排除模型选择、`FitAll` 范围、资产和 STEP/IGES/STL 导出；保存、重开、撤销和重做都按文档设置恢复。旧 document v10 迁移到默认样式。

视口默认显示 XY 工作网格（Z=0，间距 10 mm）。底部状态栏按当前文档提供显示开关、间距（0.1–1000 mm，可直接输入并回车或移开焦点提交）和创建点吸附开关，交互参考 Direct2dCad 的当前编辑文档网格选项。三个值属于 `DocumentSettings.Grid`，修改通过文档命令提交，可以撤销／重做，并随 `.cadoryx` 保存、重开和恢复；不同文档互不影响。旧文件迁移为显示、10 mm、不吸附。工作网格的边线仍是视口绘制，不作为几何体、模型树对象或 STEP/IGES/STL 导出内容；缩放到模型时排除网格范围。

M2-V6 在“网格与吸附”页提供 XY、XZ、YZ 三种正交工作平面，以及沿所选平面法向的偏移（±1,000,000 mm）。XY 的局部 U/V/N 对应世界 X/Y/Z；XZ 对应 X/−Z/Y；YZ 对应 Y/Z/X，均为右手系。网格绘制、相机射线求交、平面内吸附和鼠标创建共用同一文档设置。Box、Cylinder 与冻结轮廓的 Extrude/Revolve 在鼠标锚点使用平面的旋转与世界坐标；Box 反向拖动按平面局部坐标取最小角。关联草图仍保留其原有放置。切换平面会取消当前未完成的鼠标手势，不改变已确认的形体。旧 document v11→v12 显式迁移为 XY、偏移 0；偏移和方向可撤销、保存及重开。原点坐标轴继续固定在世界原点，与偏移工作平面互不影响。自由旋转工作平面、面附着、轴向手柄与尺寸标注仍需单独实现。

从 Ribbon 选择 Box、Cylinder、Extrude 或 Revolve，或者在建模参数面板选择工具后点击“在视口中绘制”，即可进入鼠标创建状态。Box 和 Cylinder：点击当前工作平面起点，移动鼠标并点击确定矩形底面或圆柱半径，再上下移动并点击确定高度。高度阶段向上拖动沿工作平面正法向生成，向下拖动沿负法向生成；尺寸保持正数，向下时将实体位置移至基准面另一侧，切换方向不会累积位置偏移。网格吸附对两个方向都生效。移动时 Box／Cylinder 显示半透明原生形体，数值面板同步更新；第三次点击执行隔离预览计算并自动提交为可撤销的文档命令，之后可直接点击选择该实体。计算失败时保留错误提示，不提交半成品。反向拖动矩形会将位置移动到平面局部最小角，使尺寸保持正数。

Extrude 和 Revolve：点击确定冻结轮廓的位置（关联草图保留自身位置），移动鼠标决定拉伸距离或旋转角度，同时显示半透明 OCCT 形体；最后点击进入既有隔离预览，再确认提交。移动中的形体仅是视口辅助展示，不分配文档资产、不修改特征图或保存点。轮廓创建与草图关联仍使用现有面板和草图编辑器；无效或未选中的轮廓暂不显示形体，不终止鼠标手势。未提交的预览不可作为正式文档实体选中；Esc 或“取消”放弃鼠标创建与未提交预览，但不会删除已经提交的 Box/Cylinder。中途文档改变也会退出创建状态。数值面板仍可手动预览／确认／取消，并沿用撤销链路。

拾取位置由 OcctSharp 的当前相机射线与所选工作平面求交；视线与平面平行时 Box／Cylinder 会提示切换可见该平面的视角，不猜测三维位置。网格吸附作用于局部 U/V 创建点和 Box／Cylinder 高度；数值框仍可精确覆盖结果。圆柱“尺寸 X”现有字段代表半径。移动阶段的 Extrude／Revolve 形体使用与内核相同的轮廓面、拉伸／旋转及放置规则，按现有约 40 ms 视口节流更新；最后点击仍由隔离内核执行权威预览。自由旋转工作平面、轴向拖拽手柄与尺寸标注留待后续阶段。

## 验证

M2-V7 的“视图”按钮切换前／顶／右／轴测等标准方向时使用约 320 ms 平滑相机转动。目标方向由现有 OCCT 标准视图求得，转动中插值完整相机状态，结束时恢复精确目标；快速连续点击从当前帧开始下一段。鼠标拖动／滚轮、FitAll 和文档视口销毁会停止动画，保留当时的相机位置。动画是视口导航行为，不进入文档设置、撤销链或交换文件。

单元测试覆盖多文档隔离、撤销／重做、范围校验、保存重开、旧 document v7/v11 的默认值迁移，以及鼠标三段尺寸、不同平面的 Box/Cylinder/Extrude/Revolve 放置及形体配方；窗口冒烟检查状态栏绑定、原生网格可见／隐藏、XZ/YZ 偏移工作平面射线拾取与 YZ Box 形体、移动中的拉伸／旋转形体。最新发布版窗口回归还在空白文档验证：点击未提交圆柱预览不会产生悬空选择，第三次点击提交圆柱，随后点击可选中实体，按 Esc 后已提交实体仍在。完整验证日志与限制见 [路线图](ROADMAP.md)。窗口冒烟使用投影坐标驱动真实 OCCT 视口，不代表物理鼠标、混合 DPI/RDP 或长时间交互验收。
