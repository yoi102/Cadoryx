# M8 后续交互改进：实体尺寸手柄

## 范围

在属性面板或模型树进入现有特征编辑后，视口显示橙色 3D 尺寸手柄：Box 的 X/Y/Z，Cylinder 的半径/高度，Extrude 的距离。按住手柄沿对应的世界轴拖动，屏幕位移投影到该轴；已有特征放置旋转和装配实例变换均参与世界轴与手柄位置计算。开启文档网格吸附时使用文档格距。与视线几乎重合而无法可靠投影的轴不开始拖动。

拖动只修改当前编辑器候选和辅助形体，不写入文档。鼠标松开后沿用 `RecomputeCommand` 的预览／确认，按“确认”才提交，可撤销／重做。Esc、捕获丢失、取消或切换操作恢复拖动前参数并清理辅助形体。只对可见且无歧义的实体实例显示手柄：一个结果有多个实例时要求当前选择精确指定实例；锁定／只读／过期特征没有手柄。

本项不新增文档格式字段，旧文件可原样编辑。Revolve 角度与沿复杂拓扑面的局部手柄另列后续能力；这里不声称通用 3D 操作器、拓扑命名或任意多实例同时编辑。

后续 M12 已补 Revolve 角度与装配实例 XYZ 拖动；以 [M12 交互与性能](M12_INTERACTION_AND_PERFORMANCE.md) 的实现和验收范围为准。
