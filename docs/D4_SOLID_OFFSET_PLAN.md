# D4：整体实体偏移实施契约

更新：2026-10-04。承接 [D3 抽壳/拔模](D3_SHELL_DRAFT.md)，属于用户已授权的 A–F 实体建模工作。第七批实机、安装及交付仍暂缓；本批不替代 D1 任意曲面终止和 E 缺失算法历史。

## 契约

整体偏移只消费用户选定的当前单实体特征输出。距离为带符号的毫米：正值向外、负值向内；绝对值须大于 0.000001 且不超过 100000。零值、非有限值、失效来源、锁层、未解除外部部件及塌缩/多实体结果拒绝，不降级为面模型。

锁定 `8.0.1-preview.31.cadoryx.curve-inspection.8` 的公开 `Shape.Offset`。独立消费者已证明盒、圆柱、球的内/外六个正例和三个塌缩反例，9/9 通过，62 个包内原生 DLL 哈希与独立目录加载来源核对通过；见 `artifacts/d4-offset-sdk-2`。它只证明这些样本和 SDK 前提，不能代替应用验收或任意几何成功保证。

源和结果都必须为一个 exact 有效实体、正体积且原生全局自干涉清晰。体积变化符合作者方向，并以源/结果 common 的体积核对包含关系。原始 BRep 不得被修改。原生构造、后继重算及关联图纸更新在一个候选内，失败、取消和晚到结果不改文档/历史；所有资产必须释放。

这是完整实体的依赖，不依赖源面选择。上游有效实体改变时自动刷新其源几何并重算；编辑不能偷换来源身份。原始到最终拓扑历史目前不可用，明确诊断，不猜测索引或几何近似续接；后继可以显式选择最终边/面，上游再变时旧选择失效。实体颜色、材料、图层、可见性保留，无法证明的原逐面样式不继承。

## 应用链与验收

1. 带符号配方/几何/创建与重算命令、参数 Distance、抑制恢复、原子失败和撤销重做。
2. Ribbon 和完整特征树编辑，复用生产窗口，只显示整体源和带符号偏移控件；三语言预览/确认/取消/关闭，异步原生生命周期和状态变化。
3. document40/features36、能力 `cadoryx.solid-offset.1`，保持每个旧迁移独立，旧 schema 夹带新配方和畸形 companion 拒绝；保存重开再编辑。
4. `cad_model` 的 `solid_offset` 作者类型，精确 `{featureId, revision}` 输入，signed distance；检查查询可复制的完整编辑请求、无变化编辑和旧状态拒绝。
5. 内外、旋转、曲面、贯通孔凹实体、塌缩；C1 驱动工程图、原生文件/STEP、导入逐面色边界以及最终选边后继。
6. 最终候选 Release 构建、专项/全量及同候选窗口，程序集哈希与证据绑定。自动化控件、原生视口、物理指针和外部 CAD 分开报告。

状态和本轮证据见 [实施记录](D4_SOLID_OFFSET.md)。整个 A–F 的余项见 [总跟踪](AF_IMPLEMENTATION_TRACKER.md)。
