# 鼠标中键圆盘菜单

在 3D 视口按住鼠标中键会打开八扇区圆盘。移动指针到某个扇区后松开中键执行；在中心区域松开不会执行。菜单打开期间按住 `Shift`、`Ctrl` 或 `Alt` 会即时切换到对应页面，松开修饰键返回中键页面；同时按下时优先级为 Shift、Ctrl、Alt。松开 `Alt` 只切回普通中键页，菜单保持打开，直到松开中键。`Esc`、真正切换到其他应用、切换文档或关闭视口都会取消菜单。

在“应用设置 → 圆盘菜单”中可启用/关闭菜单。左侧切换中键、Shift、Ctrl、Alt 四页；右侧圆盘可将下方图标拖入八个位置，也可将一个扇区拖到另一扇区复制操作，拖到圆心清空。图标悬停提示显示动作名称。位置 1 位于正上方，随后顺时针排列。设置属于应用，不写入 CAD 文档；设置窗口取消不保存，重置会恢复默认页面。关闭菜单后，中键仍由原来的视口导航处理。

动作调用已有命令及其 `CanExecute`：适应窗口、聚焦选择、顶/前/右/轴测、撤销/重做、保存、隔离/隐藏/恢复显示、新建草图、Box 和 Cylinder。不可执行的动作（例如未选中实体时聚焦选择）不会改变文档。视图动作使用已有相机动画；菜单自身不改变保存点。菜单窗口使用屏幕坐标更新选区，以适应多显示器和 DPI 下弹窗自动挪位。

实现边界：原生 `OcctViewportHost` 接管启用状态下的中键按下、移动、修饰键与松开；弹窗是不可命中的 WPF Popup。Alt 松开可能引发同进程的短暂失焦和捕获变化，手势会保留并重新捕获中键；真正切到其他进程仍会取消。中键手势拥有独立输入状态，取消后直到物理松开前都不会把“孤立的抬起”转送给 OCCT。运行时圆心文字垂直居中，设置页八个槽位按相同半径和 45° 间隔排列。设置 JSON 旧版本缺少 `RadialMenu` 时补默认值，非法动作归为空，长度缺项补默认值。
