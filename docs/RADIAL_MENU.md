# 视口快捷圆盘菜单

在 3D 视口按住 Esc 下方的实体键（美式键盘为 `，日式键盘为半角/全角）打开八扇区圆盘，指针会移到圆心。移动到扇区后松开该键执行动作；在圆心松开则不执行。滚轮向下依次切到第 2、3、4 页，再回到第 1 页；向上反向切换。高分辨率滚轮的首次小增量立即切页，同一滚动手势的后续增量按累计的 120 单位计算。鼠标移动只更新扇区选择，不改页码。圆盘下方显示 1–4 页码并突出当前页。Shift、Ctrl、Alt 也能临时切页，松开修饰键返回第 1 页；滚轮切页后，本次打开期间以滚轮所选页面为准。松开 Alt 不会关闭圆盘。Esc、真正切换到其他应用、切换文档或关闭视口会取消圆盘。Ctrl 加该键保留给命令行快捷键。

在“应用设置 → 圆盘菜单”中可启用/关闭菜单。左侧切换第 1–4 页；右侧圆盘可将下方图标拖入八个位置，也可将一个扇区拖到另一扇区复制操作，拖到圆心清空。图标悬停提示显示动作名称。位置 1 位于正上方，随后顺时针排列。设置属于应用，不写入 CAD 文档；设置窗口取消不保存，重置会恢复默认页面。中键拖动用于平移视图，右键拖动用于旋转视图。

动作调用已有命令及其 `CanExecute`：适应窗口、聚焦选择、顶/前/右/轴测、撤销/重做、保存、隔离/隐藏/恢复显示、新建草图、Box 和 Cylinder。不可执行的动作（例如未选中实体时聚焦选择）不会改变文档。视图动作使用已有相机动画；菜单自身不改变保存点。菜单窗口使用屏幕坐标更新选区，以适应多显示器和 DPI 下弹窗自动挪位。

实现边界：原生 `OcctViewportHost` 与所在 WPF 窗口按扫描码 `0x29` 识别该实体键，兼容输入法产生的键盘消息；不再依赖随布局变化的虚拟键值 `VK_OEM_3`。视口只用指针移动更新扇区，用独立的修饰键事件切换页面。弹窗是独立 HWND 的 WPF Popup；物理滚轮消息在 WPF 线程分发前统一截取，窗口钩子仍处理直接发送到 Popup、视口或宿主窗口的消息。页码和图标一起更新，随后以 Render 优先级完成布局并对弹窗自身调用 `RedrawWindow`，显式刷新分层窗口的显示表面；连续翻页合并待执行刷新，关闭弹窗时取消该任务。滚轮同向增量连续累计；反向或停顿 500 毫秒才开启新手势。系统拒绝移动光标时，弹窗改以实际光标为圆心。Alt 松开可能引发同进程的短暂失焦和捕获变化，手势会保留并重新捕获指针；真正切到其他进程仍会取消。运行时圆心文字垂直居中，设置页八个槽位按相同半径和 45° 间隔排列。设置 JSON 旧版本缺少 `RadialMenu` 时补默认值，非法动作归为空，长度缺项补默认值。

定向验收：运行 `Cadoryx.wpf.exe --radial-smoke <输出目录>`。检查向 Popup、原生视口、WPF 宿主窗口排队发送滚轮消息，同时维持按键重复消息；指针不移动，直接读取屏幕上四个页码指示器的像素，要求 400 毫秒内显示目标页。该检查不调用 `UpdateLayout`、`RenderTargetBitmap` 或 `PrintWindow` 来促使页面绘制。另覆盖后续鼠标移动不改页、小增量累计、反向切页、捕获、Esc 和 IME 按键；需要可见且未被遮挡的桌面。2026-09-30 本机 Release 专项通过，记录在 `artifacts/radial-stationary-screen-smoke`，绑定日志为空；队列消息检查不等于实体鼠标或触控板人工验收。
