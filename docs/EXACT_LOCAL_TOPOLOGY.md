# 局部结果的精确拓扑选择与倒角（M4-T3-B2d1–d4）

本阶段将连续局部建模扩展到生成边，并允许在局部结果上创建等距或双距离倒角。用户在局部特征窗口的原生视口拾取边；倒角再切换到“面”并拾取支撑面。窗口仍以预览、确认和取消提交为边界。模型树与属性面板可编辑已绑定圆角/倒角的参数；上游形体变化时，该特征和后继冻结，从当前上游结果显式重选后才重新计算。

## 四个有界阶段

1. **B2d1 — 精确拾取**：OcctSharp 新增 `RepairSnapshot.FindTopologyIndex(source, picked)`，在 Viewer 所显示的原始 BRep 上查询 `TopExp::MapShapes` 的零基完整索引。`RepairSnapshot.Create` 会深拷贝形体，因而不能对它的子形状与 Viewer 命中做 `IsSame` 比较。Cadoryx 只接受唯一命中、当前文档/特征/资产与正确边/面类型。
2. **B2d2 — 生成边绑定**：`ExactTopologySelection` 将文档、目标特征、几何修订、资产 SHA-256、完整拓扑指纹、索引、类型及适配器版本一起保存。每次命令准备和同资产重算时重新打开 BRep 核对；上游修订变化不寻找最近边，也不自动迁移索引。原 Box 边仍可用既有唯一历史路径。
3. **B2d3 — 结果倒角**：用户明确选择同一精确 BRep 上的支撑面；`HistoryChamferRecipe` 使用现有 OcctSharp `ContourChamferRecipe`，支持等距和双距离。OCCT 判定面是否邻接及算法是否可行，失败不提交文档。连续圆角也可直接使用精确选择的生成边。
4. **B2d4 — 编辑、重选和文件**：模型树/属性打开统一 `MetroWindow`；冻结的绑定特征展示当前上游结果，重选边与倒角支撑面后由 `RebindExactLocalFeatureCommand` 原子重算后继。`features` v10、`feature-bindings` v2，旧 v9/v1 显式迁移；写出器 0.4.16。坏指纹、错误资产或类型拒绝，撤销/重做和保存重开保留精确绑定。

## 安全边界

完整拓扑索引只是**该资产与修订的局部地址**，不是跨重算的语义名称。选择记录没有源子形状的永久名字；更换上游结果后需要用户重新拾取。文件读取不启动 OCCT，只校验结构；预览、重算或重选时才重新打开资产验证真实指纹与索引。一次操作只绑定一条边；倒角只绑定一个明确支撑面。跨特征自动拓扑命名、拆分/合并后的自动选择、多边连续局部结果、装配实例级编辑和大模型性能仍另行验收。

锁定的本地 OcctSharp 配对包是 `8.0.1-preview.28.cadoryx.topology.1`；新增的是缺失的原始形体完整拓扑索引查询，其余圆角、倒角、历史和 Viewer 接口复用已有包能力。包尚未公开发布。验证证据以 ROADMAP 的本阶段记录为准。
