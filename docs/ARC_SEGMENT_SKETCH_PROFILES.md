# M4-S3y–ad：三点圆弧闭合区域

这一组六项交付一个范围明确、可编辑并可精确拉伸的草图圆弧区域。它由三点定义的有向圆弧和隐式闭合弦组成；隐式弦显示为点线，不额外占用草图直线 ID。圆弧可为小于整圆的优弧或劣弧。端点、中点各有稳定点 ID，圆弧自身有稳定 ID。

| 阶段 | 能力 |
| --- | --- |
| M4-S3y | 草图三点圆弧实体、精确几何、退化拒绝和构造状态 |
| M4-S3z | 编辑器三次点击绘制、预览、拾取、点拖动与撤销/重做 |
| M4-S3aa | 非构造圆弧区域进入关联拉伸的轮廓列表 |
| M4-S3ab | OcctSharp 曲线链和面生成精确圆弧实体，支持原有 STEP/IGES/STL 导出 |
| M4-S3ac | 以 SketchId、Revision、ArcId 关联重算；点变更和失败整体回退 |
| M4-S3ad | sketches v4、features v14 持久化、旧版迁移与恢复 |

绘制时依次点击起点、弧上中点、终点；可以捕捉现有点。选择工具后点击草图点可移动定义点。起点、中点、终点重复或共线时会拒绝改动。关联拉伸的缓存必须和草图上的三点一致；旧文件中伪装成新版圆弧字段会被迁移规则拒绝。

写出器版本为 0.4.21，`sketches` v4 在 Key(9) 保存圆弧实体，`features` v14 在草图引用 Key(6) 保存 ArcId，并以 `extrude-arc` 配方保存冻结的三点几何。本阶段只支持单条圆弧加其闭合弦形成的拉伸区域。任意直线/圆弧混合闭环、圆弧孔、带孔旋转、样条及嵌套岛屿继续列在路线图中。独立包探针确认 OcctSharp 已有圆弧、闭合曲线链和精确建面 API，无须新增上游封装。
