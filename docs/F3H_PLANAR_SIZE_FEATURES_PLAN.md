# F3h：平行平面尺寸特征与中面制造基准

更新：2026-10-03。A–F已授权，G实机、安装及交付暂缓。本页原计划现已完成有界应用契约，最终范围为完整直线多边形棱柱外部厚度和完整矩形贯通槽宽；不是任意两平面。28专项、1683全量、Release0/0、八同发布窗口及33截图/15矢量PDF验证通过，详见[F3h实施记录](F3H_PLANAR_SIZE_FEATURES.md)。下文保留原计划顺序。

当前制造尺寸证据仅覆盖完整有限圆柱壁。单个PlaneFace分类不能证明板厚、槽宽或尺寸中面，不能直接把表面基准改称尺寸中面。下一项以用户明确选择的一对原始有限平面为来源，分别验证外部厚度和内部宽度；两面均绑定同文档、实例、定义、当前Body/Feature、修订、资产、指纹和原始完整定位，不从最近面或包围盒推断另一面。

1. 先用锁定NuGet独立消费者证明必要的有限域、邻接、实体内外及平面检查能力。首批以完整直棱柱、平面板厚和贯通直槽为样本，补旋转/STEP、面域不重合、斜面、台阶、缺口、多实体和薄退化反例。若不能取得完整证明，明确拒绝该几何，不能用抽样点代替整个有限域。
2. 两面必须平行、具有有限且非退化的边界，证明其共同有效范围、恒定间距、材料侧及连接边界。每个面和证明槽由原始拓扑邻接取得；尺寸及中面从精确解析平面计算，不抄写Box/Extrusion设计参数。外部厚度与内部槽宽使用不同材料方向规则。
3. 增加独立平面尺寸证明和解析器，明确与现有圆柱尺寸证据的类型关系。保存两面、方向、宽度、中面、内外类型和有限域/邻接见证；两处附着均保存作者来源，不只验证主附着或把第二面索引放在未经核验的缓存中。
4. 制造基准增加明确的尺寸中面类型；公差目标增加中面，非直径容差域和材料条件按受支持规则消费完整尺寸证明。圆柱轴、平面表面、中面分别约束，禁止用直径符号标普通中面，禁止把不同尺寸类型的共同基准混作同一种轴系统。完整标准合规与实际测量仍分列。
5. 重选视图来源时，两面各自沿唯一已核验原生历史延续，必须到达同一当前实体，随后重新检查完整平面尺寸；任何一面分裂、合并、删除、改变修订或证据不足均保留旧证明并标失效。显式重选基准仍使依赖框失效，不能自动确认。
6. drawings采用独立版本和必需能力，新增数字键只追加，不重排旧字段。迁移保留已有圆柱、孔、作者来源与布局；旧版夹带新字段（包括nil/空数组）拒绝。有效尺寸证明保存/加载逐项原生核验，无解析器拒绝，失败保存不替换原文件。
7. 接入生产工程图的两次原始面选择、类型/尺寸/中面说明、取消/替换/关闭与晚到结果守卫。WPF/PDF共用原始中面引出线和已有矢量控制框；模板应用保持两处作者来源、ID与证明。
8. 完成核心事务、同类型伪造、第二面身份/有限域变化、撤销、资产归零、保存重开及原生消费者检查，再固定发布核对全量、相关窗口、三语言截图与单页矢量PDF。自动化控件、物理输入、外部CAD与实纸证据继续分列。
