# M4-S3：二次 Bézier 与单层岛屿

本轮连续交付三个大阶段，全部实现后统一验证：

| 大阶段 | 交付范围 |
| --- | --- |
| 二次 Bézier 区域 | 三次点击绘制起点、控制点和终点；点拖动、构造状态、撤销/重做、草图求解与修订保存。曲线加隐式弦形成无孔区域，使用 OcctSharp 原生 Bézier 曲线链精确拉伸、关联重算及 STEP/IGES/STL 导出。只接受非共线三点，保证简单封闭区域。 |
| 直线轮廓孔内岛屿 | 已明确选择的孔内，可选择闭合直线多边形岛屿。岛屿必须严格位于唯一一个孔内，不能碰触或彼此嵌套；与主体分别精确拉伸为复合实体。稳定有序实体 ID 驱动编辑、重算、文件恢复。 |
| 圆与混合曲线孔内岛屿 | 相同的单层规则扩展到圆岛屿、混合直线／圆弧岛屿及圆／多边形／混合曲线孔。建模面板随孔选择列出合法岛屿候选，错误组合在预览前拒绝；恢复种子核对曲线孔内岛屿。 |

岛屿是孔内独立实体，结果可为 `BodyKind.Compound`；它与外轮廓不自动相连。当前只支持一层岛屿，不递归定义岛中孔、多层嵌套或多零件分配。二次 Bézier 是有一个控制点的特定样条区域，并不等同于任意 B 样条闭环；任意混合样条链、样条孔、样条约束和多层嵌套仍列后续任务。
