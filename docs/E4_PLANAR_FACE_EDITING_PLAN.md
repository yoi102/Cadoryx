# E4：有限平面区域推拉及删除面修补

更新：2026-10-04。属于 [A–F跟踪](AF_IMPLEMENTATION_TRACKER.md) 的G15/G17；本文定义的本地应用契约已实现并验证，见[实施记录](E4_PLANAR_FACE_EDITING.md)。95专项、347联合、2211全量、Release0/0、同冻结七窗口及程序集/截图审计通过；整个A–F继续，第七批G继续暂缓。

## 明确的几何语义

平面区域推拉消费当前完整单实体上的一个exact平面Face，以及带符号毫米距离。正值沿原生确认的实体外法向扩展该有限面域，负值从该域向内去料；孔和面域边界全部来自原生Face，不以包围盒、无限平面或显示多边形代替。该工具表达有限区域加/去料；斜邻面不会被宣称为自动移动或延伸到一个新的无限平面。曲面移动、旋转和替换面须继续按几何类型建立独立契约。

删除面修补消费用户明确选中的当前exact面集合，使用native defeaturing重建邻接；不接受直接删掉Face后留下开放壳作为成功。删除孔壁或特征表面必须由完整单实体、exact有效及自干涉检查确认。算法未完成、部分结果、断开或零实体都拒绝，保留原文档。

## 实施要求

1. 先用独立NuGet消费者证明盒/旋转盒、有孔平面有限域的内外推拉与孔壁修补，核对解析体积、STEP重读、源指纹和算法历史。受限/失败样本原样保留，不调整预期迎合结果。
2. 配方保存完整来源、exact面和明确native法向证据；多个面修补需无重复、无跨源。旧来源变化先冻结，用户明确重选后恢复，不靠坐标近似重绑。
3. 接入原子命令、C1距离驱动、撤销/重做、后继、抑制、native存储复证及独立schema/能力。逐面色和拓扑延续只使用能够核验的原生历史；分裂/合并/多路径继续明确诊断。
4. 生产窗口包含精确面选择、完整集合/方向显示、预览/确认/取消/关闭；Ribbon、树编辑、结构化创建/编辑/查询使用同一契约，三语言实际控件和晚到候选守卫完整。
5. 最终专项/全量、Release零警告/错误、同冻结相关窗口、三语言布局/native像素及程序集哈希分别取证。SDK前提不替代应用验收；物理输入和外部CAD单列。
