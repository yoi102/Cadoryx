# F3e：有类型的制造基准系统与公差规则实施契约

更新：2026-10-03。A–F已授权，G第七批暂缓。F3a已有基础公差框，F3c已有原始孔证明，[F3d](F3D_ASSOCIATED_HOLE_COORDINATES.md)接入C2孔坐标；本页契约的完整圆柱尺寸/有序共同基准及受支持规则已实施并验证，见[F3e记录](F3E_TYPED_DATUM_SYSTEMS.md)。原始附着历史见[F3f](F3F_ORIGINAL_ATTACHMENT_HISTORY.md)；进一步尺寸类型/规则与缺失算法历史继续，本联合范围不标整体完成。

1. 使用锁定curve-inspection.6消费者证明完整有限圆柱尺寸特征：原始面/边/顶点邻接、两端闭合2π圆环、有限且共轴/同径的内外圆柱壁。验证外轴、通盲孔、沉孔/沉头主壁、STEP输入、侧切/分叉/缺口拒绝及指纹不变。只凭CylinderFace分类或参数范围不足以授权材料条件。
2. 给制造基准符号增加明确的表面/圆柱尺寸轴类型及原始尺寸证明；基础表面符号继续保留。公差框的轴目标及材料条件核对同一原始完整尺寸特征，尺寸证据不能来自历史配方或复制解析几何。
3. 基准系统用有序稳定ID表达主/次/第三基准；共同基准在同一框格内表达，不能被扁平字符串误作两个优先级。材料边界条件属于基准引用，不能混入基准标签本身。重复/自引用、错实例/定义、不存在的符号及不相容类型在整笔事务中拒绝。
4. 制造组合规则集中于领域模型，覆盖特征/表面或轴目标、直径容差域、被控尺寸材料条件及基准引用类型；ISO/GB和ASME差异须明确表达，不能因图纸选了标准就声称整套标准合规。未支持的组合明确拒绝，保留旧状态。
5. 原始资产或基准证明变化时，保持标注ID和旧证据并标失效；失效阻止有效PDF。新特征仅沿唯一原生历史延续，不凭距离、近似尺寸或遍历顺序重绑。共同基准组与条件必须被编辑、删除依赖、改名、撤销及存储守卫完整消费。
6. WPF/PDF共用矢量框格与条件符号；新增三语言明确编辑入口、保存重开与真实来源/后继样本。drawings独立迁移，旧版新字段夹带（含nil/空数组）拒绝；有效尺寸证明保存/加载逐项原生核验，缺核验器拒绝而非信任缓存。
7. 收齐消费者、相关/全量、固定载荷窗口/历史、PDF及截图检查后更新状态；物理输入、外部CAD、性能及G交付边界分列。随后继续F新特征历史、交换/命令和A/B/C/D/E余项。
