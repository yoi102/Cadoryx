# M15：精确建模与装配收敛

更新：2026-09-29。M15 仍在实施，以下记录已经落地的限定范围与完成门槛，不将控制点数量扩展等同于整个阶段完成。

## 特征抑制

特征树右键现在可抑制或恢复特征。抑制会阻断下游依赖并移除其可见输出，恢复未被消费的上游实体；恢复时在同一文档事务中重算依赖闭包并清理直通实体。状态写入 features v21，旧 v20 缺字段时迁移为未抑制；将真实抑制状态伪装成 v20 会被拒绝。撤销/重做、保存/重开及输入恢复由 `FeatureSuppressionTests` 覆盖。关联截面不能在未先解除关联时被抑制。当前只提供单特征抑制与恢复，还没有特征树回滚位置和任意历史分支重放。

最终验证补充：中间特征抑制的多级依赖、上游实体恢复、STEP 导出、被阻断参数编辑拒绝、保存/重开和撤销/重做由新增测试覆盖，树菜单文案已补齐三语言资源。完整 Release 测试 601/601 通过，`scripts/verify.ps1 -PublishSmoke` 的 CLI 与常规桌面冒烟通过，证据时间戳 `20260929-011308`。树右键的人工操作和特征树回滚位置仍需另行验收或实现。

## 已实施的样条编辑扩展

草图窗口的三次 B 样条工具现在可设置 4–16 个控制点，默认仍为 5 个；绘制按选定数量完成，切换数量会取消尚未提交的点击序列。所有控制点继续通过原有草图点编辑、撤销/重做和关联重算。核心验证、精确 BRep 建模和 MessagePack 读取共用同一上限。已有 4–8 点文件结构未变；新增 16 点闭环通过实体构造、文件保存/重开及超限拒绝测试。当前几何契约仍要求控制点沿首尾弦单调前进并处于同侧，使用均匀夹持结点。这个扩展不代表任意控制多边形、自定义结点或曲率连续约束已经实现。

## 未完成的 M15 范围

- 样条非均匀结点编辑、完整解析曲线交点、相切及曲率连续约束仍缺数据契约和精确验证；当前曲线孔岛检查保留采样边界，不能称为全解析。
- 复杂拓扑面的参数手柄尚未逐几何类型形成预览、确认、取消、撤销和保存闭环；抑制已有受限实现，但回滚位置与任意历史分支重放尚未实现。
- 当前跨重算拓扑身份只在有唯一、可证明的历史链时延续；拆分、合并、多路径和过期资产继续要求重选，通用自动命名未实现。
- 装配求解仍是局部数值解；大型奇异/多解样本、更多厂商 XDE 基准与来源依赖的对照验收尚未完成。不能把局部满足约束称为全局唯一。

阶段完成需对上述能力逐项交付真实几何、过期/歧义拒绝、编辑事务、旧文件迁移和多来源装配证据，详见[后续规划](NEXT_STAGES.md)。
