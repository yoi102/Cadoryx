现有exchange-loss.json描述写出器能力，没有实际重读结果。当前导出器已通过精确变换历史保留可证明的源逐面颜色，报告中的旧“源样式不导出”声明须与实现一致。IGES仍可能将实体和共享装配转为面集合；STL只有毫米坐标的网格，无内在单位声明。不能把同一内核的自往返写成外部CAD验收。

## 实施契约

1. 独立保留能力声明；增加版本化实测报告，绑定输入快照的文档/StateId、所选格式、参数、可执行版本、导出文件哈希和实际重读文件哈希。声明、观测、比较和未测项分列。单位检查使用独立英寸/米fixtures和解析尺寸，不能用两次错误相消作为正确性证明。
2. 对STEP/IGES执行实际导出及导入；以世界坐标边界、实例数量、定义共享组、有序层级/名称、有效实体体积、面面积及颜色作明确比较。只能报告这些观测，不能以边界/体积一致声称几何完全等价；不通过几何相似找回原始拓扑身份。
3. 对STL记录真实网格重读、边界和三角面数量，单位仍由调用方明确为毫米；不将三角网格当作精确BRep。网格误差使用所选线性/角度参数及受支持指标报告。
4. PMI只在有原始支持证据和实际API时测量。当前无法证明的PMI、制造图纸、草图约束、特征历史及装配关系明确标未传递或未测，不从没有PMI的测试零件推断保留。
5. 报告生成只读快照并持有全部资产租约，运行在工作线程；取消、失败及晚到结果不改变文档或替换既有报告。输出采用同目录临时文件完成后原子替换，覆盖必须遵循已有明确调用语义。异常和资源释放均验证。
6. 提供确定性命令入口及生产界面入口，明确写出“Cadoryx/OCCT重读”与真实外部CAD回传来源。第三方重读只有真实文件和来源软件/版本证据时才能计入；没有安装或样本时记录未验收，继续可执行部分。
7. 固定fixtures覆盖毫米/英寸/米、递归共享定义及旋转、逐面色和显式颜色覆盖、STEP/IGES/STL、隐显过滤、错误格式/取消/失败/源改变与报告伪造。完成聚焦检查、必要回归和相应实际控件，更新总状态。
