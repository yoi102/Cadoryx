# M12：大型 STEP 导入与视口直接操作

## 目标与实现边界

M12 处理上一阶段留出的两类实际等待，并补齐直接操作：大型 STEP 的首次导入与完整场景显示、选中装配实例的视口平移，以及 Revolve 角度手柄。数据结构不增添新的文件字段；实例移动沿用完整 `OccurrencePath`、`ComponentSlot.LocalTransform` 和 `DocumentEdits.MoveOccurrence`，实体参数编辑沿用现有候选预览／确认事务。

视口选中一个可独立移动的实例时，在其可见几何中心出现 X/Y/Z 三色手柄。拖动过程中只变换该实例及子实例的原生 presentation，鼠标松开后才把世界位移换算到父装配局部坐标并提交一次命令。Esc、捕获丢失、场景切换和视口销毁恢复原位。共享父装配、只读文档、在途建模/预览，以及任何启用的约束涉及所选路径或子路径时不提供手柄。文档状态在拖动中变化也拒绝提交；不自动重绑过期路径。网格吸附沿用文档间距。

编辑 Revolve 特征时，角度手柄位于剖面最远径向顶点的旋转终点。切向拖动改变 0–360° 候选角度，鼠标松开生成原有特征预览，点击确认才写文档；取消保持原角度。角度不使用以毫米为单位的工作网格吸附。

## 性能口径

固定样本为本机 `C:\Users\yoiri\Downloads\MiniPC3.step`，88,258,425 字节，SHA-256 `f3773a7f37bd0cb8e717e4be6f1070a72e5c6e7b2f36f26f9501183df8c4c68e`，约 4,975 个可见实例。M12 开始前，使用发布版 `artifacts/publish/20260928-003717/Cadoryx.wpf.exe`、两轮双视口基准，在 `artifacts/m12-baseline2-20260928` 记录内核／存储加载约 108.28 秒、首批显示约 1.27 秒、完整场景提交约 9.20 秒。旧 M8 约 55.4 秒导入来自另一次运行，不能与本轮直接当作相同条件的优化前值。首批与完整提交是 UI 线程原生调用耗时，不是显示器帧率或 GPU 端呈现时间。

内核增加可选的 `CADORYX_IMPORT_PROFILE` JSONL 分段诊断，不设置时不写日志；日志写入失败不影响导入。它拆出 OCCT 交换读取、XBF 保存/资产暂存、逐定义转换（拓扑摘要、有效性、包围盒、体积、BRep 写出和资产暂存）、颜色、文档验证。该日志用于定位瓶颈，不能替代固定样本端到端复测。初轮诊断显示 OCCT 读取约 38.67 秒，逐零件 `StoreShape` 约 58.74 秒，颜色约 0.14 秒。细分后，重复的有效性检查约 11.93–12.09 秒：锁定包的 `GetTopologySummary` 已执行 `BRepCheck_Analyzer::IsValid` 并返回结果，原实现再调用 `Shape.IsValid` 又遍历一次。因此直接复用摘要结果，保留相同拒绝无效拓扑语义，无须迁移 OcctSharp 包。

另一个可削减项是会话级磁盘资产的逐文件 `Flush(true)`。磁盘缓存可随会话关闭清理；正式文档和恢复档案有各自的写入/提交路径。移除该缓存的逐资产强制刷盘后，相邻两次 CLI 分段诊断的暂存合计约从 14.34 秒降至 7.89 秒；两次运行也受文件缓存、杀毒软件及主机负载影响，不能把全部差值归因于这项代码。生产 STEP 工作进程使用内存资产，桌面主进程延迟加载时使用磁盘资产，因此 CLI 直读与用户点击打开的耗时要分别记录。

每个 XDE 实例可能继承父标签的颜色。曾尝试对表面上颜色一致的零件改走普通 shape 显示，基准截图发现黄色外壳变蓝，故已撤回。最终仍保留完整 XDE 源样式；截图必须与基线核对后才报告性能，不以丢失颜色换取提交时间。

## 验收与限制

自动测试覆盖父坐标系旋转换算、精确实例移动／撤销、Revolve 切向手柄和候选事务。发布版桌面冒烟走真实视口指针按下、移动、松开和捕获取消通道，比较拖动前后文档及撤销结果。性能报告记录样本哈希、导入与完整提交时间，并区分首次运行、缓存和环境波动。

本机联合验收：`scripts/verify.ps1 -PublishSmoke -WindowSmoke` 完成锁定还原、Release 零警告构建、596/596 自动测试、CLI、常规桌面与窗口冒烟。窗口冒烟走原生视口指针拖动、捕获取消、提交和精确撤销，并覆盖三份旧文档、源颜色和 12 轮浮动／关闭；`artifacts/window-smoke-20260928-194725/result.txt`、`m12-occurrence-handles.png` 与 `artifacts/smoke-20260928-194725/result.txt` 为证据，两处绑定日志均为空。固定样本双视口基准另在最终代码上通过，见上表。

M12 的限定实现与本机验收完成。仍限定为单个选中路径的轴向平移，不包含任意旋转操纵器、约束驱动实时求解或数千实体的连续动画保证。完整场景仍约 9 秒；OCCT 原生读取约 38 秒、逐定义转换约 41 秒（见 `artifacts/m12-optimized-import-profile.jsonl`），进一步提速需对这两段和完整显示流水线分别设计并复测。混合 DPI、RDP、新机器、数小时运行仍属于交付环境验收，不用本机短时窗口冒烟代替。
