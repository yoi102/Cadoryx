# E1 特征历史回滚、插入与合法重排

更新：2026-10-03。第 4 节 A–F 的 E/G16 子项，代码、专项及生产历史窗口通过；同版通用窗口的圆盘定位门禁未通过。整个 A–F 仍进行中，第七批 G 暂缓。

## 行为契约

模型树特征右键菜单提供“回滚到此特征之前/之后”“返回历史末端”和“前移/后移”。回滚位置是当前会话的临时状态，不写入文件，不改完整文档，不增加撤销记录或 dirty，也不创建几何资产。位置按零件明确的特征顺序计数，包含抑制和冻结条目；显示有效前缀中没有被有效后继消费的精确缓存结果。其他零件保持末端，共享同一定义的实例使用同一回滚结果，实例路径和位姿不变。

临时场景标记 `IsTemporaryHistoryView`，不能直接保存、导出或提交。会话保存仍保存完整图；生产导出入口提示先返回末端。临时场景隐藏工程测量缓存，避免把完整结果的尺寸叠到中间实体。抑制、失效和依赖缺失的前缀不显示为有效结果。

在回滚位置可用主建模面板新增特征并预览。新增依赖必须全部位于游标之前，基准、草图及其间接特征依赖也检查。确认将新特征插入该位置，返回完整图，单次撤销/重做。新增分支保留原有后继的 operands、ID、精确结果、拓扑历史及当前外观；不自动把原后继重新绑定到新结果。取消释放预览，保留游标。改变游标会使旧准备结果失效。

现有特征、草图、参数、基准、实例及文档作者数据编辑须返回末端。会话再次校验带游标命令的候选图，阻止伪造提交绕过限制；只允许新特征和对应输出，旧特征、其他定义、冻结原始体、层、材质、审阅/拓扑/装配作者数据及工程图作者字段保持。工程图缓存刷新仍属于完整图的关联处理。

重排只改变同零件的完整 chronology，须包含全部原特征各一次并满足直接及间接依赖。它不重排布尔参数、不重算几何、不猜拓扑身份；非法移动报告依赖特征名。旧文件的非常规顺序须明确合法重排后才能回滚，不按遍历顺序自动修复。任意配置分支、自动改接后继及反事实重算不属于该游标契约。

## 实现入口

- `Cadoryx.Db/FeatureTimeline.cs`：顺序校验、临时精确输出、插入守卫及完整结果恢复。
- `Cadoryx.Commands/FeatureTimelineCommands.cs`：游标创建包装与合法重排；准备提交带明确游标。
- `Cadoryx.Editor/DocumentSession.cs`：独立 DisplaySnapshot、generation 失效和原子提交。
- 模型树、历史工具和主建模面板：游标提示、未来条目标记、返回按钮、菜单及预览/取消/确认。
- 英/中/日共键资源；存储仍用既有特征数组，不新增持久游标或 schema。
