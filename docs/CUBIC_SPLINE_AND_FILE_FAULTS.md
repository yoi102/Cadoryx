# 三次 B 样条独立区域与 M3 文件故障矩阵

本轮连续完成两个大阶段，统一验收结果记录在 [ROADMAP](ROADMAP.md) 末尾。

| 大阶段 | 实现与边界 |
| --- | --- |
| 三次 B 样条独立区域 | 草图数据接受 4–8 个控制点，三次均匀夹持 B 样条与起终点隐式弦围成单侧区域；端点不同，内点沿弦严格单调且都在弦同侧。编辑器五次点击绘制，控制点可移动、撤销、重做或设为构造；稳定 SplineId 驱动拉伸重算。使用 OcctSharp 原生 B 样条边建面及精确拉伸，可导出 STEP、IGES、STL。 |
| M3 文件故障矩阵 | 同目录临时 ZIP 写入、逐节与资产校验、最终替换；注入第二个扩展节读取异常或取消，核对原文件字节及临时文件清理。加载第二个扩展节资产时注入 Stage 失败，核对前一租约回滚。恢复负载写完后取消，核对未发布元数据、旧快照可打开及孤立文件清理。 |

文件写出器 `0.4.26` 使用 features v19、sketches v6。features v18→v19、sketches v5→v6 在未含新字段时显式迁移；把含样条的节伪装成旧版本会被拒绝。样条控制点和引用 ID 持久化在 MessagePack 数字键中，BRep 资产仍单独存放。显示折线只供 UI 预览与命中，不参与内核建面。

此阶段**不提供** B 样条与直线／圆弧组成的任意混合链、样条孔、样条约束和多层岛屿。文件故障测试是确定性的应用层注入；实际磁盘满、断电、网络文件系统、系统崩溃与目录项持久化仍需环境专项验证，不能据此承诺所有介质上的掉电原子性。

2026-09-25 联合验收：Release 构建 0 警告／错误，440/440 测试；独立发布、桌面、窗口、草图真实指针及生产 30 秒强制终止恢复冒烟全部 PASS，五份 WPF 绑定日志均为空。恢复快照包含五控制点样条的关联 ID 与约 168.5 mm³ 精确实体；草图指针冒烟完成五次点击绘制。独立锁定 NuGet 消费探针 28/28 场景通过，62 个原生 DLL 哈希与包载荷一致，现有 OcctSharp 接口足够，本轮没有迁移上游绑定。日志和证据路径见 [ROADMAP 验收记录](ROADMAP.md#5-本轮验证记录)。
