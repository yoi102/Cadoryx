# B11 实体边与椭圆投影实施记录

更新：2026-10-03。解析曲线、原生有理自由曲线及有限曲线明确端点的生产流程已接入，完整 B11 和 A–F 仍进行中；第七批实机、安装及交付按用户要求暂缓。范围来自 [B11 规划](B11_EDGE_AND_ELLIPSE_PROJECTION_PLAN.md)及 [总跟踪](AF_IMPLEMENTATION_TRACKER.md)。

## 已实现的工作流

草图新增固定数值定义的仿射椭圆，保存中心、余弦轴、正弦轴、起始角和有向扫角。斜向草图圆/弧和已有椭圆投影保留解析定义、区间、反射和方向；显示和命中使用的离散点不参与模型几何证明。数值栏只格式化显示，完整双精度系数仍存储。

草图编辑器的“投影实体边”打开独立原生视口，用户明确选择来源特征和边，再选择关联或独立复制。关联记录文档、特征、资产、修订、指纹、边索引及适配器；确认时重读原始 BRep，核验类型和解析系数。未知曲线与退化投影拒绝，不拟合或降级为折线。

来源变化、抑制、失效或草图平面变化后，关联冻结并保留原始不可变 BRep，消费者保持旧结果并显示失效。显式重选可保留目标作者 ID，但必须保持曲线类型；解除关联后才能编辑驱动值。重选、解除、构造状态、预览取消/确认及草稿/文档撤销均接入。异步迟到、文档 generation 变化及窗口关闭不能发布旧结果；租约持有至原生任务结束。

完整椭圆可直接成闭环；有限椭圆可形成明确弦封闭的单实体区域。精确拉伸/旋转、混合孔及递归岛已接入。自动嵌套通过原生精确面、边距离及布尔分类选最近父区域，不使用显示采样。内部越过旋转轴的椭圆由解析极值拒绝。

零件独立化重映射原生来源特征到新零件，同时保留不可变几何资产。原零件重算只冻结原零件投影，不能使副本误引用原作者图。

## 原生自由曲线应用接入

完整不可变定义保留曲线族、控制点、权重、结点及重数、次数、周期、有限原生区间和方向；独立于旧非有理三次作者样条。精确内核、实体选边确认、关联/独立复制、同族重选/解除、求解器意图保护、作者图独立化、旧BRep租约、递归轮廓/孔岛、拉伸/旋转和扫掠/放样均接入。旋转使用原生精确轴交点拒绝内部穿越、切触及重合，不按控制多边形猜测实际曲线位置。

数值编辑栏消费完整双精度表，关联时保护数值，解除后可编辑并撤销。边选择仍用原始BRep身份核验；细自由曲线的原生选边像素容差由2改为8，其他模式维持2。该容差只扩展屏幕命中，不替代拓扑证据。三语言新增11键；原生冻结诊断和自由曲线驱动保护已用资源键。

`SketchCurve2d` 的非有理权重必须传null；构造后按实际native参数域归一化裁剪。完整周期fixture不传range，避免上游Segment改变周期定义。当前验证只覆盖构造native域内的有限区间；跨接缝和域外周期区间应用尚未接入，精确分段路径已通过后续50场景锁定消费者。完整曲线是精确几何，但面积/体积属性积分是数值计算：独立有理线积分对照的已验相对阈值为1e-6，不能宣称任意曲线质量属性达1e-9。试验native tolerance1e-12未一致改善结果，保留 `b11-freeform-volume-1` 与早期core日志。

固定产物 `artifacts/publish/b11-freeform-20261003-6` 的143联合专项、1333/1333全量和Release0/0已过；三语言生产 `artifacts/b11-freeform-smoke-5` PASS，33张截图均检查，12份文档保存重开、空绑定日志及资产归零。11组相关窗口中10组PASS，一般window的圆盘定位FAIL保留：即时warp成功且光标在中心，Idle后光标另移；后续端点构建修正诊断以即时warp和布局中心稳定性分别检查，未改生产warp，也未证明后续移动的来源。机器证据 `artifacts/b11-freeform-verification.json`。早期空weights、周期fixture和旧schema断言失败均保留；1289全量属于前一解析构建，不证明自由曲线版本。

## 有限曲线的明确作者端点

新增可选 `SketchCurveEndpoints`，持久保存首尾点与两条固定锚点ID。用户对未闭合椭圆弧或自由曲线显式生成端点，然后画布捕捉可让新直线/圆弧/Bézier/作者样条共用这些ID；核心也支持明确选择已有同位置端点。导入及闭环识别不会按距离、顺序或相似几何合并旧作者ID。混合轮廓保留曲线完整定义，反向走边反转曲线有向参数；两边曲线加直线、较大混合链均可被精确区域服务验证。

数值编辑、草图来源刷新及原生边显式重选保留端点ID，更新端点位置和锚点后原子重算依赖边/特征。固定点不能拖动、删锚点或关闭锚点来改变数值曲线；删除端点删除引用它的曲线/邻边，删除曲线释放其锚点并保留可编辑的其余作者点。闭合曲线不生成两个伪端点。独立零件内的同一草图ID域保留端点关系，不影响原件。

端点阶段存储 `document37 / features34 / sketches15`，Key3追加端点记录，能力 `cadoryx.exact-sketch-endpoints.1`；sketches14和更早格式伪装新端点必须拒绝。新三语言资源3键，当前三套1071键非空且集合一致。生产按钮为WPF Automation，画布使用与WPF相同的PointerPressed和捕捉路径；这不是实体鼠标证据。

端点19新增、166联合及包含锚点保护的71联合通过。三语言实际控件和画布捕捉检查PASS，9张截图均逐张检查。首轮11窗口为10/11，B8孔Toggle未完成布局的诊断失败保留；完成布局后的端点第二产物5组复验全部PASS，包含B8、一般window、C1和原生投影。历史全量1352通过，但其运行期间工作目录内另有新构建，不把它作为不可变同版证明；随后曲线参数构建的固定测试二进制全量1378通过并核验生产依赖哈希，详见[B11/C1](B11_CURVE_PARAMETER_TARGETS.md)。首次编译的ImmutableArray测试写法和一次将求解前坐标与求解后保存坐标逐值比较的失败已修，日志保留。存储篡改测试重写校验和后再断言具体几何验证原因，不能只以文件校验和失败冒充端点守卫。
