# M5：装配实例编辑与共享子装配独立化

本轮连续实现两个大阶段，统一验收结果记入 [ROADMAP](ROADMAP.md)。

| 大阶段 | 实现范围 |
| --- | --- |
| 实例生命周期与重挂 | 在选中实例旁创建空子装配，或在指定装配实例下插入已有定义；替换或删除指定实例；将指定实例重挂到另一装配并保持世界位姿。路径定位到具体槽位，重挂采用 `目标父世界变换⁻¹ × 原实例世界变换` 计算新局部位姿。槽位 ID 在移动中保留；循环、根定义作为子级、失效路径、跨文档路径和共享父级编辑均拒绝。 |
| 共享子装配独立化及 UI | 从模型树选中复用的装配，在属性面板明确执行“使这个子装配独立”。沿目标路径按需复制共享的装配定义并给复制的子槽位新 ID；不复制 BRep、零件定义或特征。属性面板提供定义选择、插入、替换、删除及目标装配选择与重挂。独立化后可对该副本的子槽位单独移动和编辑，其他副本保持原定义与位置。 |

这些操作是文档命令，使用已有不可变快照、撤销／重做、`.cadoryx` 十节 MessagePack 和恢复协议，不新增文件格式字段。移除实例只移除其槽位，不隐式销毁零件定义、特征或资产；重挂、独立化失败时不发布半成品状态。选中的共享装配在独立化后保持有效路径；嵌套共享装配会返回重映射后的槽位路径。

本阶段不提供零件几何的逐实例独立副本、删除未使用定义及其资产、装配约束求解、外部零件链接和自动重绑定。它们仍是 M5 后续工作；尤其“使子装配独立”只隔离装配层次与子槽位编辑，零件建模仍修改共享零件定义。
