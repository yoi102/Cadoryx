# B12：不共享端点的有限圆形曲线接触关系

更新：2026-10-04。接着 E4 最终验收，属于 [A–F 总跟踪](AF_IMPLEMENTATION_TRACKER.md) 的 G04 基本草图关系。本文契约已实施，实际验证与保留失败见 [B12 记录](B12_CIRCULAR_CONTACT_RELATIONS.md)；最终全量2262/2262及候选审计已通过。G 第七批继续暂缓。

现有 `TangentConstraint` 仅适配直线与圆的支撑相切，`EndpointTangentConstraint` 需要唯一共享端点 ID。两个分离的圆/圆弧、直线与圆弧还没有明确有限接触契约；不能靠合并坐标冒充共同身份，也不能把弧所在整圆相切当作有限弧已接触。

## 范围与语义

新增独立、具名且稳定 ID 的有限圆形接触关系。消费作者明确选择的两个实体，支持直线段—圆/圆弧、圆/圆弧—圆/圆弧。直线侧别以及圆形曲线外切、A 包含 B 的内切、B 包含 A 的内切由作者明确选择；不从最终解偷偷改变分支。

求解器使用完整圆的精确中心、半径与三点圆弧构造，不以 tessellation、Bézier 近似或接触点附近采样代替。解算后必须确认接触点属于有限线段与各自有向圆弧的实际区间。弧外支撑相切、线段延长线上相切、同心重合及退化都不能报告成功。无需创建共同点 ID，现有端点关系的身份规则保留。

## 实施与验收

1. 领域验证输入实体、分支、引用与退化；三点弧的方向/major 区间保持，既有 `TangentConstraint` 不被重新解释。稳定约束 ID 随删除、投影/参数守卫和草图作者克隆正确处理。
2. 增加尺度归一化残差和可核对的 Jacobian，圆弧中心/半径对三点的导数复用同一解析构造；LM/SVD 冲突、奇异/自由度、取消和预算仍保留。有限域复证属于成功门禁，失败返回原草图。
3. 正例包含分离圆外/内切、直线—有限圆弧、两弧接触、旋转/平移/尺度与驱动半径；反例包含错误分支、同心、弧外/线段外接触、共线三点、重复或跨草图实体及固定冲突。
4. 预览/确认/取消、撤销/重做、草图参数及冻结作者到实体/工程图的联动检查，确保失败原子且没有身份合并。完整配方存储和独立中间迁移，旧 schema 夹带新约束拒绝。
5. 生产编辑窗口使用两个明确实体和分支输入，提供三语言有限域诊断；结构化草图作者和约束查询沿用同一契约。最后专项/关联/全量、Release、同候选窗口/布局与哈希分别取证。

任意 Bézier/样条/椭圆的非端点接触和曲率连续需要后续独立参数/分支契约；本批不能推广为任意曲线求解。物理输入与外部供应商样本继续单列，不能被 G 的暂缓抹去。
