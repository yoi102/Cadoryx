# M6：大型模型基础三个大阶段

后续进展：历史资产预算、深路径搜索与选择包围测量已在 [M6_WORKSPACE_TOOLS.md](M6_WORKSPACE_TOOLS.md) 继续交付。下文保留本基础批次的范围与当时验收记录。

本轮先处理重复实例和大型装配最直接的编辑负担，不把它称为大型真实模型性能验收。所有改动完成后统一执行发布版验证。

| 大阶段 | 实现范围 |
| --- | --- |
| 几何复用与规模信息 | OCCT 视口按 BRep 资产、XDE 来源和格式共享原生几何资源；不同建模修订但相同资产的实例不重复读取同一几何。场景投影在同一文档状态内缓存，避免界面重复构造。状态栏显示定义、实例、唯一资产及其字节量；字节量只计算当前文档引用的去重载荷，不等于进程内存或显存。 |
| 按展开加载模型树 | 根级实例立即列出，子装配、零件的 body/草图、特征历史只在展开时生成；场景修改后保留已展开实例路径及历史分组的展开状态。TreeView 启用容器回收虚拟化。完整树结构仍由领域模型验证，未实现文件层的按需资产读取。 |
| 自适应显示网格 | 显示间距依照当前像素/毫米采用 1–2–5 倍数，缩小视图时疏化，放大时回到文档设置间距；相机缩放、恢复、适配和窗口尺寸变化会更新。文档网格间距、吸附间距、保存协议及撤销语义均不变；状态栏提示显示密度与吸附的区别。 |

仍未覆盖：真实三档 CAD 样本的导入/首帧/交互/峰值内存测量、文件层按需 BRep 读取、树中的任意深路径搜索、多视口、剖切、混合 DPI/RDP、长时间运行及 worker/进程隔离路线。须依据真实测量确定预算；不能据本轮缓存和虚拟化宣称“百万面 60 fps”。
