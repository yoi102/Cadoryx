## 用户可编辑内容

| 内容 | 编辑行为 |
| --- | --- |
| 名称与密度 | 保留现有共享材质资源与 kg/m³ 输入；修改可撤销。 |
| 正面与背面 | 颜色、不透明度、金属度、粗糙度、折射率和发光；背面可选择独立配置。 |
| 着色与透明 | Phong / PBR、面剔除、Opaque / Mask / Blend / MaskBlend 和遮罩阈值。 |
| 颜色纹理 | 导入单张 PNG 或 JPEG；应用时复制解码后的 RGBA 像素，文档不保存外部路径。 |
| 纹理映射 | 原生 UV 或零件坐标平面 S/T，缩放、平移、角度、重复、采样和各向异性质量。 |
| 导入面样式 | 默认保留来源面颜色与纹理；明确勾选覆盖后才使用整实体材质。实例颜色覆盖优先。 |

旧材质的外观字段为 null，保持现有渲染。PBR 材质需要启用视口级 PBR 管线；单独设置实体外观不能作为 PBR 生效证据。建模预览临时使用原绿色提示，确认后恢复材质。外观修改不重建BRep、不修改UV或拓扑身份。缩放限定0.000001–1000000，平移与平面系数限定±1000000，旋转限定±360000°；负缩放明确拒绝，不夹紧或悄悄替换。平面映射可通过S/T方向系数表达方向。

SDK 的整实体外观接口接收一张纹理。导入 XCAF 的多个纹理槽与完整来源样式另行保留；当前作者界面不宣称提供原生接口未证明的多槽创作。

## 资产与文件契约

纹理资产采用版本 1 的 `CDXRGBA1` 封装：24 字节头，明确宽高，保留字段必须为零，后接从上到下、未预乘的紧密 RGBA8 sRGB 像素。宽高各不超过 16384，总像素不超过 16,777,216。描述符、字节长度、媒体类型、编码、版本和资产目录必须一致；缺失或无效纹理会拒绝编辑、读取或显示，不自动替换。

`DocumentSnapshot.ReferencedAssets()` 纳入材质纹理，使当前文档、撤销与重做、捕获和关闭遵守原有租约机制。每个视口独立持有纹理资产与 GPU 资源；禁止跨视口或线程共享 GPU 对象。

新外观存入独立必需的 `material-appearances` 分区，声明 `cadoryx.material-appearances.1` 能力。现有 presentation v2 的名称与密度字段不改编号。只有实际外观存在时才使用 writer 0.7.10；没有外观的普通文件仍为 0.7.8，有当前路径表的文件仍为 0.7.9。旧 JSON presentation 不能嵌入未声明的外观。

读取必须检查能力与分区同时存在、分区必需性、版本、完整消费、重复/不存在的材质 ID、纹理角色冲突及实际像素。延迟资产读取也必须在发布可用材质前验证纹理，不能以延迟读取为由跳过校验。

## 命令与 AI 契约

`MATERIAL` 是嵌入命令入口；独立候选已接入 `Cadoryx.Cli material-contract` 与 `Cadoryx.Cli material INPUT.cadoryx --request REQUEST.json --output OUTPUT.cadoryx`。GUI、Agent和CLI共用无WPF依赖的 `CadMaterialAuthoringService`，支持 contract、inspect、set、delete、assign、texture_pixels。工具修改必须提供当前 documentId/stateId；实体分配还必须提供 bodyId 与当前 geometry revision。新建 set 不提供 id，编辑保留原 id；省略 appearance 保留现有外观，显式 null 清除，完整对象替换整份外观配置。

默认工具目录保持原12项。只有明确的材质/纹理请求才追加cad_material，支持中英日及显式工具名；默认工程图、草图与长期收据上下文继续使用原目录。新14项通过实际AgentRunner与上下文重试夹具验证选择/执行路径，不代替真实LM Studio原模型验收。原14项默认目录FAIL和原供应商FAIL均保留。

独立CLI的只读inspect可省略身份以读取当前documentId/stateId；`collection: "bodies"`分页提供实体ID、当前revision及materialId。修改必须显式提供读取到的文档/状态，分配还需要实体当前revision，不自动补身份。输入限制为65536 UTF8字节、16384字符、32层；递归重复字段及非UTF8拒绝，共享服务直接调用也保留大小/深度守卫。输出与输入必须不同，替换须显式--overwrite；先计算临时文件哈希再原子移动，失败/取消清理临时输出。见[CLI30实际文件验证](../artifacts/a5-material-cli-shared-draft-1/published-process-1-verification.json)。NETCore依赖及隐藏进程启动已验，物理Console.CancelKeyPress未测，API预取消另由159相关测试覆盖。

纹理描述符只能完整复制自同一文档的检查结果，或者通过带明确宽高的 RGBA 像素导入。Agent工具像素请求受16384字符总请求和12000字符Base64上限约束；嵌入命令仍保留4096字符总输入上限；完整尺寸的图片导入由 GUI 完成。失败返回只读状态查询提示，不补造身份、不自动执行修改。
