# M5：逐实例零件、未用定义清理与编辑范围

本轮连续实现三个大阶段，最后统一验收。

| 大阶段 | 范围 |
| --- | --- |
| 逐实例零件独立化 | 选中共享零件实例后，沿实例路径先隔离共享祖先装配，再复制零件、体、特征、草图和关联拓扑引用的业务 ID。复制特征输入、输出体、草图来源及局部边绑定均映射到新 ID；BRep 几何资产和修订保持共享，后续编辑写入独立零件。原实例和其他装配分支不变。 |
| 未用定义清理 | 从根装配计算可达定义；仅显式清理不可达且没有保存的拓扑引用、历史诊断查询或可达特征绑定依赖的定义。同步移除其体、特征和草图；保留受诊断引用保护的定义。文件资产继续遵循快照、撤销历史和显式保留资产的租约，不在命令中直接删除。 |
| 明确编辑范围 | 属性面板分别提供“仅此位置”的实例名称和“所有实例”的定义名称，显示定义使用次数。共享定义重命名影响全部引用实例；实例重命名只修改所选槽位，遇共享父装配时须先独立化。零件独立化和未用定义清理均有界面入口。 |

这些命令复用现有不可变文档快照与 `.cadoryx` MessagePack 格式，不增加文件节或新的 OcctSharp 接口。显式独立化不会伪造新的 BRep 修订或猜测拓扑；复制后的精确边绑定仍指向相同的几何资产，但引用新的本地特征身份。外部文件链接、装配约束求解以及对明确保留资产的物理垃圾回收仍留待后续阶段。
