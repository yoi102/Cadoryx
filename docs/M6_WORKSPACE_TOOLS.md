## 历史预算的语义

`DocumentHistoryUsage` 统计 undo 与 redo 所引用资产的并集，扣除当前文档引用的资产。相同 BRep、XDE、保留资产在多个快照中只算一次。长度来自已持有的租约，不再为报告载入或复制几何。

提交、撤销、重做及手动应用限额都会裁剪历史。先移除最旧 undo，再移除最远 redo，保留从当前状态可达的连续历史。某一步退回较小模型后，大模型资产会变成额外历史载荷；如果预算不足，该重做记录也可能被裁掉。零字节预算仍允许无额外资产的元数据历史。

清空/裁剪释放相应历史租约，不改当前 snapshot、generation、文件路径或保存点，不是可撤销文档命令。独立 capture 仍可持有资产；因此历史报告不等于进程内存，也不保证清理后立即减少相同数量的物理内存。不统计快照对象、原生几何、显存或其它消费者租约。界面在应用和清空按钮之前说明丢弃语义。

## 搜索与选择身份

后台读取不可变结构，取消搜索或文档变化后丢弃旧结果。结果绑定 document state，定位前验证完整 DocumentId + SlotId 路径及 body/revision/part，不能按共享定义猜实例。名称路径仅供展示，重名不会改变身份。

2026-09-27 的交互整理后，模型树用整行的轻量选中底色及左侧细条显示当前项，选中区域不再随文字长度变化。视口选中实体会自动展开并选中对应实例下的实体行；在树上选中实体会更新文档选择并使视口高亮。选中零件或装配节点时保持其 occurrence 路径，由视口高亮该节点下当前场景中的实体，不把装配路径改成第一个子实体。多选仍以首个实体行作为树的当前项，勾选状态保留所有已选实体。

这次联动新增单元回归和发布版 `WorkspaceToolsSmokeRunner` 的自动同步断言。2026-09-27 UI 收尾联合运行通过 578/578 测试、常规/旧文件窗口/图纸冒烟；最终模型树截图为 `artifacts/smoke-20260927-172401/workspace-tools.png`，对应 WPF 绑定日志为空。视口高亮仍按当前显示场景内的 occurrence 路径匹配，隐藏/未提交几何不会凭空创建显示对象。

搜索不创建整棵 UI 树，也不读取 BRep。采用既有最多 100,000 个展开实例、128 层领域边界；搜索仍需遍历实例，200 项是结果上限，不是索引系统或任意规模性能保证。本轮未加入特征/草图正文检索。

## 测量的数值边界

世界包围范围由本地 bounds 的八个角经完整父子刚体变换计算；旋转后可能比真实曲面更宽，并非精确 BRep 最紧包围盒。两个实体的距离是这些包围盒的中心距离，不是表面最短距离或质心距离。

体积读取已存的内核结果，按实体实例相加。同一 body 在不同 occurrence 中重复计入，同一精确选择重复输入则去重。相互重叠不扣除，不能解释成布尔并集体积。仅 Solid/Compound 参与体积和密度质量；只要有非体积对象或缺材料，质量显示不可用。数据不足时不猜测材料或将 mesh 当实体。所有持久化数值仍为 mm/mm³，显示按文档单位转换。

未覆盖：精确点/边/面测量、最短 BRep 距离、截面、测量标注、多视口、文件按需加载、真实大型模型性能测量、混合 DPI/RDP 与长时间运行。当前锁定 OcctSharp 包足够，本轮无新增原生封装或 NuGet 升级。
