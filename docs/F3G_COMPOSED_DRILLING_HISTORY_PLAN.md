# F3g：沉孔、沉头及连续钻孔的历史组合契约

更新：2026-10-03。接续[F3f原始附着历史](F3F_ORIGINAL_ATTACHMENT_HISTORY.md)。A–F已授权，G实机、安装及交付暂缓。本页定义的有界应用契约已实施并验证，当前结果见[F3g记录](F3G_COMPOSED_DRILLING_HISTORY.md)。以下保留实施契约，不代表所有组合几何都支持。

普通孔提供单次原生历史；沉孔、沉头与含种子孔阵列现沿真实原生阶段组合，不能把最后一次操作的来源槽当成原始来源。圆周沉头规范化、排除种子及缺历史继续拒绝，具体边界见实施记录。

1. 锁定curve-inspection.6的独立消费者分别验证作者实体/STEP输入上的通孔与盲孔沉孔/沉头，Boolean锥体工具作为第二操作数，及已有生成孔壁跨三次后续钻孔。每步写出/重读BRep，核对完整拓扑图和各槽规范化见证。此证据只证明原生前提，不证明应用已经接入。
2. 组合器逐步检查来源、结果资产/修订/指纹、数量、类型、所有操作数和完整覆盖。每个原始面/边/顶点只在每一步都有唯一可证明后继时传播；分裂后重合、共享合并、生成/删除、缺映射和跨类型不能被后续操作抹掉。终止状态保留，不能恢复为成功。
3. 原生重放重新构造每个内部中间结果；组合器仅接受同一保存资产的相邻映射。保存后的组合映射重新核对完整关系，换同类型槽、换中间输入和伪造adapter均拒绝。语义来源入口也必须重放组合历史，不能绕过核验。
4. 沉孔使用已证明的头部钻孔加主孔；沉头使用有历史的锥体Boolean加主孔，并保留现有入口/方向、材料去除和实体有效性核验。中间资产只由求值事务持有，失败、取消和重放后释放。
5. 包含种子孔的阵列可从种子结果逐步组合。排除种子孔的阵列从原始基体重放，种子结果不是它的物理几何输入；没有正确生产依赖及来源身份时不得宣称种子到最终的延续。需单独明确依赖契约后才能开放。
6. 版本能力和历史adapter独立声明，旧版本夹带拒绝；仍无真实历史的抽壳、变换及其他算法维持失效诊断。现有模板/工程图作者来源、基准绑定、孔号和失效旧资产规则继续保持。
7. 增加原始面/边、已有孔、模板不变、孔表当前尺寸重验、原子失败、取消、保存重开及三语言来源重选样本；固定版本完成专项、全量和工程图/历史联合窗口再更新状态。

整个A–F的余项仍见[总跟踪](AF_IMPLEMENTATION_TRACKER.md)，包括A性能目标、B关系与偏移连接、C多副本样式/螺纹、D曲面终止/实体偏移、E复杂边链、进一步制造尺寸/规则、交换与命令/AI。
