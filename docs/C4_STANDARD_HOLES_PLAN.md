# C4：标准孔与孔型工具

更新：2026-10-01。属于已授权 A–F，承接 [C3](C3_MIRROR_AND_PATTERNS.md)。本页保留起始契约；常用孔型的当前实现、证据及指针门禁见 [C4 实施](C4_STANDARD_HOLES.md)，螺纹仍独立跟踪。

| 范围 | 契约及验收 |
|---|---|
| 通孔/盲孔 | 单一当前精确目标实体、局部轴与起点、直径/深度；优先使用锁定包 `LocalFeatures.Hole` 的受控 Through/Blind 算法及失败状态，不通过包围盒猜测盲孔已封底 |
| 沉孔/沉头 | 明确主体孔和头部直径/深度/角度、加工方向与起始平面；精确圆柱/圆锥几何，体积/端面及算法失败验证；不让过深沉孔默默变为无底孔 |
| 尺寸标准 | 常用公制螺栓间隙孔尺寸和规格表，标准名称/版本、名义规格与实际尺寸分开保存；修改标准尺寸后明确成为自定义，标准表不冒充完整 ISO 全家族 |
| 参数与基准 | C1 长度/角度字段及 C2 同零件基准帧，源实体/基准/数值驱动原子重算孔与后继；循环、过期、锁层/外部来源及失败原子拒绝 |
| 用户流程与文件 | 新建/编辑、预览/确认/取消、三语言入口与诊断、撤销重做、旧格式迁移/伪装拒绝、保存重开及三格式导出/STEP读回 |
| 螺纹 | 几何孔、符号螺纹/孔标注、真实螺旋实体分别实现与验证；不能把光孔或只写“螺纹”文字当成已完成精确螺纹实体 |

Cadoryx 当前锁定消费已证明基础 `LocalFeatures.Hole` 可用，随后补齐盲孔/沉孔/沉头正例、过深失败及方向反例，并实现配方、命令、来源身份、存储、参数与界面。原生算法可能切到入口后方，应用新增指定方向有限刀具的精确布尔去除量校验；完整证据与当前边界见实施记录。
