# M6：截面、干涉与缓存生命周期

接续七项审阅与交付能力，本轮按三个大阶段实施，全部实现后统一验证。

## 1. 真实截面曲线及文档闭环

属性面板“剖切视图”新增截面名称和“生成截面几何”。选中 1–256 个体，使用上方 X/Y/Z 轴及偏移作为世界坐标平面，与每个实例的真实 BRep 求交。平面覆盖范围来自该体世界包围盒投影并留边，不用有限的固定尺寸近似无限平面。

`CreateSectionCommand` 校验文档、实例路径、体、完整几何引用、世界变换和源特征状态。结果存入一个新独立零件，源体不改动；失败、无交点、取消、目标图层全部锁定或会话代际变化均不提交部分结果。现有事务负责一次撤销/重做、资产租约及失效保护。

截面采用现有 ImportedRecipe 保存冻结 BRep，不新增存储协议。支持 `.cadoryx` 保存重开和 STEP/IGES 曲线交换。它不是自动关联源体的参数化截面，也不生成封口面、工程剖面标注或薄层两侧轮廓；STL 不能表示这些零厚度曲线。原有“应用剖切”仍只影响显示。多个实例的曲线独立保留，不合并重合边。

## 2. 装配实例接触、包含与体积干涉

属性面板新增“检查干涉”，对明确选择的 2–32 个单实体实例逐对计算，最多496对；使用文档线性容差，当前允许 `(0,1] mm`。报告区分 Separated、Touching、Contained、Interfering，记录最小距离与相交体积。混合复合体、片体和网格不作为实体干涉输入。

选择一条结果可隔离、选择并聚焦准确的两个实例，重复零件不会按定义合并。选择改变、文档变更、参数改变、关闭或取消使在途报告失效；结果定位保留当前报告。该检查不修改模型，也不会自动创建装配约束。距离是无符号值；重叠体积为逐对值，不能累加为总体积，也不是穿透深度。

内核接入 `Shape.InspectPair`，临时重叠形状及时释放；后台使用既有串行原生队列，UI持有快照租约并在回写前检查状态。单个已进入 OCCT 的调用不支持强制打断，取消发生于调用边界。

CLI 增加同一能力：

```powershell
Cadoryx.Cli.exe interference assembly.cadoryx --output interference.json
```

CLI 检查文档可见实例，沿用数量限制、原子报告写出及 `--overwrite` 保护。建议对大装配先在桌面明确选择子集，本阶段不是无上限碰撞检测引擎。

## 3. 磁盘缓存异常退出回收

新缓存使用 `assets-v2-<GUID>` 目录和 `.owner` 版本标记。创建时写入标记并持有 OS 独占文件锁。Dispose 后仍有消费者租约时，锁和文件继续保留；最后一个消费者释放后才关闭锁并删除空缓存。Stage 对输入字节先取得独立副本，避免调用者并发写入破坏内容寻址。

WPF和CLI在创建资产存储时自动执行有界回收，默认至多128个候选目录。清理只接受直接子目录、合法版本/GUID/标记、能够取得独占锁且仅包含标记和64位小写SHA256文件名的扁平目录。活动缓存、标记缺失或损坏、未知文件、子目录及重解析点均跳过，不递归删除。清理失败不阻止新会话启动。暂时被占用而删除失败的载荷留给后续清理。

显式诊断入口：

```powershell
Cadoryx.Cli.exe cache-clean "$env:LOCALAPPDATA\Cadoryx\AssetCache"
```

输出扫描、删除、跳过、失败数量和已回收字节。旧版 `assets-<GUID>` 无所有权标记，不能证明不再使用，因此不会自动删除；本阶段只解决采用新协议的缓存生命周期，不扫描或删除恢复文档目录。
