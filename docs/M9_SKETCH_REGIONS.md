# M9：草图区域与自由工作平面

## 范围

M9 在既有草图关联特征上扩展三类闭环编辑：直线、三点圆弧、二次 Bézier 和三次 B 样条可按共享端点组成混合闭环；闭合样条加隐式弦可作为孔；圆、多边形、混合曲线或样条区域可以按孔／岛交替递归嵌套。新建草图可继承文档的自由工作平面，草图圆半径可直接拖动手柄。

工作平面由文档设置持有：预置 XY/XZ/YZ 或自由原点、绕 X/Y/Z 的角度与法向偏移。视口射线求交、网格、捕捉、鼠标实体构造和新建草图读取同一变换。角度采用 Z·Y·X 组合，单位为度。改变设置走文档命令，可撤销／重做。

## 区域与关联数据

`SketchBoundaryCurve` 保留直线与圆弧的旧字段，另有 Bézier 控制点或样条控制点，两种表示互斥。关联特征记录稳定草图实体 ID、草图修订和按方向排序的边链；草图更改后由现有预览／重算事务重新解算，失败不提交结果。

`SketchRegionReference` 将内区域表示为树：深度 1 是孔，深度 2 是岛，深度 3 是岛中的孔，之后继续交替。每个节点恰好引用圆、直线环、混合曲线环或样条区域之一。禁止一个实体在树中重复作为区域边界，也禁止与旧平铺孔／岛选择同时使用。支持最多 64 个节点、最多 12 层；交叉、接触或不严格包含会拒绝。工具箱“识别嵌套区域”从当前草图的闭合环形成树，遇到接触或歧义直接报错，不自动猜测。

特征配方按区域树展开成带孔的轮廓和子岛；每层使用精确 OCCT 曲线建面、拉伸及布尔切除。样条和 Bézier 在拓扑判定时采用 128 段验证轮廓，最终建模仍使用原生精确曲线。对接近采样精度的相切或微小间隙不承诺完整判定，需提高曲线交点验证能力后才能称为任意自由曲线拓扑。现有样条实体仍受 4–8 个控制点、沿弦单调且处于弦单侧的约束；控制点可沿用草图点约束与拖动，未新增曲率连续或样条相切尺寸约束。

## 操作与格式

- 在文档设置的“网格”页选择自由平面，填写原点和 X/Y/Z 角度；新草图“Document”平面继承当前工作平面。
- 草图“Select”工具在圆的右侧显示半径手柄；拖动预览，松开后作为一次草图编辑，同时更新已有半径约束。
- 关联拉伸可勾选样条孔，也可点击“识别嵌套区域”自动收集当前外边界中的闭环；预览和确认复用现有关联命令。
- MessagePack 数字 Key 只追加：document v18 增加自由平面刚体变换；features v20 增加样条孔、混合曲线控制数据和递归区域引用/几何。v17→v18、v19→v20 显式迁移，旧版声明携带新字段会拒绝。

旧功能仍有意保持保守：草图单独二次 Bézier/圆弧段区域不直接接受孔；“识别嵌套区域”只发现已闭合且不交叉的环，不自动修复分叉或断端；物理混合 DPI、RDP 和长时间手柄操作需在对应设备验收。
