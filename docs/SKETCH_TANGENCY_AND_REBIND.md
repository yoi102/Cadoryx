# M4-S3m–r：圆孔换源与草图角度约束

本文保留当时的阶段范围；后续 M4-S3s–x 已增加闭合直线多边形孔，见[多边形草图通孔](POLYGON_SKETCH_HOLES.md)。

本轮连续完成六项交付，重点是让已有带孔拉伸可继续编辑，并在草图中提供切线和角度尺寸。圆弧与非圆形孔仍保留为后续独立阶段。

1. **任意数量圆孔的显式选择**：在拉伸外轮廓下提供逐圆勾选，可选择模型上限内的任意组合；原单孔和少量孔组合仍可从来源列表直接选取。预览会对勾选后的整体区域做严格包含、相切及重叠校验，不把未勾选的圆自动当孔。
2. **已有拉伸的原子换源**：编辑关联拉伸时可改变外轮廓或孔集合。`RecomputeCommand` 先核对新来源的草图、零件和修订，再在隔离候选中重算根特征及后继；失败不提交。关联与冻结模式切换仍需新建特征，旋转仍不接受圆孔。
3. **直线与圆相切**：新增稳定 ID 的 `TangentConstraint`，约束圆心到有向直线的距离等于半径。求解保持创建约束时圆心所在的一侧；几何定义为直线的支撑线，不限制切点必须落在线段内部。
4. **两直线角度尺寸**：新增 `AngleConstraint`，编辑器以度显示和输入，协议和求解器以弧度保存。角度依赖两条直线的端点方向，允许严格处于 0° 与 180° 之间的值；精确平行关系继续用已有平行约束。
5. **草图协议与兼容**：写出器 `0.4.19`，`sketches` v3。MessagePack 约束白名单增加切线与角度；v2→v3 显式迁移并拒绝把新约束伪装成旧版本。旧 v1→v2 修订迁移仍按原顺序执行。`features` 保持 v12，已有特征换源沿用稳定孔 ID，无新特征字段。
6. **验收链路**：定向测试覆盖求解、9 孔选择与已有特征换源、过期来源失败不提交、撤销/重做、v3 往返与旧版迁移；生产恢复种子同时保存带孔实体、角度与切线约束。最终构建、测试、发布、窗口、草图鼠标和强制终止恢复门禁结果以 [ROADMAP](ROADMAP.md) 为准。

本轮不宣称圆弧/样条轮廓、非圆孔、自动拓扑命名或完整全局约束求解已完成。局部自由度和非线性求解失败仍按现有求解器语义报告，不将未收敛推断为几何冲突。
