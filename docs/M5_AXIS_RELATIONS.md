# M5：局部锚点与轴关系三个大阶段

本轮连续推进三个大阶段，最后统一验收。轴向关系采用显式输入的实例局部轴线，不从拓扑面或边暗中推断。完整机械配合求解仍是后续任务。

| 大阶段 | 已实现行为与边界 |
| --- | --- |
| 局部锚点可编辑 | 属性面板可输入参照与移动实例各自的局部点。重合、距离关系创建时使用这些点；已存在的点对关系可通过文档命令修改，参与撤销、保存和恢复。固定关系拒绝修改点对。 |
| 平行轴与同轴单关系调整 | 关系保存局部单位轴向及局部点；无向轴方向相反也视为平行。显式调整时只修改第二实例的刚体位姿：平行轴绕其锚点旋转并保持锚点世界位置；同轴再消除到参照轴的径向偏移，保留轴向滑移。共享父装配、路径/定义失效、拓扑来源未获支持或破坏其它已满足关系时拒绝调整。没有多个约束的全局求解或运动学。 |
| 属性面板、诊断与兼容文件 | 属性面板可创建平行轴/同轴关系，编辑两端局部点与轴向、查看角度及径向误差、显式调整或重新指定路径。`document` MessagePack 节从 v13 升到 v14，追加两个轴字段；v13 点关系迁移后保留原身份和参数并获得空轴字段，旧 v12 仍先迁移为空关系表。发布版桌面冒烟覆盖同轴关系输入与调整，测试覆盖数值几何、冲突、撤销和往返。 |

可选精确拓扑来源仍只是失效诊断；尚未实现从面、圆柱或边自动求轴。轴数值为当前定义坐标中的输入，定义更换或实例路径消失时必须显式重新指定。外部零件链接、面贴合、角度驱动、自由度报告和全局求解不在本轮范围内；新能力只使用托管刚体数学，不需要新增 OcctSharp API。
