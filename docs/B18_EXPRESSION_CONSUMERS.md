# B18 表达式轮廓与路径消费者

2026-10-07。A–F 继续，G 暂缓。这是 B18 的消费者子阶段，不是 B18 或全部 A–F 完成。

非构造表达式现在可按明确作者 ID 出现在拉伸、旋转、扫掠截面和放样列表中，并可作为有向扫掠路径。独立开放曲线沿用已有曲线与闭合弦的轮廓约定；直线表达式只提供路径，避免零面积轮廓。端点已有外接边时只提供显式闭合链，不另加隐式弦。画布继续显示独立曲线的闭合弦。构造、缺失、未解端点、过期来源、外部零件、重复路径 ID 和错误顺序均拒绝。

路径保留原始表达式、有限域、作者方向、明确 Reverse、草图来源和版本。关联截面及路径可以随参数重算；构造切换或删除来源冻结后继，并保持最后有效结果。撤销、重做、JSON/MessagePack 保存重开及恢复已验证。没有新增最近坐标连接或原生拓扑自动重绑。

## 两个实际内核问题

开放二次 Bézier 的 .03 mm 偏移轮廓沿单条直线扫掠时，原管道算法报告 Ready/Done/Solid，但 ShapeIsValid=false，两个面为 UnorientableShape；输入截面及路径有效。原始输入、拒绝结果和诊断见 [管道证据](../artifacts/b18-expression-consumers-pipe-evidence-1/diagnostics.json)。

两个同形、同向偏移截面的直纹放样原来得到有效 BRep，但体积 1.5150723565356226 mm³，与独立解析积分 1.5150894465900901 mm³ 相差约 1.71e-5 mm³，超过原 1e-7 要求。12 项新增回归全部复现偏差，见 [放样诊断](../artifacts/b18-expression-consumers-loft-evidence-1/loft-diagnostics.json)和第一次失败 TRX。

单条基本直线、或明确以基本直线为基曲线的表达式路径，固定截面的扫掠现在用沿实际世界位移的精确 prism。其余路径仍走管道算法。两个截面、Ruled=true、旋转值相同且全部有向轮廓值相同的放样，也采用数学等价的精确 prism；其他放样保留原算法。实体使用精确面，薄壳使用精确 wire；圆/直线沿用原有代数等价表示，一般偏移保持真实 OffsetCurve。没有拟合作者曲线，也没有放宽姿态、有效性、自交、孔岛包含、正体积、正面积或单实体要求。
