# F3b：模板库、自定义栏位、图框分区和制造备注

更新：2026-10-03。属于用户已授权的A–F和[F3联合计划](F3_ASSOCIATED_MANUFACTURING_ANNOTATIONS_PLAN.md)。本页记录模板复用的实现；有效孔表、完整制造规则、新特征历史和A–F其他余项继续，第七批暂缓。

## 用户入口与复用

工程图“图纸”页新增模板库、自定义栏位和制造备注、图框分区三个展开区。模板库可以保存当前已应用的图纸设置为新模板、明确替换所选模板、应用、删除，以及导入/导出`.cadtemplate`文件。库随文档保存，最多64个具名模板；名称按忽略大小写和首尾空格校验唯一。跨文档复用通过独立模板文件完成，不依赖用户安装目录。

模板是纸张尺寸、单位、制图约定、标题/作者、图框、标题栏和额外作者内容的独立快照，没有视图、实体、资产、实例路径、拓扑或标注来源。应用模板保留目标图纸ID和名称、全部视图/投影位置与比例、尺寸和关联标注来源，不重新排列模型内容。复制时为栏位和备注分配新的ID；后续编辑模板或删除库条目不改写已经应用的图纸。制造图框才可保存模板，旧简式图框可以明确保留，不自动迁移成制造图框。

应用较小纸张时，若已有零件表或新作者内容越界，整次操作拒绝，不移走内容或只应用部分字段。各编辑进入既有事务、撤销和重做；历史插入仍禁止改写保留的模板/图纸作者内容。

## 图纸内容与共同输出

自定义栏位有稳定ID、标题、值、毫米位置、宽度和高度，支持添加、编辑/移动和删除。制造备注有稳定ID、毫米位置/宽度及明确换行文本；同一编辑入口可以选择栏位或备注，不能用更新操作暗中把一种内容变成另一种。

每张图纸最多32个栏位和32个备注。栏位标题48字符、值128字符、高度8–50mm；备注最多20行，每行96个可打印字符。最小宽度20mm，备注的行高固定为4mm。文本使用既有字体测量和单行最大宽度显示，备注换行由作者控制，不根据打印机器隐式重新分页。

栏位和备注必须完全位于图框内，不能互相重叠，也不能覆盖标题栏及其上方投影符号保留区。视图内容按作者放置，不作自动避让。图框分区可以开关、设置列/行数、反向数字和字母；上限32列/26行，每区至少20mm。分区刻线和标签位于四边页边空白中，仍须在纸张范围内。这里提供可配置图框内容，不宣称完整制图标准认证。

新增矢量线、栏位、备注和分区进入共同`DrawingPageLayout`，WPF、PDF和打印使用同一布局。三语言翻译用于产品编辑入口；模板中的作者文本原样保留，图纸标准栏位仍由其打印标签语言决定。

## 文件与迁移

drawings v7在图纸书追加模板库，并在制造图框追加栏位、备注和分区；新必需能力`cadoryx.drawing-template-library.1`。document39/features35及其他schema不变，锁定上游仍为`8.0.1-preview.31.cadoryx.curve-inspection.6`，本段没有新原生能力或包。

v6→v7是独立迁移：旧版必须没有新字段，显式空模板数组/栏位数组同样拒绝夹带。真正旧版样本清除新增字段，迁移后原布局、来源和缓存保持。v5→v6及更早各独立迁移仍执行，不跳级。

独立`.cadtemplate`为版本1、最多128KiB的单模板JSON；禁止未知字段，不承载模型、视图或来源。读取先验证版本、全部作者数据及范围，导入为新库ID；损坏、重名或超量时不发布文档。导出先验证全部内容，然后在同目录写临时文件并原子替换，失败保留已有文件。
