1. 为表达式保存稳定起终点 ID 和明确的端点方程 ID。方程为 `P_endpoint - E(source variables, u=0/1) = 0`，每端点两行；使用解析 AD 及明确单侧导数。端点作为真实求解变量，继续计入原 256 变量/512 方程预算。不能用捕获坐标的 FixPoint 代替关联端点。
2. 构造曲线可没有实体端点；非构造曲线必须具备完整端点作者。显式共享端点应保存用户选择，闭合接缝和多条曲线共端点不能按坐标近似自动合并。合并/拆分/删除需明确重选和原子历史。
3. 增加由端点点 ID 到表达式作者的依赖边。源直线、圆/弧、Bézier、样条控制点可能引用表达式端点，应连同 Source.Expression 检测循环；冻结/解除来源保留自己的定义，不按遍历顺序猜依赖。
4. 求解后同时复验源变量、表达式作者值和端点方程；草图提交再用现有整段原生正则性认证。G1/G2 的共端点方向和曲率应使用同一精确求值/解析敏感度，不通过显示采样或有限差分求生产 Jacobian。
5. 对独立表达式分区显式再迁移；旧 JSON2/MP3 关系和原几何 schema1 保持值。新增端点字段和隐式关系不能夹带到旧文档或旧分区。基础 sketches21 必须仍可独立严格解码，表达式和自身关系挂载后统一验证。
6. 接通 SketchProfileBuilder/SketchProfileReference、混合显式有向链和孔岛消费者，再接 Canvas 绘制/命中、实体选择、距离/方向/连接、预览/确认/取消、撤销重做和三语言窗口。新增默认边界能力前先验证所有 typed registry、删除/修剪/投影及后继重算路径。

验收至少包括：源控制点/半径驱动真实端点移动；共享端点 G1/G2；源经端点循环拒绝；冻结/解除/恢复；参数驱动和后继原子重算；保存重开/恢复；损坏/降版数据拒绝；真实原生 wire/face/solid；三语言实际操作。最后同一最终构建完整回归和作者窗口通过后才提升 B18 状态。

作者结构校验与求解后关系校验要分开：预览候选可包含尚未求解的端点位置，端点方程 ID/目标/角色必须完整；求解后须独立复验端点一致性，轮廓消费者也须拒绝不一致的端点。关联端点方程不能通过普通“禁用约束”破坏曲线作者结构，界面应说明端点关联，避免把内部方程字段暴露为用户操作步骤。

共端点 G1/G2 沿用“从接点向外”的约定：起端使用有向参数0的切向/曲率，末端使用有向参数1且两者都翻转符号；两曲线平滑连接仍要求向外切向反向、向外有符号曲率和为零。曲线自身的 Reverse 和共端点末端符号必须分别处理，不用采样位置相同替代方向证明。

主要接入点是 `SketchExpressionEntities` 的作者/来源表、`SketchEndpointTangency`/`SketchEndpointCurvature` 的端点与单侧求值、`SketchEquationSystem` 的隐式方程和解析 Jacobian、`SketchProfileBuilder`/`SketchProfileReference` 的类型注册，以及独立表达式分区的严格迁移。现有 `SketchFixedCurveEndpoints` 要求固定锚点，不能直接套用到关联偏移端点。
