# B1：直线修剪/延伸与解析曲线旋转

日期：2026-09-30。属于 [产品规划](CAD_PRODUCT_GAPS.md)的 B 批首个有界实现；不代表 G03/G06 或整个 B 批完成。

后续 [B2](B2_CURVE_EDIT_OFFSET_PROJECTION.md)已扩展解析曲线编辑、单实体偏移和草图关联投影，并把 sketches 升到 v7。本文以下记录 B1 当时的范围、v6 格式和验证结果；最新验证见 [STATUS](STATUS.md)。

## 契约与交互

- 修剪：点击目标直线的待删区间，按其它有限直线的解析交点切除。交点处点击、没有内部交点、共线边界均拒绝。
- 延伸：点击靠近待延伸端的一半直线，沿该端射线找到最近有限直线交点；中点点击、无交点和共线歧义均拒绝。构造直线也可作为边界。
- 不移动共享端点；单段编辑保留直线 ID；修剪成两段时两段均用新 ID，旧轮廓引用必须失效，不自动选一段。唯一的已有边界端点可共享；多个端点身份重合时拒绝。
- 删除引用被编辑直线的约束，以及不再被几何使用的旧端点及其约束；共享旧端点和其它几何不动。界面明确显示移除约束数，确认前必须预览；草图草稿一步撤销/重做，文档预览/确认保持现有原子事务。
- 旋转新增完整圆、三点圆弧加闭合弦、直线—圆弧混合闭环；不含孔/岛。草图 X 表示非负半径、Y 表示轴向位置，映射到局部 XZ 面并绕 Z 轴旋转，再应用放置变换。圆须严格离轴；圆弧按端点和圆周极值解析验证，不用显示采样判断穿轴。多边形仍允许边/顶点落在轴上。原生 BRep 合法性检查继续负责最终实体验收。
- 持久化：features v22 增加 `revolve-circle`、`revolve-arc`、`revolve-mixed` 配方种类，复用已有数值/曲线字段；新增必需能力 `cadoryx.analytical-revolve.1`。v21→v22 不改旧数据，但拒绝旧版本伪装的新配方。document v20、sketches v6 保持不变。旧旋转多边形现在也须满足非负半径/不穿轴，原来未检查的负半径或穿轴配方会明确拒绝。
- 交点处的新端点为精确坐标，不自动给边界增加分裂或驱动约束；后续移动边界不会自动带动这些新端点。

## 验收与后续

已核对：端部/内部修剪、最近交点延伸、约束与共享端点、歧义拒绝及失败不改草稿；圆/圆弧/混合旋转体积与 BRep、关联预览/重算、撤销/重做、文件重开、版本拒绝和桌面操作。分裂已关联轮廓时，确认命令整体失败并保留原文档。

尚未包含：曲线修剪/延伸、曲线偏移、外部关联投影、更多约束、Bézier/样条旋转、带孔/岛旋转、自定义旋转轴。A 批实物鼠标/触控板、IME 和 M14 硬件性能门禁仍需独立证据。
