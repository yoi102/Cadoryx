# B15 混合有限参数 G1/G2 接触

2026-10-05。继续第 4 节 A–F 的草图关系缺口，G 交付暂缓。D5 最终冻结全量独立运行，本批采用新构建目录，不覆盖其程序集或证据。

扩展同一有限参数接触作者，支持线段、三点圆弧、圆、二次 Bézier、非有理三次作者样条、固定精确椭圆和已有复制的有理自由曲线之间的 G1/G2。参数是各曲线原始有向有限域的归一化参数，仍显式选两条曲线、两个内部参数和同向/反向。G1 为位置及切线；G2 另要求有符号曲率在明确方向下相同。反向关系比较相反符号的曲率，不把镜像或相反朝向误作失败或同向。

参数不自动移动到另一交点；不合并点 ID。圆从局部 +X 按逆时针参数化；三点圆弧由中点选定有向弧；椭圆和复制自由曲线保留已有有限域、反向和精确数字定义。固定复制曲线参与接触，不被求解器偷偷变形；可变作者点和圆半径由约束求解。对导数不确定的重复结点或周期缝，必须核对所需导数连续阶数；无法证明就拒绝，并保留旧作者。

先用锁定 SDK 独立消费者核对点、一阶/二阶导数和方向，再以真实原生曲线复证应用解析计算。求解 Jacobian 使用解析链式微分，生产路径不采用坐标差分。保留 256 变量/512 方程、线性/角度/曲率公差、退化导数、曲线有效性、取消与原子发布守卫。G1 计三行，G2 计四行，不能漏算预算。局部求解失败不报告全局无解或唯一。

实施包括三语言创建/编辑及明确 G1/G2 字段、参数驱动、实体/图纸后继、独立化、修剪/分裂引用清理、撤销/重做、保存重开、独立格式迁移及旧格式夹带拒绝、严格结构化作者；分别保留专项、联合、全量、冻结窗口、独立消费者和视觉证据。全部验收前不标 B15 完成，其他 A–F 待办不因本批缩减。
