# F5：保留实际原生来源读取

本批修复来源读取在长上下文里的丢失，不宣称工程图供应商已通过。原 drawing3 在请求23/24保留完整 CylinderFace，但请求25–30已将那次成功 `inspect_sources` 及其助手调用对删除；模型随后重复前八次查询，第三轮达到原16工具轮上限。原提示含完整路径，不能归因于验收提示缺少文档根。

上下文现在同时保护本用户轮最近一次完整成功写和最近一次完整原生来源读。读取必须与真实 `cad_drawing.inspect_sources` 调用成对、身份/页码及所有暴露的来源上下文匹配；失败、重复属性/调用ID、孤立/不完整批次和其他工具不能获得保护。新用户轮、后续成功写或工作区变化不保护旧来源；后续 `cad_status` 显示不同文档/状态或无活动文档也会取消保护。预算不能容纳完整交换时仍删除整组调用/回执，并明确要求重新读取，不伪造半条收据或选择。

原6000/2400回执和8192上下文/1024输出预算保持。补充项按已返回的几何种类保留完整原行；小预算可保留有界子集，优先较少出现的种类，省去可选提示。它只安排上下文呈现，不挑选对象、不猜索引/距离或重绑身份；每个来源索引、指纹、资产和修订逐字段保持实际读取结果。前缀仍是原连续行，额外行计数和查询位置单独说明。预先计算前缀字符下界，跳过必然超预算的序列化候选。连一整行都不能容纳时明确无可用选择。

[实际会话夹具](../Cadoryx.Tests/Fixtures/AgentContext/NativeSelectionRetention/before-request30.json)逐条复制原响应、回执和用户轮，输入引用及SHA保存；没有重写原三份提供方C#、提示或预算。原模型并未在本轮重跑，第三轮16轮FAIL保留。新32项加原分页13项，Release/Debug各45/45；独立适配器身份夹具各4/4，与产品测试分列。原截断40项两配置各40/40。保持最终测试DLL/依赖/夹具、只换原Agent DLL时，两条实际上下文重放均失败（0/2），修正后两配置通过；这些结果不是STEP24。

为了不反复运行用户延期的严格STEP，[精确过滤工具](../tools/CurrentCadCandidate/deferred-step-filter.ps1)只按原24个完整display name排除。已用实际xUnit适配器核对布尔、字符串、小数和枚举参数，保留同一方法所有其他兄弟用例。过滤前必须确认当前真实发现名单包含那24项，过滤后TRX必须恰好等于当前发现减精确24、其余全部通过。缺原项、额外遗漏或非零退出都会拒绝；不修改测试属性、公差或断言。当前整应用尚未重新发现，此工具是已验证准备，未用于原生STEP执行。

xUnit会截短过长的字符串参数，不同用例的display name可能相同。非延期案例必须按真实次数核对、每个testId只执行一次；原24延期名称则必须各唯一，歧义不能靠排除整个名称猜测解决。实际transport40中的同名参数已验证可审计；少执行一次的反例被拒绝。此验证是适配器与审计工具验收，不是严格STEP已通过。
