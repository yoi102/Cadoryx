# M4-S3g–l：关联拉伸的精确圆孔

本文保留当时的圆孔阶段范围；后续 M4-S3s–x 已增加闭合直线多边形孔，见[多边形草图通孔](POLYGON_SKETCH_HOLES.md)。

本文保留 M4-S3g–l 当时的范围。后续不限 8 个圆孔的勾选和已有特征换源见 [新阶段文档](SKETCH_TANGENCY_AND_REBIND.md)。

这一组六阶段在直线闭环或完整圆外轮廓内，支持用户明确选择一个或多个完整圆作为拉伸通孔。孔与外边界、孔与孔之间必须有严格间隔；相切、相交、越界和构造圆都不能生成该区域。圆弧、非圆孔与带孔旋转仍不支持。

1. **S3g 区域规则**：`SketchProfile` 保存外轮廓和最多 64 个圆孔，验证每个孔的有限中心、正半径、严格包含和孔间分离。多边形沿每条边计算最近距离；圆外轮廓按圆心距检查。区域不能靠边界的数值容差为 `1e-7 mm`。
2. **S3h 精确实体**：OCCT 用现有 `CreateCircleEdge`、`CreateWire`、`CreatePlanarFace`、`Extrude` 和 `Shape.Cut` 从外部拉伸体逐孔切除。切刀略越过两端面，避免共面布尔不稳定；每个临时 native 对象由当前计算持有并释放。无需增加 OcctSharp 封装。
3. **S3i 稳定引用**：`SketchProfileReference.HoleCircleIds` 保存明确选中的草图实体 ID，解析时重新验证同一草图、零件、修订和非构造状态；特征缓存逐个比较孔中心及半径。编辑草图后重算特征及后继闭包，非法结果不提交，也不靠位置猜测新孔。
4. **S3j 选择入口**：建模面板保留无孔外轮廓，并列出每个合法单孔和最多 8 个候选孔的合法组合。选择项显示圆编号；其它圆不会自动成为孔。超过 8 个可用孔时面板只提供单孔选择，数据模型仍可容纳最多 64 个孔。编辑既有特征时锁定来源下拉框，避免界面显示切换成功但命令仍使用旧来源；现阶段须新建特征才能换孔组合。
5. **S3k 文件协议**：写出器 `0.4.18`、`features` v12、能力 `cadoryx.circular-sketch-holes.1`。配方 Key(6) 保存圆孔几何，草图引用 Key(4) 保存有序孔 ID；v11→v12 仅接受没有新字段的旧记录，拒绝改清单版本来冒充旧文件。旧 v11 单圆拉伸可显式迁移。
6. **S3l 联合验收**：定向测试核对多边形双孔与圆环真实体积、放置、非法边界、关联半径变更、撤销/重做、失败回退、v12 保存重开、v11 迁移/伪装拒绝以及 STEP/IGES/STL。恢复冒烟种子含圆环引用和实体。独立 NuGet 消费探针增加真实通孔布尔场景；最终门禁结果以 [ROADMAP](ROADMAP.md) 为准。

圆外轮廓目前只能拉伸；旋转保持单一直线闭环。多闭环自动区域识别、圆弧/混合曲线轮廓、相切与角度约束、任意数量孔的交互式多选、修改已有特征的孔组合留待后续阶段。

最终联合验证：Release 零警告/错误，410/410 测试及桌面/窗口/强制终止恢复冒烟通过；时间戳 20260924-200517。独立 NuGet 探针 22/22、62/62 原生 DLL 匹配。草图物理鼠标、混合 DPI/RDP、长期资源和大型模型仍另行验收。
