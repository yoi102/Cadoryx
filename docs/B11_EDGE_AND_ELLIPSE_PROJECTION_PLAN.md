# B11 实体边与椭圆投影

更新：2026-10-03。A–F 的 B/G03 继续；G 第七批暂缓。

## 顺序和完成边界

1. 复制值的仿射椭圆与有限区间：解析点/导数，主轴变换保持参数方向；消费锁定包已有 `SketchCurve2d.EllipticArc`，不以折线或非有理三次样条替代椭圆。
2. 明确选择的 BRep 边：文档/特征/资产/修订/指纹/拓扑种类核验。先覆盖解析直线、圆及椭圆有限边；投影退化到点或直线时拒绝。原生导数与已证明解析类型确定系数，禁止拟合若干采样点猜曲线。
3. 草图数据、关联重算、缓存核验和迁移：斜向草图圆/弧投影和实体边来源，源修订改变的冻结/唯一证明延续与显式重选；改变草图平面后重新核验，拒绝循环及跨零件隐式引用。
4. 生产入口、选择/预览/取消/确认、驱动保护/解除来源、撤销和保存重开；三语言诊断，闭环/孔岛建模及后继精确重算。

仅数学值与内核 API 通过时属于核心进行中，不能标为 G03 完成。实体边样条/Bezier 的完整复制值定义与后续精确关系若缺底层 API，先以锁定消费者证明，不把未知边降级为折线。独立复制与关联投影语义必须显式。

## 验证

对斜向、反射、反向参数、非零起点、完整圈和有限弧分别核验原生点/导数/交点/面积。实体来源覆盖同资产不同修订、伪造值、错误指纹/类型/零件及关闭/迟到租约；编辑与存储不能自动凭遍历顺序或相似几何换来源。

本批未要求新增安装包、签名或公开发布。

## 原生自由曲线接入顺序

锁定 NuGet 消费者 `artifacts/b11-freeform-capability-3` 已通过49场景和62原生DLL哈希核验。新场景验证有理二次Bézier、非均匀四次B样条和周期三次B样条：`FreeformAuthoring.GetCurveDefinition` 复制完整定义，线性投影各控制点后保留权重、结点、重数、次数和周期，`SketchCurve2d` 精确构造并按实际参数域裁剪，原生点/导数和独立生命周期一致。不得以该能力证据替代应用实施。

1. 建立独立于旧作者三次样条的不可变自由曲线数值类型，完整保存几何族、控制点、权重、结点/重数、次数、周期、有限原生区间及有向参数。验证容量、正权重、支持参数域和结点关系；不能丢掉高次或有理定义。原生返回的导数按实际参数域转换为应用的归一化导数。
2. `ExactSketchCurve`、投影证据及来源重验支持完整新类型，控制数据必须逐值核验。显示离散与精确模型分离；任意曲线关系继续使用已证明的内核交点/投影/区域服务。
3. 草图实体、关联或独立复制、显式重选/解除、驱动保护、求解器篡改防护、作者图独立化和旧来源资产保留同时接入。数值固定定义不能伪造可拖动的自由度；新增数值字段的参数表达式适配单列跟踪。
4. 按新版本追加存储字段与迁移守卫；轮廓、混合孔/递归岛、扫掠/放样及拉伸/旋转的桥接必须使用完整精确定义。有限曲线混合链使用明确作者端点身份，消费者不能按距离或遍历顺序重绑。
5. 扩展同一生产选边窗口和三语言诊断，验证真实控件的选择/取消/旧状态/重选/确认、保存重开、关闭租约及后继精确几何。完成对应应用全量和窗口证据后再更新该范围状态。
