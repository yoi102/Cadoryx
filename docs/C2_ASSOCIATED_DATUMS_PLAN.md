## 来源与身份原则

先覆盖可证明的基准来源：文档/零件基础框架、已有命名基准，以及有显式语义契约的基本体平面。已有 `AssemblyDatumReference` 包含 occurrence、定义/实体、资产/修订、指纹、几何类型及完整拓扑索引；若采用任意 BRep 面，必须复用其证据检查并规定过期后显式重选，不复制缓存平面后称为持续关联，也不按距离、索引或法线猜测重绑定。

基本体语义平面随尺寸变化的延续必须由具体配方和边界语义证明；Boolean/倒角/圆角后的任意面不能沿用 Box 语义。中间平面和角度平面的方向/绕向保存在契约中，不能由一次内核遍历改变。

## 实施次序

1. 稳定基准类型、依赖/循环、局部框架以及来源证据；明确过期/解除规则。
2. 偏移/中间/角度构造，C1 参数目标适配和联合依赖求值。
3. 草图/工作平面绑定与原子草图/特征/图纸更新，复用现有求解器意图检查。
4. 独立存储节及旧文档显式空表迁移，旧版夹带新字段拒绝。
5. 三语言窗口、原生样件、失败注入与同版回归，按真实结果更新状态。

随后推进 C3 镜像/线性与圆周阵列，以及 C4 常用通/盲/沉孔/沉头；它们继续使用 C1 的量纲和驱动绑定，并分别验证输出身份、依赖、后继、失败回退和持久化。D、E、F、A 的待办不因 C2 开始而取消。
