# B8：曲线及孔岛旋转闭环

属于已授权 A–F 的 B/G06；第七批仍暂缓。继续完成现有 Bézier/样条、孔及嵌套岛的旋转，不将这批当作整个请求的终点。

1. 先由当前锁定包的独立消费者验证精确 Bézier、B-spline 及带孔面的部分/整圈旋转。结果必须使用原曲线的 BRep，不通过显示折线重建；验证局部有效性、自干涉和独立几何/解析体积。
2. 旋转轴继续为明确手动线或 C2 关联基准轴，位于作者子午平面。沿轴法向的坐标极值用曲线多项式/导数计算；不能只检查控制点、起中终点或采样点来判断轴穿越。保留端点接轴的有界合法契约，内部曲线切轴/穿轴明确拒绝。
3. 外环、圆/多边形/混合/样条孔及嵌套岛保持作者明确选择。精确原生区域核验补充托管预检；孔、岛的旋转与父级执行精确差集/独立输出，断开的材料区域明确为多实体，不假装单Solid。
4. 草图来源、参数角度、关联轴、取消/算法失败回退、后继失效及完整配方编辑保持一致；来源只由作者明确配置，不自动搜索相似轮廓。
5. 存储声明新旋转种类及孔岛能力，顺序迁移拒绝旧schema伪装携带新语义，保存后重开/编辑/解除来源保留曲线和选择身份。
6. 补核心正反例、草图/轴/参数及Boolean后继、保存/畸形输入、三语言生产入口和原生截图；测试、WPF Automation与真实物理输入分列。

这一批仍采用已存在的有界均匀三次样条作者契约。任意合法控制多边形、非均匀结点与精确草图交点继续归 B/E/G05 后续实现，不能通过本次旋转入口扩展隐去其待办。A 性能、C 螺纹、D 曲面终止、E 历史/装配和 F 制造/交换/命令继续。
