# B10 多环、孔和岛的草图偏移

更新：2026-10-03。属于 A–F 的 B/G03；本地解析范围契约完成，46 联合专项、1239 全量及三语言生产窗口通过。整个目标继续，G 第七批暂缓。

## 契约

选择每个需要参与的边界上的一条边或一个圆；同一边界多边选择自动去重。只处理明确选中的边界，未选孔不会被隐式加入。多个独立根允许一起偏移。原边界必须是隔离的解析直线/圆弧闭环或圆，彼此严格不接触。按精确有限交点与包含关系建立所选边界的父子树。

正距离扩大所选材料区域：外环和偶数深度岛向外，奇数深度孔向内；负距离反向。尖角连接沿用单闭环 20:1 miter 上限。塌陷、接触、自交、分裂、合并或包含关系改变时整次拒绝。64 边界、12 层及每条混合边界 256 边预算；Bezier/样条偏移需要另立精确契约。

操作创建独立作者点/边/圆及明确的新边界 ID，不复制原驱动约束或建立隐藏关联。原草图及引用保持；结果树可作为已有递归区域配方的显式输入，无存储格式变化。整次草图局部撤销/重做和正常预览确认/取消沿用生产编辑器原子流程。
