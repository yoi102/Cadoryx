# B7：扩大下一批——草图尺寸、倒角和多角编辑

## 实施顺序与依赖

1. **先定义 B7-1 的约束语义和迁移。** 检查现有圆半径求解路径和锁定包的原生混合轮廓能力；如果扩大既有约束目标，单独提升 sketches 语义版本和必需能力。旧版仅圆目标保持兼容；伪装成旧版本的圆弧目标（包括禁用约束）明确拒绝，不只改 UI 类型检查。
2. **实现 B7-1、B7-2 的单角编辑和验证。** 复用 B6 的安全裁剪契约；为批处理输出明确编辑结果（旧端点、相邻原线、新连接实体/切点、受影响约束），该结果不能依赖空间距离匹配。
3. **实现 B7-3 的联合几何预算。** 基于原草图一次计算所有裁剪，不把第一角的局部结果反复作为下一角的原输入。所有剩余线长、闭环和自交检查完成后才形成一个候选。
4. **实现 B7-4 的引用事务。** 基于旧快照核对用户选择的旧轮廓及唯一相邻次序，明确展示转换后引用，在同一候选里求解、更新引用、原子重算；严格保留其他受影响引用的阻断。关联旋转仍遵守现有穿轴与解析轮廓限制，不借此开放孔岛/Bézier/样条旋转。
5. **收敛 B7-5、存储和全链回归。** 候选参数、编辑对应和选择状态按真正需要的最小字段设计；临时编辑对应优先不写文件。只有需要长期重放的关系才持久化，禁止保存暂时性指针或依赖遍历序号。

B7-1 与 B7-2 是基础，B7-3 依赖单角构造与对应结果，B7-4 依赖批处理对应和身份验证，B7-5 贯穿全部项。本计划不要求并行 agent，也不以多代理替代依赖检查。

## 联合验收样件

建立 40×30 mm 支架底板草图：先做两角 R3、另两角 2×3 mm 倒角，添加圆弧等半径并拉伸 5 mm；创建关联图纸，再将 R3 改 R4，核对精确解析面积/体积和图纸更新。另建符合既有旋转轴限制的单外环样件，验证明确转换引用后的旋转重算。

对每个样件执行创建→候选预览→取消→重新预览→确认→参数修改→撤销/重做→保存/重开。失败样件包括相邻两圆角吞线、批处理中一个非法角、受驱动投影、半径与固定点冲突、未选中的受影响特征、失效的编辑对应及文档代次变化；每个失败都核对原快照/资产未发布。

验收记录包括：锁定还原、Release 零警告/错误、针对新增行为的自动测试与全量回归、真实 OCCT BRep、旧版本迁移和伪装旧语义拒绝、发布版桌面与 B1–B6 草图回归、三语言截图与绑定/资产结果。记录实际命令、构建目录和失败/修复过程，历史失败不得被后续 PASS 覆盖。
