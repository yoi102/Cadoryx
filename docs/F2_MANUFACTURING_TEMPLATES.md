# F2：制造图框、纸张与标题栏

更新：2026-10-03。整个A–F请求继续，第七批实机、安装及交付暂缓。本页记录已经实施并验证的模板机制；GD&T/基准、关联孔表和交换/命令仍继续。

工程图窗口的新建图纸采用制造模板。用户可选择A4/A3/A2/A1/A0、ANSI A–E、横向/竖向，或自定义纸张；输入明确图框左/上/右/下边距。预设尺寸严格以mm保存，不随图纸显示单位改变。工厂默认ISO/GB为A4第一角，ASME为ANSI B第三角；窗口中的制图惯例、投影法与纸张均为明确可编辑选择，不根据视图位置猜测投影法。

标题栏包含图号、版本、单位、名称、材料、表面要求、一般公差、设计、审核、批准、日期、投影法、视图比例、纸张与张数。日期使用yyyy-MM-dd并校验真实日历日期；材料/表面要求/公差是用户填写的制造声明，不从模型或自由文本推断。混合比例显示“见视图”，各视图仍显示自身比例。投影符号由矢量线段画出，不依赖特殊字体字形。打印标签可保存为英文、中文或日文，重开或更换界面语言不会改变已保存图纸的标签语言。

图框和180×60mm标题栏由领域层的共同布局产生，WPF预览、矢量PDF与现有打印路径消费同一布局。模板字段按单元格容量验证，渲染按实际字体宽度缩小，PDF不接受小于1.5mm仍才能容纳的文本。旧版简易图框保留原8mm边距、标题栏与标签；旧文件迁移不改已有布局。用户可明确切换回旧图框，并通过撤销恢复制造模板与字段。

新模板的编辑、纸张尺寸、边距、标签语言及投影法都进入既有事务和存储；更改图纸模板不移动模型视图、不重绑尺寸，也不改源BRep。drawings v5追加模板字段；v4→v5独立迁移并拒绝旧版本夹带新字段，必需能力为cadoryx.manufacturing-templates.1。F1材料规则的v3→v4迁移独立保留；document39/features35等其他schema和curve-inspection.6上游包均不变。空规则、错误边距数组、缺失标题字段等损坏数据返回格式错误，不发布部分文档。
