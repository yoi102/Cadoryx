- `thick-solid-selected-closing-face`：10×12×15 盒，明确选择顶面、向内壁厚 1 mm，最终体积 **680 mm³**；exact BRep 有效，原生全局自干涉检查清晰，源体积仍为 1800。输出独立持有，可在源和面释放后继续使用。
- `face-draft-explicit-neutral-plane-and-programs`：明确选择 X 两侧面，XY/Z=0 为中性平面，拉拔方向 +Z；每面独立角度 0.05/0.1 rad，SelectedFaceOnly。Preflight Ready、AlgorithmDone、ShapeIsValid、实际梯形体积公式和全局自干涉检查通过；重复面程序拒绝，源保持 1800。

`RepairSnapshot.CopySubshape` 深复制子形状，不能把它当作 `MakeThickSolid` 输入源的同一面。抽壳必须从当前私有源的 `GetFaces()` 取得其原始成员，并通过 `FindTopologyIndex(source, face)` 与已确认的完整拓扑索引相配；这个核查使用原生身份，不能用面数组顺序或最近几何匹配。包探针证明的是当前能力，不能替代应用输入验证、失败反例及 UI 验收。

## 实施步骤

1. 抽壳保存精确源结果、明确去除面列表、正壁厚与向内/向外选择。拔模保存精确源、逐面程序、带符号角度、拉拔方向、中性平面和明确传播策略。限制面数、重复身份、尺寸和角度，不能默认选择一个面。
2. 每个选择保存 document/feature/revision/asset/fingerprint/kind/index/adapter。所有面必须属于同一当前源；上游改变后保留旧结果并标为失效，要求明确重新选面，不能按旧索引自动续接。解除基准关联是明确操作，不能解除精确面身份。
3. 命令只消费所选当前输出，保留零件、图层、颜色、材料和可见性。准备、原生构造、联合重算及图纸更新都在候选内；失败/取消不改文档、历史或资产。重选可恢复后继；未重选时后继保守失效。
4. 抽壳直接使用拥有私有几何的源与其成员面；拔模使用 RepairSnapshot 与 FaceDraftRecipe。分别核查算法完成、exact BRep、一个实体、有限正体积及独立自干涉。抽壳还需证明去除面/偏移方向有效，未移除或破坏目标不能当成功。算法失败不得降级为表面。
5. 壁厚/逐面角度加入 C1 字段；中性平面可由 C2 同零件基准驱动，加入联合依赖图及循环检查。尺寸/平面改变可重算；源面身份变化必须失效。直接修改受驱动的帧须先解除来源。
6. 新建/编辑/重选共享生产窗口。明确源、逐面列表、厚度/方向、每面角度、拉拔/中性平面、传播，预览/确认/取消与异步关闭；接入 Ribbon、特征树和三语言资源。列表选择与编辑分开，不能遗漏已保存程序。
7. 追加 MessagePack 配方字段和独立能力/版本迁移。保留 D1/D2 的逐步旧版夹带拒绝，不能把旧 schema 直接跳到新的 CurrentFormats。精确选择和逐面程序显式编码；旧文件、畸形 companion、空/重复/外来面、非有限值、保存重开和再编辑一起验证。
8. 抽壳暂不伪造原始到最终历史；拔模只收录原生结果提供且经证明的历史。组合和缺失证据仍保守诊断，最终面/边可显式精确重选并进入后继局部编辑。

## 验收样本

抽壳覆盖向内/向外、单面/多面去除、过厚/窄壁/外来面/源修订变化，以及管状/曲面目标。拔模覆盖正负角、多面独立角度、中性平面平移/旋转、不同传播策略、非法方向/重复面/切穿失败。每类保留体积、拓扑、算法和自干涉数值，失败要证明原子回退与零泄漏。

共同样本覆盖 C1/C2、预览失效、取消/关闭中的晚到原生结果、单步撤销重做、后继失效/重新选面恢复、关联图纸、STEP 原生往返、原生文件保存及三语言控件。自动化按钮与真实桌面指针、外部 CAD、硬件/安装/交付分别报告，不把第七批暂缓转写为前六批全部通过。
