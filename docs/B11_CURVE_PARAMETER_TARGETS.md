# B11 椭圆和自由曲线参数驱动

更新：2026-10-03。属于已授权 A–F 的 B/G03 与 C/G08 联合工作。核心实现、三语言窗口及最终18组同版联合检查已通过，9张截图逐张检查。整个 B11 和 A–F 仍进行中，第七批实机、安装与交付暂缓。

## 使用与字段

在“文档参数”中选择明确草图曲线的数值字段，建立长度、角度或无量纲参数，再应用、绑定、预览与确认。目标标签先显示字段、单位和表索引，再显示曲线与草图，完整名称有工具提示。控制点、权重和结点在界面按 1 起算，持久数据中的明确表索引按 0 起算。

| 定义 | 可驱动及参考字段 | 量纲 |
|---|---|---|
| 仿射椭圆 | 中心 X/Y、余弦轴 X/Y、正弦轴 X/Y | 长度 |
| 仿射椭圆 | 起始角、有向扫过角 | 角度，公式支持 deg/rad |
| 有理 Bézier / B 样条 | 明确控制点的 X/Y | 长度 |
| 有理 Bézier / B 样条 | 明确权重 | 无量纲；必须为正 |
| B 样条 | 明确结点、有限原生区间起点/终点 | 无量纲；结点与区间整体校验 |

读取的是完整作者定义，不是显示采样或质量属性测量。非有理定义的空权重表没有可驱动的权重字段。次数、周期标志、方向、重数及表结构不作为表达式目标；保留驱动或参考目标时，改变曲线族、次数、周期、方向、表长度或重数必须先解除这些目标，防止索引悄悄指向另一个字段。

草图投影和原生边投影在来源驱动期间均不能作为这些参数目标，必须明确解除投影。数值曲线端点的固定锚点继续保护；通过曲线定义更新端点和锚点，而不是将端点固定尺寸伪装成曲线参数。未共享作者 ID 的同位置端点不会被合并。

## 原子更新与身份

参数目标新增种类 `ExactSketchCurve=4`，独立保存草图 ID、曲线 ID、属性和可选表索引；不借用约束 ID。其他目标携带隐藏曲线字段、错误索引、缺失对象或未知属性均拒绝。

全部表达式先计算，全部数值字段再暂存，然后一次验证完整几何并同步明确端点。这样允许同时平移结点与区间、修改多个椭圆轴分量，不因合法整组修改的暂时无效中间值而失败。随后按草图投影依赖求解，核验求解器没有改变完整曲线及原生来源意图，重建实体和图纸；失败、取消和下游内核异常保留整个原文档并释放候选资产。

已有受驱动字段的普通数值编辑被拒绝。文档级参数仍可以明确驱动独立零件的两套作者图；独立化重映射草图 ID，曲线 ID 和表索引在各草图内部保持。分别解除副本的驱动后，两件可独立修改。参考目标保留其原先明确选择的对象。
