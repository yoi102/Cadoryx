# M14：大型 STEP 打开与完整场景

更新：2026-09-28。M14 的生产路径计时和视口批次优化已实施，并在发布版完成两轮生产打开与双视口验证；**完整场景达到 M12 9.26 秒基线再降低 30% 的目标尚未实现**，不能把本轮标成全部完成。数据均为本机 CPU 提交与工作进程计时，不是 GPU 帧率或显示器首帧延迟。

## 生产打开路径

`--m14-open-benchmark` 从真实 `MainWindowViewModel.OpenPathAsync` 开始计时，经过独立 STEP 工作进程、临时 `.cadoryx` 保存、主进程延迟资产加载、文档激活、首个非空视口批次和完整场景提交。工作进程在自己的临时目录记录内核导入与保存阶段；主进程记录启动、退出、结构加载与资产所有权交接；`ViewportPane` 记录首批、完整提交、批次数和更新次数。关闭后检查原生视口与资产归零，截取完整画面。诊断文件只在工作目录内读取，正常退出和取消仍删除目录。固定样本为 `C:\Users\yoiri\Downloads\MiniPC3.step`，88,258,425 字节，SHA-256 `f3773a7f37bd0cb8e717e4be6f1070a72e5c6e7b2f36f26f9501183df8c4c68e`，4,975 个可见实例、1,196 个几何资源。

## 视口提交及源样式

原生产视口每批最多 32 个实例、35 ms 预算、每 450 ms 重绘且每批更新状态栏。改为每批最多 64 个实例、50 ms 预算、约 1200 ms 重绘及至多每 250 ms 更新状态；仍在批次之间让出 Dispatcher，首个非空批次立即重绘。相邻运行中原生资源准备约 3.89→3.83 秒，逐实例显示约 7.61→7.49 秒，分批重绘约 0.98→0.64 秒。其余差值来自批次调度、WPF 更新、最终提交与系统波动。最终画面 PNG SHA-256 在优化前后均为 `679ce900e0dce29f0401a3eddd0e7befb33c6bbf669334712839f7cea16e4ee6`；黄色外壳、红色风扇、蓝色底板和 XDE 继承面色没有被普通 shape 显示替代。

M12 的 9.26 秒是**直接内核/资产双视口基准**，本页 16.83/13.28 秒是用户打开后的 WPF 生产视口阶段，不能把两者混作同条件的优化率。若以 M12 目标计算，完整场景 CPU 提交应不高于约 6.48 秒；本轮既未证明达到这一目标，也未明显缩短约 81 秒的首次内核导入。

## OcctSharp 能力审计

锁定的 `8.0.1-preview.28.cadoryx.assembly.partner.1` 提供 `OcctViewer.Display(XdeLabel)`、独立 presentation 变换与选择，但每个可见实例仍创建并提交一个 `AIS_ColoredShape`。较早相邻运行分段显示约 7.5 秒；最终发布版两轮为 12.75/12.25 秒。原生 `viewer_display_xde_label` 为每次调用重新收集源样式、创建 presentation 并调用 `AIS_InteractiveContext::Display`。尝试在上游复用不可变 XDE 样式收集，并将样式成员逐个遍历改为拓扑索引；新原生 DLL、配套本地包及针对性的颜色/实例测试均通过，但同包同代码 A/B 中显示阶段分别约 7.49→7.43 秒、7.491→7.483 秒，收益不足且可能是噪声。实验接口及 Cadoryx 依赖已撤回，稳定锁定包未改变；本地实验包不是交付或公开发布。

若要达到原目标，OcctSharp 需要经独立消费者验证的高效**带源面样式的重复实例提交**，同时维持独立 occurrence 身份、命中选择、变换、面色和释放语义。不能简单合并成一个彩色 shape 或关闭选择来换速度。首次导入还需针对 OCCT STEP 原生读取约 38 秒、精确 BRep 逐定义转换约 41 秒分别设计；不能跳过几何校验或丢失可编辑资产。

## 复现与验收边界

对同一发布产物、同一哈希样本运行 `scripts/verify-m14-open.ps1 -Executable <Cadoryx.wpf.exe> -InputFile <MiniPC3.step> -Runs 2`；脚本逐轮写 `report.json`、`full-scene.png` 和资源清理结果，核对输入及截图哈希、实例/资源数，并记录 CPU/GPU/内存与未受控缓存条件。`scripts/verify-m6-benchmark.ps1` 单独检查双视口输入、旋转、资源趋势和中途取消；本轮 `artifacts/m14-dual-viewport-final` 的 `Cycles=2` 结果为 PASS，直接路径加载 103.25 秒、首次提交 1.87 秒、完整提交 13.99 秒。发布版 `scripts/verify.ps1 -PublishSmoke -WindowSmoke` 通过锁定还原、Release 零警告构建、596/596 自动测试、CLI、桌面和窗口冒烟。生产打开取消、失败和关闭由发布版桌面冒烟走真实工作进程验证。物理混合 DPI、RDP、长运行及新机器安装属于独立环境门禁。
