# B18 区域偏移的来源选择与内核基础

2026-10-07。本阶段实现了区域偏移的三个基础层，尚未接通整组关联作者工作流。正式已验收仍为 A4 / B17 / C5 / D5 / E4 / F5g，A–F 继续，G 暂缓。

`SketchExpressionRegionSelection` 按曲线 ID 和端点 ID 遍历闭合的二度链，保留每条作者曲线的原始值及遍历方向。支持显式直线、圆弧、Bézier、样条、固定椭圆/自由曲线、表达式边界和独立闭合作者。相同坐标不能连接不同端点身份；开放单曲线的轮廓闭合弦不能成为隐式来源。分支、构造曲线、缺失作者及未求解的端点拒绝，选择过程不修改草图或历史。输入枚举在 257 个槽位停止，重复种子不能绕过原 256 槽位预算。

`IExactSketchExpressionRegions` 返回拥有值的完整区域结果。原生统一绕向后，适配器按明确方向恢复原循环及原曲线索引，记录来源 ID、包含深度、直接父级和每段的来源角色。并行段保留完整原作者前缀、右法线偏移符号和原生参数单位；必要的有限延伸单独保留。圆角和斜接桥段复制原生 line/circle 定义，来源为明确相邻两条作者，不按坐标或采样推断身份。这些记录是作者对应关系，不能充当原生边/面历史。

多曲线连接继续使用 SDK 的六次有限交点窗口及 20:1 miter 上限。单条闭合曲线没有角点，因此直接保留偏移后的完整有限域，避免冗余 `Trim(0,1)` 对反射端点产生一个浮点单位的越域；不夹紧非法区间。输出复验正则性、自交、原生边界分离、包含树、面积单调性及实际带孔填充面。原生面使用 `InspectAdaptiveProperties(..., 1e-12)`，与轮廓积分仍按原 1e-8 面积容差比较，几何容差仍为 1e-7。

嵌套直线偏移的距离相互抵消时，SDK 原生建边后的长度量取会失败，独立诊断保存在 `artifacts/b18-expression-region-line-diagnostic-1.txt`。本阶段保留明确拒绝测试，不发布部分结果。用于验证完整来源前缀的矩形夹具采用可认证的同向嵌套偏移，原直线基值作精确平移以保持最终矩形。未修改隔离 SDK 的 1007 个源文件、13 个托管程序集或 62 个原生库。

`SketchRegionIntersectionSensitivity.Differentiate` 在已经证明的有限交点处求解 `A_u du - B_v dv = B_source - A_source`，提供解析源坐标敏感度。它使用归一化切向矩阵，保留 1e-9 相切拒绝、1e-7 共同点及 256 变量预算。它不负责求根、分支选择、拓扑证明，也尚未接入区域组的求解方程。

专项包含 105 个新用例：内核 76、解析导数 15、来源选择 14。覆盖三种连接、两种偏移符号、原循环及单曲线反向、反射椭圆的负角/跨周期域、四层孔岛/多根/输入排列、独立 Steiner 面积公式、明确闭合弦、同坐标不同身份及原预算拒绝。Release/Debug联合各 **2036/2036通过**；同冻结904源码完整Release **3862/3862通过，0失败/0跳过**，原3757、此前3667及SDK19全部2936名称保留。当前实际62原生加载匹配，两个配置各113载荷冻结。证据为 `artifacts/b18-expression-region-foundation-verification-2.json`，组作者接入详见 `artifacts/b18-expression-region-group-integration-next-1.md`。
