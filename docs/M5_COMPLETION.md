# M5 收尾：外部零件快照与受限装配关系图

本轮将外部零件和两类基准关系接入既有文档事务、属性面板与文件协议。实现范围是可检查、可撤销的受限装配工作流；任意闭环机械配合和从真实 BRep 自动提取面/轴基准仍须独立设计和验收。

| 能力 | 行为与约束 |
| --- | --- |
| 外部零件 | 显式选择 `.cadoryx` 来源及非空零件，将其 BRep 资产与冻结 body 拷贝进当前文档的新零件定义。记录来源文档、零件、状态 ID、SHA-256、相对路径及绝对路径提示、本地指纹。来源丢失时冻结形体仍能读取；检查返回当前、来源缺失/变化、本地变化或读取冲突。更新仅在本地指纹未变化、来源身份相同且来源状态改变时发布新快照；解除链接保留当前几何。未用定义清理同步移除链接元数据。 |
| 角度轴与平面贴合 | 两端局部点/单位轴由用户显式输入。角度关系限制为 0–180°；平面贴合将两端法向调成反向并消除法向距离，保留平面内自由滑移。单关系调整只移动第二个实例，失败时不提交。拓扑来源仍只用于精确修订检查；不能由面或边自动生成基准。 |
| 批量调整 | 对无多驱动歧义的有向关系图依次调整，最后复核全部启用关系；冲突、陈旧关系和未满足的环拒绝整个候选快照。报告未固定的根实例，但不声称数值自由度。固定关系仍受文档验证保护。 |
| 文件协议 | 写出器 0.4.29；`document` v16 在原有关系后追加目标角度；新增必需 `external-parts` v1，共十一节 MessagePack。v14→v15 引入空链接节，v15→v16 为旧关系补默认角度。文档载入不主动打开外部来源；普通保存及恢复保存冻结快照。 |

独立来源文件与当前文档间没有自动更新订阅或跨文档循环依赖图。来源身份冲突会在显式刷新时拒绝；文件哈希变化先显示为“来源变化”，再由刷新核对内部身份。外部零件使用同一文档资产租约与撤销历史，不能在仍关联时直接向冻结定义添加建模特征，须先解除链接。当前未完成：真实拓扑基准提取、任意闭环非线性配合、准确自由度/冗余报告、跨文档依赖管理及真实大装配性能验收。这些能力不能由受限有向调整结果推断为已实现。
