工程图补局部放大、剖面线、ISO/GB/ASME 可选模板、尺寸/公差与图框表达；物理打印从 M17 环境门禁取证。交换以多厂商固定 STEP/IGES/STL 样本核对装配层级、单位、面色、PMI 与丢失项，IGES 曲面/实体语义不可保留时明确报出。外部材料库、纹理和 PBR 材质需要独立的持久化与交换契约，不把现有简单颜色误称为完整材质系统。命令行和 AI Agent 扩展到用户常用的草图、装配、图纸操作，但每个写操作继续要求精确文档/状态/对象身份、预览与撤销；不允许模型文本直接调用任意 CAD API。补文件对话框、Ctrl+V、长对话、取消、视觉附件与不同 DPI 的人工使用验收。

完成标准：真实零件和装配的关联图纸经模型修改后正确刷新，PDF 和打印预览可读；交换报告逐项记录保留与损失；Agent 工具返回的成功与文档实际状态一致，过期/歧义输入不改模型。将外部模型服务可用性、响应质量和本地工具安全分别报告。

## M17：最后取得真实交付证据

使用 M13 已固定的 MSI 和 SHA-256，在**未安装开发 SDK/本地 OcctSharp 包**的 Windows x64 机器验证安装、首次启动、STEP/IGES/STL、文档保存/恢复、升级和卸载。再做两台不同 DPI 显示器之间的停靠/浮动、RDP 断线重连、多 GPU/驱动、数小时大模型交互、物理打印机输出与资源趋势。真实磁盘满、断电及网络盘与既有故障注入分开记录。签名、外部 CI 和公开发布各自保留独立结果；公开发布前需有相应发行授权与可核对的最终包。

这些环境设备和外部服务未在当前本机证据中出现时，只能标为“未验收”。M14–M16 可在同一开发机实施；M17 的实机矩阵可提前准备样本与脚本，但不能由模拟 PATH、短时冒烟或本机 MSI 安装自动代替。
