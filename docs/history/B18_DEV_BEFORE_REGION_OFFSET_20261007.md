## 已确认的入口与缺口

当前应用的`SketchLoopOffset`仅接受直线/圆弧，`SketchRegionOffset`基于这些解析边界验证包含树；`SketchBoundaryCurve`和`SketchFreeformGeometry`拥有作者曲线数据，但没有持久化的偏移曲线表达式。Bézier/样条的普通等距曲线一般无法由同类有限控制点精确表示，因此不能把拟合样条或显示折线存成偏移结果。

当前14锁包公开消费者已确认`Geom2dOffsetCurve`真实对象及释放调用方基曲线后的求值有效，椭圆两个符号的8个解析法线点误差不超过1e-9。高层`SurfaceModeling.OffsetUv`对二次/三次Bézier、非均匀有理样条、有限椭圆的正负8例均返回BSpline，原调用方值保持。其`IsExactGeometry=true`、`Residual=0`、`PreservesSourceParameterization=false`不能证明原始偏移表达式保留；现有`SketchCurveKind`没有基曲线＋距离类型。缺口属于复制草图/BRep输入链，不声称所有原始OCCT路径均不可用。证据见[锁包消费者审计](../artifacts/b18-api-probe-verification-1.json)。上游canonical迁移源码和全局状态不修改。
