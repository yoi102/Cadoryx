# C1：命名参数、单位表达式与驱动绑定

更新：2026-10-01。属于 [A–F 总实施](AF_IMPLEMENTATION_TRACKER.md)中的 C 批，不代表镜像/阵列、关联基准、标准孔或其余 A–F 功能已完成；G 第七批仍暂缓。

## 当前功能

- 文档内稳定参数 ID、大小写不敏感名称、长度/角度/无单位数；表达式按依赖求值，循环报告实际参数链。
- 四则运算、括号、科学计数法、`pi`、`abs/sqrt/min/max/sin/cos/tan`；`mm/cm/m/in/ft/rad/deg`。长度内部为 mm，角度为 rad，不把未带单位的数自动解释为长度。
- 表达式参数可明确绑定多个已有设计尺寸，一个目标只能有一个驱动参数。参考参数只读已有配方/约束数值，不可同时写表达式或直接驱动尺寸；可以被另一个表达式引用。参考读取的是设计值，不是屏幕测量或自由几何的实测尺寸。
- 草图求解、投影后继、原生特征、关联截面和工程图随参数事务更新；参数列表、绑定、结果、修订、资产和图纸共同提交，只有一条撤销历史。
- 三语言参数窗口、参数/目标选择、行应用、删除及绑定解除、候选预览/确认/取消。未应用的表单输入会阻止预览确认，不能用旧的行内容确认新输入。

## 支持的目标

| 类型 | 可绑定字段 |
|---|---|
| Box | X/Y/Z |
| Cylinder | Radius/Height |
| Extrude / Revolve | Distance / Angle |
| LocalFeature | Size，已有的 SecondDistance/EndRadius |
| HistoryFillet / HistoryChamfer | Radius/Distance，已有的 EndRadius/SecondDistance |
| 草图尺寸 | Distance、OffsetX/OffsetY、Length、圆/圆弧 Radius、Angle；固定点 X/Y |

引用必须指向当前文档内明确对象及字段；不使用显示次序作为保存身份。删除/禁用目标尺寸、删除/抑制/过期特征、字段类型改变、投影锚点及错误量纲均拒绝。用户须先解除参数绑定或投影，再做相应操作。数值受驱动时，普通尺寸编辑被原子拒绝并提示改参数/解除绑定，不悄悄覆盖用户输入。

后续新特征的数量、间距、基准偏移等字段将在对应配方交付时扩展目标适配；当前不支持任意 API 属性、表达式执行代码、自由曲线测量值或几何面积/体积作为表达式输入。

## 使用

在 Ribbon 文档工具点击“文档参数”。新建参数，填名称、量纲和表达式，再“应用此行”。例如长度 `width = 40 mm`、`depth = width / 10`。选中参数和已有尺寸，点“绑定所选参数”；可重复绑定不同尺寸。

勾选“读取已有设计尺寸（只读参考）”后选择目标，其量纲跟随目标；表达式为空。参考 `source_width` 可以用于 `radius = source_width / 10`。若形成 `radius → source_width → radius`，预览会报告循环而保留原文档。

应用全部输入后求解预览，检查计算值与实体，再确认。关闭或取消释放候选，文档保持原状。更名不会自动改写其他公式；仍引用旧名称时报告缺失依赖。删除参数会移除它自己的驱动绑定，其他公式依赖须明确修正。

## 事务与存储

`ParameterExpressions` 是有界解析器，最多 2048 字符/512 token/64 层表达式；文档最多 256 参数/1024 绑定/64 层依赖。中间值、量纲幂和最终值检查有限性及预算，不做截断或代码求值。

`ParameterGraph` 同时处理表达式依赖和参考目标的驱动依赖。`ParameterRecompute` 先在孤立候选中应用全部驱动，再按草图投影依赖顺序求解，严格检查注入求解器的身份/意图，重建受影响特征及后继；`UpdateAssociatedSections.PrepareCommandAsync` 统一后处理关联截面和图纸，生产会话与各候选预览使用同一路径。普通命令改变独立参考尺寸时也刷新依赖驱动。

document **v21**，新 `parameters v1` MessagePack 节，共十四节；必需能力 `cadoryx.document-parameters.1`。features v22/sketches v11 不变。保存参数 ID/名称/量纲/公式、只读目标和驱动绑定 ID；不保存计算值或临时窗口状态。v20→v21 独立迁移引入空参数表，v19→v20 图纸迁移保持独立。旧文档夹带新参数节触发跨节碰撞拒绝，不能将其静默抹成空表。既有旧版测试夹具仅在模拟实际旧文档时移除新节，伪装测试保留新节并验证拒绝。
