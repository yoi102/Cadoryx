## 必须证明的关系

当前 `OcctGeometryBridge.ReadShape` 每次从 BRep 字节建立独立原生图。相同字节、表索引、拓扑数量或几何值不能让不同解码共享身份。保存桥必须在编码时捕获实际来源成员的原生引用，在加载时把根和这些引用放进同一个解码图，再验证引用的实际根成员关系。

OCCT 8.0.1 的 `BRepTools_ShapeSet` 保存形状、几何和位置表；`TopTools_ShapeSet.Write(shape, stream)` 与 `Read(shape, stream)` 处理这个实际集合中的 TShape、方向及 Location 引用。这是待验证机制，不预先认定足以关闭所有历史边界。
