# M4-S3：曲线区域三个大阶段

本轮连续实现三个可交付能力，全部代码完成后统一验证。输入仍是草图中的共享端点直线和三点圆弧，尺寸单位为毫米；圆弧始终保留精确 OCCT 曲线，不以屏幕折线代替建模。

| 大阶段 | 范围与验收边界 |
| --- | --- |
| 多圆弧闭环 | 允许一个闭环含多段圆弧和直线；仅识别孤立、无分支、每个顶点度数为二的连通分量；解析检查线线、弧线、弧弧的交叉和重叠；稳定有序实体 ID 驱动关联拉伸和重算。 |
| 混合外边界与常规孔 | 混合曲线外边界可选多个完整圆孔及闭合直线多边形孔。每孔必须严格内含、互不接触和嵌套，精确布尔切穿实体；非法编辑保持原特征及资产。 |
| 混合曲线孔贯通 | 圆、直线多边形或混合曲线外边界可选混合曲线孔；界面逐孔勾选，保存有序孔线／弧 ID 和草图修订；特征缓存逐曲线校验，重算和文件恢复保持来源身份。MessagePack features v16 新增独立字段，v15→v16 显式迁移并拒绝新字段伪装旧版本。 |

边界相交采用解析几何；孔包含关系以边界不相交和射线奇偶分类为前提。最多 64 个孔、单环最多 256 段。现有圆弧加隐式弦区域和单圆弧混合区域继续兼容。内核沿用已锁定 OcctSharp 的圆弧、曲线链、建面、拉伸和布尔接口，独立包探针另行验证。

本轮不提供样条草图实体、样条约束、岛屿递归区域、多实体拉伸或自动拓扑重绑定。样条所需 OcctSharp 曲线 API 已存在，但 Cadoryx 草图编辑／求解／存储模型尚未提供相应实体，因此仍在 ROADMAP 后续项。
